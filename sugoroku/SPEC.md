# ダイスキングダム（王国すごろく）仕様書 v3.0

> v2 で「カードで動く陣取りすごろく」に作り替えた。v1（不動産ルール）からの変更点は、次の「v2 ルール」がすべて優先する。盤面・キャラ・ステージ・成長要素の考え方は v1 の記述を引き継ぐ。

## v3 の変更（最新・v2 ルールに上書き）
- **手札は毎ターン総入れ替え**：ターンの最初に山札から5枚（魔女は6枚）引き、使わなかった手札はターン終了時に捨て札へ。
- **強化（+）**：王の贈り物では「新しいカード1枚」か「デッキのカード1種類を無料で強化」のどちらか。カード屋では買うか、お金で強化（カードの値段の6割、最低40G）。強化はデッキ内の + でない1枚を + にする。
  - 主な強化：歩く+ 2マス／サイコロ+ 出目+1／双子+ ⚡1／狙い撃ち+ 1〜5／疾風+ 4〜9／引き返す+ ⚡0・1〜4戻る／転移+ ⚡2／旗手+ 5マス以内・2割引／進軍+ 2マス以内／築城+ 2段階／結界+ 5ラウンド／勅命+ 2割引／金貨の袋+ 140G／徴税+ 1.5倍／作戦会議+ 3枚／盗賊団+ 30%（最大450G）／落とし穴+ 200G／大地震+ 2段階／竜+ ⚡2
- **消耗**：転移の書・王の勅命・竜の召喚は、使うとその試合のデッキから消える。
- **キャラ調整**：商人は10%引き（15%から）。略奪王は「最終決戦で奪う値段が4割引（ふつうは3割引）」＋進軍。
- **操作**：カードは上へスワイプで使う。マスを選ぶカードは盤面のマスまでドラッグ（光ったマスの上で離す）。2回タップでも使える。山札をタップするとデッキの中身が見られる。
- **見た目**：カードは Wholetone「Ivory & Lacquer」無料サンプラー、ダイアログやボタンの枠は Kenney「UI Pack - Adventure」（CC0）。Wholetone の素材はライセンス上、公開リポジトリに置けないため、ビルド時に `scripts/fetch-ui.mjs` で取得する（`src/ui-assets/wt/` は .gitignore 済み）。
- バランス（`npm run sim -- 1500 meadow`）：1人あたり 旗 4.6・奪取 7.1・強化 2.1・カード使用 44。優勝者の陣は中央値 6/18、2位との差は中央値 1。逆転勝ち 約83%。キャラ別勝利は公平な値の ±10% 前後。

## v2 ルール

### 勝利条件
- 20ラウンド後に **陣（色付きのマス）を一番多く持っている人** の勝ち（同数なら砦の段階の合計 → 所持金）。
- **全陣制圧**：18の陣をすべて持った瞬間に勝利。残り3つになると全員に警告が出る。

### 1ターンの流れ（カードゲーム風）
1. 自分の陣から **税収** が入る（陣の値段 × 7% ×（1＋砦の段階）、同じ色を全部持てば2倍）。
2. 山札から手札が **5枚** になるまで引く（尽きたら捨て札を混ぜ直す）。
3. 行動力 **⚡3** の範囲でカードを好きな順に使う。**移動はカードでしかできない**（1ターン1枚まで）。
4. 「ターン終了」で終わる。使ったカードは捨て札へ。

### 陣
- 空いた陣に止まる → 値段を払って **旗を立てる**。
- 自分の陣に止まる → **砦** を築ける（旗 → 砦 → 城塞 → 王城、1段階ごとに値段 × 50%）。
- 相手の陣に止まる → **通行税**（値段 × 12% ×（1＋段階）、色統一なら1.5倍）を払い、そのあと **お金で奪える**（値段 ×（1.7 ＋ 1.0 × 段階））。奪うと砦は1段階崩れる。守りの結界がある陣は奪えない。
- 最終3ラウンドは **最終決戦**：奪う値段が3割引。

### デッキ構築
- キャラごとの初期デッキ10枚（歩く×2、サイコロ×4、狙い撃ち、金貨の袋、築城 ＋ キャラ固有の1枚）。
- 王都の門を通ると給料と **王の贈り物**（3枚から1枚もらえる）。
- 精霊の祠は **カード屋**（3枚から買える）。買ったカードは捨て札に入る。

# v1 の仕様（参考）


モノポリーを参考にした3Dすごろく。相談で確定した内容をまとめる。

## 1. 基本

| 項目 | 内容 |
|---|---|
| ジャンル | 3D ボードゲーム（土地を買って建物を育て、通行料で稼ぐ） |
| 対戦 | あなた1人＋CPU3人（オンライン対戦なし） |
| 長さ | 20ラウンド（約15分） |
| 舞台 | 空に浮かぶ島のファンタジー王国 |
| 技術 | Three.js + TypeScript + Vite（ブラウザで動く。PC・スマホ両対応） |
| 素材 | すべて外部素材（自作モデルは使わない）。CC0 も画風が理想的なら使う。作者とライセンスはゲーム内のクレジット画面と `CREDITS.md` に記載 |

## 2. 1ターンの流れ

1. カードを使う（任意、1ターン1枚まで）
2. サイコロ2個を振る。ゾロ目ならもう一度振れる。3連続ゾロ目は地下牢行き
3. 進んで、止まったマスの効果を受ける
4. 王都の門（スタート）を通過するたびに給料 200G（最下位は1.5倍）。さらに、好きな自分の土地を1段階建てられる

## 3. 盤面（1周30マスの六角形の輪）

六角形のタイルを輪にした道を駒が歩く。道の外側に隣接する六角形が「土地」で、買うと持ち主の色の建物が建つ。

| マス | 数 | 効果 |
|---|---|---|
| 土地 | 18（6色×3） | 購入できる。価格は 60G（若葉の野）〜 350G（白亜の王城） |
| 精霊の祠 | 3 | カードを1枚引く |
| 運命の巻物 | 2 | ランダムなイベント（下位ほど良いことが起きやすい） |
| 竜の関所 | 1 | 所持金の10%を払う（ジャックポットに貯まる） |
| 王都の門（角） | 1 | スタート。ぴったり止まると給料 +100G |
| 酒場（角） | 1 | 50G か 150G を賭けてサイコロ1個。4〜5で2倍、6で3倍 |
| 地下牢（角） | 1 | 捕まる。次のターンに 50G 払うかゾロ目で脱出。2回失敗で釈放 |
| 黄金の泉（角） | 1 | ジャックポット。貯まった全額をもらえる |
| 大聖堂（角） | 1 | 祝福金 100G（最下位は200G）とカード1枚 |
| 転移の魔法陣（角） | 1 | 好きなマスへワープ（黄金の泉は不可） |

マスの並びと価格は `src/data/defs.ts` の `TILES` に定義する。

## 4. 土地と建物

- **購入**：持ち主のいない土地に止まると買える。
- **建設**：自分の土地に止まると2段階まで、王都の門を通るときは好きな土地を1段階建てられる。空き地 → 村 → 町 → 城塞 → 王国の象徴。
- **通行料**：価格 × 係数。係数は空き地 0.25、村 0.8、町 1.7、城塞 3.0、象徴 4.8。
- **建設費**：1段階ごとに 価格 × 0.55。
- **領地制覇**：同じ色の3マスを独占すると、通行料が2倍になり、3マスすべてに村が無料で建つ。「王国の象徴」は領地制覇していないと建てられない。
- **買収**：相手の土地で通行料を払ったあと、その土地の価値（価格＋建設費の合計）の 1.4倍を払えば奪える。王国の象徴と竜がいる土地は奪えない。
- **領地交渉**：自分の土地に止まったとき、同じ色で相手が持つ土地を同じ条件で買収できる。

## 5. 勝利条件

1. **20ラウンド終了時に総資産1位**。総資産は現金＋土地価格＋建設費。
2. **三国統一**：3色の領地制覇を達成した瞬間に勝利。2色そろえた人が出ると、全員に警告を表示する。
3. **他の全員が破産**。

破産処理：支払えないときは、安い土地から自動で売却（価値の60%）。それでも足りなければ破産し、残りの現金を相手に渡して退場する。

## 6. 逆転の仕組み

- **ジャックポット**：竜の関所の税、地下牢の保釈金、毎ラウンドの加算で貯まり、黄金の泉で総取り。
- **巻物イベントの重み付け**：下位ほど良いイベントが出やすく、首位ほど悪いイベントが出やすい。
  - 良いイベント：王の褒美、宝箱、民の寄付（全員から少しずつもらう）、追い風（黄金の泉へ）、無料建設、カードを引く
  - 悪いイベント：盗賊（所持金−10%）、嵐（3マス戻る）、地下牢送り、税務官（建物1段階ごとに支払い）
  - 中立：竜の襲撃（首位の一番高い建物が1段階崩れる）
- **最終局面**：最後の3ラウンドは通行料が1.5倍になり、BGMが変わる。
- **逆境の加護**：最下位はスタートを通るたびに給料が1.5倍になり、カードを1枚もらえる。

## 9. 成長要素（データはブラウザに保存）

- **経験値とレベル**：1回遊ぶごとに経験値が入る（順位、領地制覇、ジャックポット、買収などでボーナス）。レベルアップのたびに報酬（王冠、新カード、ステージ、サイコロの見た目）がもらえる。
- **王冠ショップ**：王冠でキャラを開放する。
- **ステージ**：

| ステージ | 開放 | 特徴 |
|---|---|---|
| 翠緑の王国 | 最初から | 基本ルール。CPUは弱め |
| 白銀の王国 | レベル3 | 通行料 1.2倍。CPUが少し賢い |
| 灼熱の王国 | レベル6 | 通行料・ジャックポット 1.5倍。CPUは手強い |
| 天空の王国 | レベル10 | 所持金 2000G、ジャックポット 2倍。CPUは最強 |

- **サイコロの見た目**：象牙（最初から）、黒曜石、紅玉、翡翠、黄金、星屑。見た目だけで性能は変わらない。
- **実績（称号）**：初勝利、三国統一、ジャックポット獲得、王国の象徴を建てる、最下位から逆転、相手を破産させる、全キャラで勝利、など。達成すると王冠がもらえる。
- **結果画面**：経験値バーが伸びる演出、レベルアップのファンファーレ、開放したものを1つずつ見せる。

## 10. CPU

| 性格 | 特徴 |
|---|---|
| 慎重型 | 一定額の現金を常に残す。買収は控えめ |
| 強欲型 | 買えるものは何でも買う。建設も積極的 |
| 博打型 | カードと買収を多用し、ジャックポットを狙う |

ステージの CPU 強さ（0〜1）が高いほど、判断ミスが減り、色をそろえる・阻止する動きが増える。

## 11. 演出（3D）

- 島ごと空に浮かぶ盤面。カメラは手番の駒を追い、イベント時に寄る。
- サイコロは物理演算で転がる（結果はゲーム側で決め、出目が合うように見せる）。
- 建物は段階ごとに別のモデルに差し替え、弾むように出現する。
- 通行料の支払いでは、金貨が払う人から受け取る人へ飛ぶ。
- 領地制覇、三国統一、ジャックポットでは、大きな文字の演出と紙吹雪。
- CPUの手番は早送りできる（1倍・2倍・4倍）。

## 12. 素材の方針

- 3Dモデル：itch.io / OpenGameArt の配布素材。画風の統一を最優先にし、CC0 も使う。再配布禁止の素材は、リポジトリに入れずにビルド時に配布元から取得する。
- アイコン：game-icons.net（CC BY 3.0）。カード、キャラ、マスの絵柄に使う。
- BGM：Kevin MacLeod / incompetech（CC BY 4.0）。効果音：OpenGameArt（CC BY 3.0）。
- フォント：Dela Gothic One / M PLUS Rounded 1c（OFL）。

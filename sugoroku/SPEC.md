# ダイスキングダム（王国カードバトル）仕様書 v4.0

> v4 で「すごろく＋陣取り」から「カードバトルで領地を奪い合う陣取り」に作り替えた。v1〜v3（すごろく）の仕様は git の履歴に残っている。

## 全体
- あなた1人と CPU 3人の領主。島は **13の領地**（王都4・中立8・中央の竜の巣1）に分かれている。
- **8ラウンド**後に領地が一番多い領主の勝ち（同数ならバトルの勝ち数）。ほかの全員を脱落させても勝ち。
- 相手の **王都を落とすと、その領主は脱落** し、ほかの領地は中立に戻る。あなたが脱落したらその場で試合終了。

## 1ラウンド
- 領主が順番に（毎ラウンド先手が入れ替わる）次のどちらかを行う。
  - **攻める**：自分の領地のとなりにある領地を1つ選んでカードバトル。勝てば領地を奪い、報酬のカードを3枚から1枚もらう（王都を落としたときは、その領主の得意カードも候補に入る）。
  - **訓練**：カードを3枚から1枚もらうか、デッキからカードを1枚外す（8枚未満にはできない）。
- 4・8ラウンドの初めに、竜の巣が中立のままなら **竜の襲撃**：首位の領主の王都以外の領地を竜が攻める。負けた領地は中立に戻る。
- 領地が一番少ない領主は、3ラウンド目以降のバトルで最初の手札が1枚多い（逆転の仕組み）。

## カードバトル（1対1）
- 攻める側が先攻。城の体力：攻める側 20（略奪王は24）、守る側は 王都 30・領主の領地 20・中立は領地ごと（11〜22）。
- マナは毎ターン1つずつ増える（最大7）。王都と内側の中立の守り手、竜の巣は最初からマナ +1。
- 最初の手札：先攻3枚・後攻4枚（商人は+1）。毎ターン1枚引く。手札は8枚まで（あふれたら失う）。山札が尽きると、引くたびに1,2,3…のダメージ。
- **兵**：場に5体まで。出した次のターンから、敵の兵か城を攻撃できる。兵どうしは同時にダメージを与え合う。
- **能力**：守護（敵はまずこの兵を攻撃しなければならない）／速攻（出したターンから攻撃できる）／射撃（攻撃しても反撃を受けない）／盾（最初のダメージを1回防ぐ）。
- **呪文**：一度きりの効果（ダメージ・全体攻撃・回復・強化・ドロー・兵を出す）。
- 相手の城の体力を0にしたら勝ち。どちらも14ターン経っても決着しなければ守る側の勝ち。

## カード（38種＋トークン2）
- 基本の兵・呪文（初期デッキ12枚＋キャラの得意カード1枚）：見習い兵・槍兵・盾兵・弓兵・僧侶・騎士・火矢・鼓舞 など。
- 報酬で手に入る：狩人・山の戦士・魔導士・聖騎士・騎兵・重装兵・投石機・将軍・岩の巨人・英雄・竜、呪文の火球・補給・祈り・城壁・伏兵・鍛え直し・吹雪・隕石。
- 魔物（中立の守り手）：ゴブリン・骸骨兵・大蜘蛛・盗賊・オーク・ワイバーン・トロル・亡霊。その領地を落とすと仲間にできる。
- カードの一覧と数値は `src/data/defs.ts`。

## 操作
- 地図：光っている領地（または名札）をタップして攻める。下のバーから訓練。
- バトル：手札のカードを **上へスワイプ** で出す。対象のいる呪文は対象までドラッグ。兵は **敵の兵か城へドラッグ** で攻撃（矢印で狙う）。どれも「タップで選ぶ → 対象をタップ」でも操作できる。
- 「おまかせ」でそのバトルを CPU に任せられる。守るバトルは、攻められたときに「迎え撃つ／おまかせ」を選ぶ。

## バランス（シミュレーション）
- `npm run bsim`：初期デッキどうし（攻め20 vs 守り18）で攻める側の勝率 約57%。初期デッキで中立に挑むと、外側の領地は 68〜81%、内側は 46〜57%、竜の巣は 4%。
- `npm run sim -- 600`：CPU 4人の遠征。1試合のバトル 約33回（あなたが関わるのは攻め8回前後＋守り数回）、優勝者の領地は中央値 4/13、2位との差は中央値 1、逆転勝ち 約60%。キャラ別の勝ち数は公平な値の ±10〜30%。

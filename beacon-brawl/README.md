# BEACON BRAWL

ブラウザで遊べる **3 vs 3 の 3D 対戦アクション**。拠点争奪・デスマッチなど4つのモードで戦う。
プレイヤー1人 + 味方AI 2人 vs 敵AI 3人。PC（キーボード+マウス）とスマホ（タッチ）の両方に対応。

## 遊び方

```bash
cd beacon-brawl
npm install
npm run dev          # 開発サーバー（サーバーなし。セーブはブラウザ内）
npm run build:all    # ゲーム(dist/) とサーバー(dist-server/) をビルド
npm start            # サーバー起動（PORT=8080、セーブは DATA_DIR=./data）
```

サーバーを起動して開くと、端末ごとにゲストアカウントが作られ、セーブはサーバーに残ります（ランキングも使えます）。
サーバーなしで開いた場合（`npm run dev` やオフライン版）は、セーブはそのブラウザの中だけに保存されます。

### ソシャゲ要素

| 機能 | 内容 |
|---|---|
| ガチャ | ジェム100で1回、900で10回（SR以上1体確定）。提供割合 SSR 6% / SR 24% / R 70%、50回で SSR 確定。被ったら「かけら」になる |
| キャラ強化 | コインとかけらでレベルアップ（最大10）。1レベルごとに体力・攻撃 +5% |
| デイリーミッション | 毎日午前4時（日本時間）に3つ入れ替わる。達成でコイン・ジェム |
| ログインボーナス | 7日周期で毎日コイン・ジェム |
| トロフィーロード | 勝つとトロフィー +8、負けると -4（100未満では減らない）。節目でコイン・ジェム・キャラ |

通貨はゲーム内で稼ぐだけで、課金はありません。ルールは `src/meta/economy.ts` に集約していて、ブラウザ版とサーバーの両方が同じものを使います。

| 操作 | PC | スマホ |
|---|---|---|
| 移動 | WASD / 矢印キー | 画面左側に指を置いて動かす（少し倒せば全速） |
| 通常攻撃 | マウスで狙って左クリック | 攻撃ボタン。タップで近くの敵へ自動照準、引っぱって離すと狙った方向へ |
| スキル1 / スキル2 | Q / E（押している間は予告、離すと発動） | ボタン（攻撃と同じくタップ/引っぱり） |
| 必殺技 | Space | ボタン（ゲージ満タンで発動） |

- 視点は斜め上から固定（ブロスタ風）。引っぱっている間は届く範囲が地面に出る。中心に戻して離すとキャンセル。
- 通常攻撃は弾数制。3発までためられ、時間で1発ずつ回復する。撃ちながらでも移動速度は落ちない。
- 必殺技のゲージは主に攻撃を当てると溜まる。

## ルール（4モード）

| モード | 勝利条件 |
|---|---|
| ドミネーション | 5つの拠点を奪い合い、3分後に多く持っていたチームの勝ち |
| デスマッチ | 先に12回倒したチームの勝ち（3分で決着しなければ撃破数） |
| コントロール | 中央の拠点を確保し続け、先に100%に達したチームの勝ち |
| クラッシュ | 復帰なしのラウンド戦。相手を全滅させると1本、3本先取 |

- **必殺技は2択**: キャラ選択で各ヒーロー2種類の必殺技から1つ選ぶ。ゲージは主に攻撃を当てると溜まる（拠点の確保や時間経過でも少し溜まる）。
- 倒されると 7 秒後に自陣から復帰（クラッシュを除く）。自陣の円の中では HP が急速回復する。

## ヒーロー

| 名前 | レア | 役割 | 特徴 |
|---|---|---|---|
| ガルド | R | タンク | 盾でスタン、ダメージカット、味方回復の必殺技（初期キャラ） |
| ボルガ | R | アタッカー | 大剣の範囲攻撃と自己強化（ロード60） |
| ルミナ | R | サポート | 遠距離の爆発魔法と回復（初期キャラ） |
| レン | R | ファイター | 居合の踏み込みと連続斬り（初期キャラ） |
| シェイド | SR | スプリンター | 最速。突進と透明化で拠点を荒らす |
| ヴェイル | SR | スナイパー | 最長射程。貫通弾と範囲制圧 |
| ミオ | SR | ボマー | 時限爆弾と味方へのバリア |
| ノクス | SR | ガンスリンガー | 二丁拳銃の連射と全方位射撃（ロード200） |
| ピピ | SR | トリックスター | 花火と風で敵を吹き飛ばし・引き寄せ |
| モルス | SSR | トリックスター | 鈍足・スタンで足止め、吸収で粘る |
| シロネ | SSR | ヒーラー | 範囲回復と味方全体の大回復（ロード800） |
| カイ | SSR | ブルーザー | 突進・叩きつけ・無敵化（ロード400） |

キャラクターは VRM 形式（アニメ調）。`public/assets/vrm/` に VRM を置き、`src/heroes.ts` の `model` を書き換えれば、VRoid Studio で自作したキャラなどに差し替えられます（1試合に各ヒーロー1体ずつ登場し、自分以外の味方2人と敵3人は残りのヒーローからランダムに選ばれます）。

ヒーローは12人。能力は `src/heroes.ts`、レア度は `src/meta/roster.ts` で定義しています。

## 構成

| ファイル | 役割 |
|---|---|
| `src/main.ts` | 起動、画面遷移（ホーム / キャラ / ガチャ / ミッション / ロード / 対戦 / リザルト） |
| `src/meta/` | ソシャゲ部分のルール（economy.ts）、ヒーロー一覧（roster.ts）、セーブ先の切り替え（store.ts） |
| `server/server.ts` | アカウントとセーブのサーバー、ゲームの配信 |
| `src/game.ts` | 対戦ロジック（ユニット、拠点、弾、AI、カメラ） |
| `src/heroes.ts` | ヒーローとスキルの定義 |
| `src/stage.ts` | ステージの見た目（コード生成）と配置、当たり判定、経路探索（A*） |
| `src/assets.ts` | VRM 読み込み、モーション移植、武器の装着 |
| `src/weapons.ts` | 武器の形状（コード生成） |
| `src/fx.ts` / `src/audio.ts` | エフェクト / 効果音（合成） |
| `src/hud.ts` / `src/input.ts` | HUD / 入力 |
| `scripts/build-rig.mjs` | モーション用リグの生成（`UAL_GLTF=… npm run assets`） |
| `scripts/optimize-vrm.py` | VRM のテクスチャ縮小・WebP 化 |
| `scripts/render-portraits.cjs` | 顔アイコンの書き出し（`npm run portraits -- <URL>`） |

素材のライセンスは [CREDITS.md](CREDITS.md) を参照。

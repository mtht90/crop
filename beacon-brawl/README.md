# BEACON BRAWL

ブラウザで遊べる **3 vs 3 の 3D 対戦アクション**。拠点争奪・デスマッチなど4つのモードで戦う。
プレイヤー1人 + 味方AI 2人 vs 敵AI 3人。PC（キーボード+マウス）とスマホ（タッチ）の両方に対応。

## 遊び方

```bash
cd beacon-brawl
npm install
npm run dev      # 開発サーバー
npm run build    # dist/ に静的ファイルを出力（どこでもホスティング可）
```

| 操作 | PC | スマホ |
|---|---|---|
| 移動 | WASD / 矢印キー | 画面左側に指を置いて動かす（少し倒せば全速） |
| 通常攻撃 | マウスで狙って左クリック | 攻撃ボタン。タップで近くの敵へ自動照準、引っぱって離すと狙った方向へ |
| スキル1 / スキル2 | Q / E（押している間は予告、離すと発動） | ボタン（攻撃と同じくタップ/引っぱり） |
| 必殺技 | Space | ボタン（ゲージ満タンで発動） |

- 視点は斜め上から固定（ブロスタ風）。引っぱっている間は届く範囲が地面に出る。中心に戻して離すとキャンセル。
- 通常攻撃は弾数制。3発までためられ、時間で1発ずつ回復する。撃ちながらでも移動速度は落ちない。
- 必殺技のゲージは主に攻撃を当てると溜まる。

## ルール（4モード）

| モード | 勝利条件 |
|---|---|
| ドミネーション | 5つの拠点を奪い合い、3分後に多く持っていたチームの勝ち |
| デスマッチ | 先に12回倒したチームの勝ち（3分で決着しなければ撃破数） |
| コントロール | 中央の拠点を確保し続け、先に100%に達したチームの勝ち |
| クラッシュ | 復帰なしのラウンド戦。相手を全滅させると1本、3本先取 |

- **必殺技は2択**: キャラ選択で各ヒーロー2種類の必殺技から1つ選ぶ。ゲージは主に攻撃を当てると溜まる（拠点の確保や時間経過でも少し溜まる）。
- 倒されると 7 秒後に自陣から復帰（クラッシュを除く）。自陣の円の中では HP が急速回復する。

## ヒーロー

| 名前 | 役割 | 特徴 |
|---|---|---|
| ガルド | タンク | 盾でスタン、ダメージカット、味方回復の必殺技 |
| ボルガ | アタッカー | 大斧の範囲攻撃と自己強化 |
| ルミナ | サポート | 遠距離の爆発魔法と回復 |
| シェイド | スプリンター | 最速。突進と透明化で拠点を荒らす |
| ヴェイル | スナイパー | 最長射程。貫通弾と範囲制圧 |
| モルス | トリックスター | 鈍足・スタンで足止め、吸収で粘る |

キャラクターは VRM 形式（アニメ調）。`public/assets/vrm/` に VRM を置き、`src/heroes.ts` の `model` を書き換えれば、VRoid Studio で自作したキャラなどに差し替えられます（1試合に各ヒーロー1体ずつ登場し、選ばなかった5人が味方2人・敵3人に分かれます）。

ヒーローは `src/heroes.ts` にデータとして定義しているので、ステータス調整や追加はこのファイルだけでできます。

## 構成

| ファイル | 役割 |
|---|---|
| `src/main.ts` | 起動、画面遷移（タイトル / キャラ選択 / 対戦 / リザルト） |
| `src/game.ts` | 対戦ロジック（ユニット、拠点、弾、AI、カメラ） |
| `src/heroes.ts` | ヒーローとスキルの定義 |
| `src/stage.ts` | ステージの見た目（コード生成）と配置、当たり判定、経路探索（A*） |
| `src/assets.ts` | VRM 読み込み、モーション移植、武器の装着 |
| `src/weapons.ts` | 武器の形状（コード生成） |
| `src/fx.ts` / `src/audio.ts` | エフェクト / 効果音（合成） |
| `src/hud.ts` / `src/input.ts` | HUD / 入力 |
| `scripts/build-rig.mjs` | モーション用リグの生成（`UAL_GLTF=… npm run assets`） |
| `scripts/optimize-vrm.py` | VRM のテクスチャ縮小・WebP 化 |

素材のライセンスは [CREDITS.md](CREDITS.md) を参照。

# CORE EATER 喰核の狩人（プロトタイプ）

一人称視点でモンスターを狩るアクションシューター。魔導と機巧が溶け合う大陸ヴェルドランで、狩猟団〈喰核団〉の狩人として獣を狩り、
倒した獣の **魔核** を武器（喰銃）に喰わせて、その獣の性質を持った弾で戦う。

このプロトタイプには **1エリア（霧錆の沼沢ラスミア）＋ボス1体（骸鍛王グラウムドル）** と拠点（工房船アンヴィル号）が入っています。

## 起動

```bash
cd hunter
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ に静的ファイルを出力
```

PC のブラウザ（Chrome / Edge / Firefox）＋マウス・キーボードで遊びます。初回読み込みは約 45MB です。

| 操作 | キー |

| 喰わせる魔核の選択 | Q |
| 一時停止 | Esc |

## ゲームの中心

### 手応えのある戦闘
- 弾は実体弾（弾速・落下あり）。敵は骨に追従する当たり判定（弱点・胴・部位）を持ち、**弱点**（頭など）は 1.6〜2.6 倍。
- 被弾フラッシュ、ヒットマーカー（弱点は黄色、装甲/部位は青）、ダメージ数値、怯み、反動、画面揺れ。
- **部位破壊で敵の動きが変わる**
  - 坑殻蟹：背負ったトロッコを壊すと、地中に潜る奇襲と殻ごもりができなくなり、装甲も消える。
  - 骸弩兵：連弩を壊すと射撃できなくなり、突進してくる。
  - 霧刺蜂：毒針を壊すと刺されても毒にならない。
  - **骸鍛王**：槌頭を壊すと衝撃波が出なくなり攻撃範囲が縮む。胸甲を壊すと肋骨の奥が新たな弱点になるが、動きが速くなる。HP が減ると激昂して攻撃頻度が上がる。

### 独自要素「素材喰い」
倒した獣は魔核を落とす。E で拾い（ポーチは3つまで）、F で今持っている喰銃に喰わせると、一定数の特殊弾に変わる。

| 獣 | 魔核 → 弾 | 効果 |
|---|---|---|
| 錆牙狼 | 牙核 → 貫牙弾 | 3体まで貫通、装甲軽減を無視 |
| 坑殻蟹 | 殻核 → 跳殻弾 | 地形で跳ね返り、命中後は近くの敵の弱点へ跳弾 |
| 煤鼠 | 群核 → 群散弾 | 1発が3つに分かれる |
| 霧刺蜂 | 毒核 → 毒針弾 | 毒を重ねがけ（硬いボスに有効） |
| 沼織蜘蛛 | 糸核 → 粘糸弾 | 敵の移動・攻撃を遅くする（ボスのアニメも遅くなる） |
| 紅翼蝙蝠 | 血核 → 吸血弾 | 与ダメージの一部で回復 |
| 爆嚢花 | 爆核 → 爆炎弾 | 着弾で爆発、部位破壊力が高い |
| 骸弩兵 | 呪核 → 追尾呪弾 | 近くの弱点へ曲がって飛ぶ |

道中でどの獣を狩り、どの魔核をボス戦まで残すかで戦い方が変わります（例：爆核で槌頭を割る、毒核を重ねて削る、糸核で大技を遅らせる）。

### 1エリア探索 → ボス
沼沢を奥へ進むほど敵の組み合わせが変わり、最奥の炉跡（闘技場）に入るとボス戦が始まり、出口が閉じます。

### 控えめな成長（拠点：工房船）
- 素材で **新しい武器を解放**（喰砲ブロウバック）。
- 武器ごとの **改造**（威力・給弾・喰炉拡張、各3段階）。
- **炉の気まぐれ**：骸片1つでランダムな小強化を1つ付与（おまけ程度・上書き）。
- 狩猟失敗時は素材の半分だけ持ち帰る。セーブは localStorage。

## 構成

```
hunter/
  index.html / src/style.css   画面とHUD
  src/main.ts      画面遷移・ループ
  src/game.ts      狩猟（出現・拾得・魔核ポーチ・結果）
  src/world.ts     エリア生成（外部モデル配置・高さマップ・歩行範囲・静的バッチ）
  src/player.ts    一人称移動・回避・状態異常
  src/weapons.ts   一人称武器（外部アニメ）・射撃・装填・素材喰い
  src/combat.ts    弾・当たり判定・魔核弾の挙動・爆発
  src/creature.ts  生物の基底（アニメ・骨追従の当たり判定・部位・毒/鈍足）
  src/monsters.ts  通常モンスターのAI
  src/boss.ts      ボスのAI（技・部位破壊による変化・激昂）
  src/base.ts      拠点（解放・改造・図鑑・設定）
  src/data.ts      武器・魔核・モンスター・素材・改造のデータ
  public/assets/   外部素材（変換済み）
  tools/pipeline/  素材変換スクリプト（Blender bpy）
  tools/*.cjs      Playwright による自動プレイ/撮影用スクリプト
  CREDITS.md       使用素材の作者・ライセンス・URL
```

## 素材について
モデル・アニメーション・効果音・BGM・テクスチャはすべて外部素材です（CC-BY 3.0 / 4.0 が中心）。詳細は [CREDITS.md](CREDITS.md)。
弾の光・火花・衝撃波などのエフェクトも外部テクスチャ（スプライト）で描いています。

## 既知の制限（プロトタイプ）
- ボスには専用の死亡アニメーションが無いため、怯みアニメ＋爆散演出で代用しています。
- 地形の見た目の一部（小物の根や草）には当たり判定がありません。
- 推奨は専用GPU搭載のPC。内蔵GPUでは画質（影）を落とす設定が今後必要です。

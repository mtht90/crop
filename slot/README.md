# DOPAMINE 7 — Three.js パチスロ実機シミュレーター

ブラウザでパチスロ実機を再現した 3D ゲームです。
抽選は「内部抽選 → 引き込み制御」の 2 段で、レバー ON の瞬間に役が決まり、ストップボタンを押したタイミングから最大 4 コマの範囲で出目が決まります。
演出は「予告 → フリーズ → テンパイ → 告知ランプ → ボーナス」の多段構成で、音・端末振動・画面シェイク・ブルームが連動します。

## 起動

ES Modules と fetch を使うため、ローカル HTTP サーバー経由で開いてください (`file://` では動きません)。

```bash
cd slot
python3 -m http.server 8000      # もしくは: npx serve .
# → http://localhost:8000/
```

| URL パラメータ | 効果 |
|---|---|
| `?debug` | 起動時にチューニングパネル (lil-gui) を開く。`G` キーや ⚙ ボタンでも開閉できる |
| `?lite` | 背景ホールと隣台を省き、ピクセル比を 1 に固定する (低スペック端末向け) |
| `?zoom=0.6` | カメラをリール寄りにする (0〜1) |

ビルド工程も外部 CDN も使いません。依存物はすべて `assets/` に同梱しています。

## 操作

| 操作 | キーボード | マウス / タッチ |
|---|---|---|
| MAX BET | `B` / `Shift` | 筐体の MAX BET ボタン、画面下の BET |
| レバー | `Space` / `Enter` / `↑` | 赤いレバー玉、START |
| 停止 (左・中・右) | `←` `↓` `→` / `1` `2` `3` / `Z` `X` `C` | 筐体のストップボタン、画面下の 1 2 3 |

- 自動ベットは標準でオンです。メダルが尽きると 500 枚を自動で貸し出します (フリープレイ)。
- 1 ゲームは最短 4.1 秒です (実機と同じウェイト)。
- 持ちメダルと履歴は localStorage に保存されます。

## 遊び方 (演出の読み方)

| 演出 | 意味 |
|---|---|
| 液晶「?」(青フラッシュ) | 弱予告 |
| 液晶「CHANCE!」+ 黄色ストライプ、ストップボタンが黄色 | 中予告 (チェリー・スイカ・ボーナスに期待) |
| 液晶「激アツ!!」+ 炎 + 画面シェイク、ストップボタンが赤 | 強予告 (ボーナス期待度が大きく上がる) |
| ストップボタンが虹色 | ボーナス確定 |
| **フリーズ** (暗転 → ガラス割れ → 逆回転 → 7 揃い) | ボーナス確定 (主に BIG) |
| **7 テンパイ** (REACH!) | ボーナス確定のリーチ目。ボーナス非成立のゲームでは制御が 7 のテンパイを必ず避ける |
| **DOPA! ランプ点灯** | ボーナス確定。告知はレバー ON・第 3 停止・次ゲームのレバー ON (遅れ告知) のどれか |
| 告知後 | 「7を狙え!!」。目押しアシストがオンのときは 7 が自動で引き込まれる |

## 抽選と制御の仕組み

1. **内部抽選** (`SlotLogic.draw`): レバー ON の時点で、設定 1〜6 の確率表 (`CONFIG.probability`) からフラグを 1 つ引きます。
   `CHERRY+BIG` のような重複当選もあります。成立したボーナスは揃うまで持ち越され、持ち越し中はボーナスを抽選し直しません。
2. **引き込み制御** (`SlotLogic.decideStop`): ボタンを押した位置から 0〜`maxSlip` コマ滑らせた候補のうち、次の優先順位で最良の 1 つを選びます。
   1. 非成立役を揃えない (蹴飛ばし)
   2. ボーナス非成立なら 7 のテンパイを避ける
   3. 成立小役を引き込む
   4. 成立ボーナスを引き込む
   5. ボーナス成立時はテンパイ形を優先する
   6. 滑りを少なくする
   残りのリールは「ランダムな押し順・タイミングで、同じ制御が働く」と仮定した期待値で評価します。
   全 9,261 出目の役判定は前計算し、フラグごとにメモ化しています。
3. 演出の抽選 (`Director.plan`) は成立フラグを見て、`CONFIG.effects` の重みテーブルから選びます。

### 検証結果 (`node tools/simulate.mjs 200000 0.5`)

ボーナス成立中に 50% の確率で 7 を狙い、それ以外はランダムに押した場合の結果です。

| 設定 | 機械割 | BIG | REG | 制御破綻 | 非成立テンパイ |
|---|---|---|---|---|---|
| 1 | 約 94% | 1/256 | 1/483 | 0 | 0 |
| 4 | 約 102% | 1/235 | 1/364 | 0 | 0 |
| 6 | 約 113% | 1/203 | 1/271 | 0 | 0 |

引き込み率は、ベル・リプレイ・ボーナス中ベルが順押しで 100%、チェリーが約 90%、スイカが約 44% です (スイカは狙わないと取りこぼします)。

## 磨き込みのポイント

- **確率と配当**: `CONFIG.probability` (設定ごとの分母)、`CONFIG.roles`、`CONFIG.bonus`。変更後は `node tools/simulate.mjs` で機械割を確認してください。
- **リール配列**: `CONFIG.reels.strips` (21 コマ、文字 = 図柄キー)。`simulate.mjs` の「制御破綻 0」を保ったまま変更してください。
- **演出の頻度**: `CONFIG.effects.yokoku` (フラグ別の予告の重み)、`freeze`、`notice`。
- **体感**: `CONFIG.reels.bounce` / `bounceMs` (停止時のバウンド)、`effects.shake`、`effects.vibrate` (振動パターン)、`effects.bloom`。
- **素材の差し替え**: `CONFIG.assets.*` のパスを書き換えるだけです。`symbolSkin: 'pixel'` にするとドット絵の図柄になります。
- ゲーム中に `G` キーでチューニングパネルを開くと、次ゲームのフラグを強制したり、フリーズや予告を強制したりして演出だけを確認できます。

## 動作環境

- WebGL2 に対応した最新ブラウザ (Chrome / Edge / Safari / Firefox)
- 端末振動は `navigator.vibrate` に対応した端末 (主に Android Chrome) で動きます。iOS は非対応なので、画面シェイクとフラッシュだけで表現します。

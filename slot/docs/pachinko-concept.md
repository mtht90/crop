# パチンコ (切り替え式) 構想メモ

いまの SLOT と同じページで、ホールの「島」を切り替えるように パチスロ ⇄ パチンコ を選べるようにする。
まだ実装はしていない。決めることは末尾の「相談事項」にまとめた。

## 1. 切り替えの形

- 起動画面とヘッダーに「スロット / パチンコ」の切り替えを置く。カメラが隣の島へ横移動して台が入れ替わる。
- 所持金 (財布) は共通。持ち玉・持ちメダルは台ごとで、切り替える前に換金するか、そのまま保持するかを選ぶ。
- 1 日の流れ (所持金 3 万円 → 貸し玉 → 換金して終了・戦績) と、隠し設定・データカウンター・隣台の当たりはそのまま共通部品にする。

## 2. コードの分け方

| 共通 (今のものを流用) | パチンコ専用 (新規) |
|---|---|
| `audio.js` `fx.js` (振動・シェイク・メダル物理) | `pachinko/board.js` 盤面・釘・役物・アタッカーの 3D |
| `assets.js` ローダー、HDRI、ホール、隣台 | `pachinko/balls.js` 玉の物理 (盤面の平面上の 2D 剛体) |
| `screen.js` の描画基盤 (液晶 Canvas) | `pachinko/logic.js` 大当たり抽選・保留・確変/時短の状態遷移 |
| お金 (`machine.js` の財布・換金・戦績) | `pachinko/director.js` 変動・リーチ・予告・ラウンド演出 |
| `CONFIG` の形 (確率・演出・素材パスを 1 か所に) | `CONFIG.pachinko` 一式 |

`main.js` は「台 (Machine + Cabinet + Director) を差し替えられる」形に整理し、スロットとパチンコが同じインターフェイス
(`start / input / update / serialize`) を持つようにする。

## 3. 抽選と状態 (実機のよくある形)

- 4 円パチンコ: 1000 円 = 250 玉。換金は 1 玉 4 円 (等価) か 3.57 円など非等価を選べるようにする。
- スペック案 (要相談): ライトミドル 1/199 か、甘デジ 1/99。
  - 大当たり後は「確変 (ST) 何回転」または「時短」。突入率・継続率・ラウンド振り分けを CONFIG で持つ。
- ヘソ (スタートチャッカー) に入ると抽選。保留は最大 4 個。電チュー (時短・確変中に開く) 保留も別に 4 個。
- 抽選は入賞の瞬間に済ませ、結果を保留に積む (スロットの「レバー ON で内部抽選」と同じ考え方)。
- 大当たり: アタッカーが開き、1 ラウンド 10 個入賞 or 約 30 秒で閉じる。ラウンド数で出玉が変わる。

## 4. 玉の物理

- 玉は盤面 (傾いたガラスの内側の平面) 上の 2D 剛体として計算し、表示は 3D の銀玉。
- 釘・風車・ワープ・ステージ・ヘソ・アタッカーは当たり判定付きの形として置く。
- ライブラリ: 物理は自作の簡易ソルバか、MIT ライセンスの物理エンジン (例: matter.js / Rapier) を同梱する。
- 発射: 右下のハンドル。PC はマウスホイールかキーで強さ、スマホは右下の回転ハンドル (つまみをなぞる) で強さを決める。
  左打ち・右打ち (確変中) の打ち分けを入れる。
- 釘の配置で「ヘソに入る率 (回転率)」が決まる。千円あたりの回転数がデータカウンターに出て、台の良し悪しを推測できる (スロットの設定推測に当たる部分)。

## 5. 液晶の演出 (パチンコの見せ場)

- 図柄変動: 3 列の数字図柄 (1〜9)。停止順は 左 → 右 → 中。左右がそろうと「リーチ」。
- 予告: 保留変化 (青 → 緑 → 赤 → 金 → 虹)、群予告、ステップアップ予告、カットイン、擬似連 (最大 4 連)。
- リーチの格: ノーマル → SP リーチ → SPSP リーチ → 全回転。期待度は CONFIG で重み付けする (スロットの予告と同じ作り)。
- 役物ギミック: 盤面上部の役物が落ちてくる・光る。手元の PUSH ボタン (振動と連動)。
- 大当たり中: ラウンド表示、獲得玉数、確変突入の「昇格演出」、確変中は専用ステージと BGM。
- キャラクター: 今のピエロ (Openclipart / CC0) を流用するか、新しい外部素材を探す。

## 6. 素材 (すべて商用可・出典を CREDITS.md に記録)

- 盤面の木目・釘・銀玉: ambientCG / Poly Haven の PBR 素材 + 自作ジオメトリ。
- 効果音: 玉の発射・釘に当たる音・入賞音・アタッカー開放音 (Kenney など CC0 から選ぶ)。
- BGM: 通常・確変・大当たりで別の CC0 曲。

## 7. 進め方の案

1. 台の差し替えができるよう `main.js` を整理 (スロットの動作は変えない)。
2. 盤面と玉の物理だけを作る (演出なしで、玉が釘に当たってヘソに入る)。
3. 抽選・保留・確変/時短・アタッカーをつなぐ。シミュレーターで出玉率を検証する (`tools/simulate-pachinko.mjs`)。
4. 液晶の変動・リーチ・予告を作る。
5. 切り替え UI と、ホールの島の移動演出。

## 相談事項

- スペック: 甘デジ (1/99) / ライトミドル (1/199) / ミドル (1/319) のどれか。
- 確変の形: ST (回数切り) / ループ / 時短付き。
- 世界観: 今のピエロ・サーカスで揃えるか、別のテーマにするか。
- 換金レート: 等価 (4 円) か非等価か。
- 玉の物理の細かさ (スマホでの重さとの兼ね合い)。

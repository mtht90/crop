# 液晶 AT 機 計画書 (相談しながら更新)

パチンコは廃止し、スロットに一本化した。
ジャグラー型 (今の台) は素朴なまま磨き、派手な演出と作り込んだ筐体は新しい液晶 AT 機で思い切りやる。
島で 2 台を選べるようにする。

## 決まったこと

| 項目 | 内容 |
|---|---|
| 位置づけ | 新しい液晶 AT 機。ジャグラー型と同じ島に並べて選ぶ |
| 世界観 | ダークヒーロー・バトル (紫と赤のクリスタル、騎士・ドラゴン・魔物と戦う) |
| スペック | 王道の 6.5 号機風。CZ (チャンスゾーン) → バトルに勝てば AT。AT は 1G 約 3 枚増え、上乗せあり、天井あり。初当たり約 1/300、最大約 2400 枚 |
| 筐体・画面 | 大型液晶が主役。リールの上に筐体幅いっぱいの大液晶、周りに光る役物と横の LED。座った目線で液晶が画面の大半を占める |
| 欲しい演出 | 大きな液晶でのリーチ・バトル (ステップアップ、激アツの赤・金の帯)、光と音の爆発 (筐体全体の LED が虹色、キュイン音、揺れ、振動)、PUSH ボタン |
| PUSH ボタン | 激アツ時にボタンが飛び出して大きくなる。押し音・質感は外部素材を使う |
| 素材 | 外部素材を使う。キャラは Quaternius の CC0 パック (騎士・モンスター・ドラゴン、アニメーション付き) が候補 |
| 機種名 | DARKNIGHT |
| 敵 | コウモリ・スライム・スケルトン・ドラゴンの 4 体 (強さで期待度) |
| CZ・AT | CZ「DARK GATE」10G → バトル 3G → AT「DARKNIGHT RUSH」33G+。上乗せ特化「LIMIT BREAK」5G。天井 800G、上限 2400 枚 |
| 背景 | 4 種類で内部モード (A/B/C/天国) を示唆 |
| 台の移動 | 島は後日。いまは右上の「⇄」ボタン |

3. 大型液晶の舞台 (3D キャラのバトル、カメラワーク) と予告の階層
4. 筐体 (大液晶、光る役物、LED、飛び出す PUSH ボタン)
5. 光と音の爆発、振動
6. 島での台選び

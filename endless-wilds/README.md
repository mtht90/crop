# 果てなき荒野 — ENDLESS WILDS

ブラウザで遊べる **オープンワールド × ローグライク × サバイバーアクション** です。インストール不要。

- **移動するだけ、攻撃は自動。** 押し寄せる数百体の魔物をなぎ倒し、経験値の結晶を拾ってレベルアップ
- **区切りのない世界。** 6つの地域(草原・森・砂漠・雪原・焦土・虹晶の谷)が途切れずに続き、中心から離れるほど危険で実入りも大きい
- **毎回ちがうビルド。** 9つの武器・12のパッシブ・15の秘宝・8つの祝福から選び、条件を満たした武器は宝箱で **進化**
- **目的:** 世界に散らばる3つの **封印塔** を見つけ、守護者を倒して塔を壊す → **虚ろの王** を討て
- **持ち越し:** ゴールドで恒久強化、実績で冒険者と武器を解放

## 遊び方(開発用)

```bash
cd endless-wilds
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ に公開用ファイル(静的ファイルだけなので、どのホスティングでも動く)
```

## 設計の要点

| 判断 | 理由 |
|---|---|
| Three.js + 素のJS + Vite | ブラウザで3Dを最も軽く確実に動かせる。ビルド結果は静的ファイル1.2MBだけ |
| モデル・モーション・音をすべてコードで生成 | 下の「素材」を参照。ライセンス上の不安がゼロで、ダウンロードも一瞬 |
| 敵・弾・宝石はインスタンス描画 + 空間ハッシュ | 敵700体・弾数百発でも60fpsを保つため |
| 地形はチャンク単位で無限生成(同じ場所は同じ地形) | 区切りのないオープンワールドを、読み込み画面なしで実現 |
| 地形に当たり判定を持たせない | 木や岩に引っかかって囲まれる理不尽をなくし、爽快感を優先 |
| 爽快感の演出 | ヒットストップ・画面揺れ・白フラッシュ・ノックバック・ダメージ数字・連鎖爆発・拾うほど音階が上がる経験値音・コンボ・フィーバー |
| 中毒性の仕掛け | 早い序盤のレベルアップ、進化のヒント表示、宝箱演出、秘宝によるビルドの変化、地域の危険度による寄り道の駆け引き、結果画面の「次の目標」、恒久強化と実績解放 |
| 重い端末では自動で画質を下げる | スマホでも遊べるように |

## 構成

```
src/
  main.js            起動・入力・ゲームループ・画面の切り替え
  game/game.js       プレイヤー・敵・戦闘・拾得物・探索地点・ボス・難易度
  game/weapons.js    武器の挙動
  game/data.js       武器・パッシブ・秘宝・敵・恒久強化・実績のデータ
  world/world.js     無限ワールド(地域・景観・探索地点の生成)
  render/            描画(Three.js)と、コードで組み立てるローポリモデル
  fx/fx.js           パーティクル・衝撃波・ダメージ数字
  audio/audio.js     効果音とBGMの合成(Web Audio)
  ui/                画面・HUD・ミニマップ・方角マーカー
  meta/save.js       セーブ(localStorage)と実績判定
  fonts/             使用文字だけに絞ったフォント(scripts/subset-fonts.py で生成)
```

画面の文言を増やしたら `scripts/subset-fonts.py` を実行し直してください(フォントに無い文字は別のフォントで表示されます)。

# 3D釣り図鑑ゲーム 仕様書 & 実装計画（ドラフト v0.1）

> 仮タイトル：**Angler's Atlas（アングラーズ・アトラス）**
> ヒアリング結果をもとに作成。釣った魚を集める**図鑑がメイン**。魚種・サイズ・重さ・個体値・色違い・模様違いのやり込み要素を軸に、珍しい魚や大物を狙って釣り場を巡る。

---

## 1. 仕様書

### 1.1 基本
| 項目 | 決定内容 |
|---|---|
| ジャンル | 一人称 3D 釣りシミュレーション＋図鑑コレクション |
| プラットフォーム | Webブラウザ（PC） |
| 技術 | Three.js + TypeScript + Vite |
| 視点 | 一人称。釣り場を歩き、**釣り可能エリアで操作すると釣り専用画面にフォーカス**する |
| 釣りの方向性 | **リアル寄りシミュレーション**（タックル・水深・ルアー・ドラグが釣果に影響） |
| 素材 | **外部の無料素材を中心**に制作（ライセンス条件は問わないが `fishing/CREDITS.md` で出典を管理）。調達しにくいものはコード生成で補う |
| 保存 | localStorage に自動セーブ |
| 配置 | `mtht90/crop` の `fishing/` サブディレクトリ（既存のMinecraftプラグイン・格闘ゲームとビルド分離） |

### 1.2 釣り場
**基本4箇所＋将来の拡張エリア**。釣り場はマップ画面から選んで移動する。

| 釣り場 | 状態 | 主な魚 | 解放 |
|---|---|---|---|
| 湖（翠ヶ湖） | **MVP** | ブラックバス・コイ・ナマズ・トラウト類 等21種 | 最初から |
| 渓流 | 予定 | ヤマメ・イワナ・アユ 等 | 入漁券を購入 |
| 港・磯 | 予定 | クロダイ・メバル・アオリイカ 等 | 入漁券を購入 |
| 沖合（船） | 予定 | マグロ・カジキ・ブリ 等 | 乗船券を購入 |
| サンゴ礁 / 深海 / 熱帯河川 / 氷河湖 … | 拡張候補 | — | マップ上に「未開拓エリア」として表示 |

- 最終的な魚種は**100種以上**（1釣り場あたり20〜25種＋拡張エリア）。
- 釣り場内は**徒歩**で移動。岸辺・桟橋など**釣り可能エリア**に入ると `[F] 釣りをする` が表示され、押すと釣り専用画面（カメラ固定・釣りHUD）に切り替わる。

### 1.3 環境（出現条件）
| 要素 | 内容 |
|---|---|
| 時間帯 | ゲーム内時計（**現実1秒 = ゲーム内1分、1日 = 24分**）。朝マヅメ(4–7時) / 昼(7–16時) / 夕マヅメ(16–19時) / 夜(19–4時) |
| 天候 | 晴 / 曇 / 雨 / 嵐 / 霧。ゲーム内1時間ごとに季節別の遷移表で変化 |
| 季節 | 春・夏・秋・冬。**ゲーム内7日**で切り替わる |
| 水深（タナ） | 表層 / 中層 / 底層。ルアー・仕掛けの実際の水深から判定 |
| ポイント | 水草帯・岩場・流れ込み・桟橋・砂地の浅場・沖の深場。ルアー位置から判定 |

- 魚種ごとに各要素の倍率を持ち、**出現の重み = 基本レア度 × 時間 × 天候 × 季節 × タナ × ポイント × ルアー相性 × 動かし方の相性**。
- 全体の活性（アタリの頻度）も時間帯・天候・季節で変わる（マヅメ・曇雨は高活性）。
- 寝る / 休憩でゲーム内時間を進められる（釣り小屋で）。

### 1.4 タックル（道具）
竿・リール・ライン・ルアー/エサの**4カテゴリを組み合わせる**。

| カテゴリ | 主なパラメータ | 効果 |
|---|---|---|
| 竿 | 長さ/飛距離、パワー、クッション性、感度 | 飛距離、ライン切れの衝撃吸収、アタリの分かりやすさ・アワセの猶予 |
| リール | 最大ドラグ、巻き取り速度、巻き上げ力、糸巻量 | 大物とのやり取り、糸が出切るかどうか |
| ライン | 強度(lb)、見えにくさ、伸び | 切れにくさ、警戒心（アタリの頻度）、衝撃吸収 |
| ルアー/エサ | 種類（トップ/ミノー/クランク/スピナー/ワーム/ジグ/フロッグ/ミミズ/練りエサ/活き餌）、沈下速度、潜行深度、動かし方 | 狙えるタナ、魚種との相性 |

- ルアーはライン切れで**ロスト**。エサは消耗品（個数制）。
- エサ釣りは**ウキ下**（ウキなし=底 / 0.5〜5m）を切り替えてタナを狙える。ウキの沈み込みでもアタリが分かる。
- 竿＋リール＋ラインの組み合わせで「狙える魚の上限」が決まる（ライトタックルで大物は糸を出されて切られる）。

### 1.5 釣りの流れと操作
| 段階 | 操作 | 内容 |
|---|---|---|
| 移動 | WASD / マウス / Shift(走る) | 一人称で釣り場を歩く |
| 釣り開始 | F | 釣り可能エリアで釣り画面へ（F / Esc で戻る） |
| キャスト | 左クリック長押し→離す | 溜めるほど遠投。溜めすぎると狙いがブレる |
| 沈める | 待つ | ルアーの沈下速度に応じて沈む。**着底**は通知される |
| リトリーブ | 左クリック長押し | 巻き取り。ルアーは種類ごとの潜行深度へ |
| アクション | 右クリック | トゥイッチ / ポップ / シャクリ |
| アタリ → アワセ | 右クリック | 前アタリ（コツコツ）で合わせると失敗。本アタリ（竿先が大きく入る）の猶予時間内に合わせる |
| ファイト | 左長押し=巻く / マウス左右=竿を倒す / ホイール=ドラグ調整 | **テンション管理型**（下記） |
| 取り込み | 自動 | 魚が手前に来て弱っていればランディング |

#### ファイト（テンション管理）
- 魚は「走る / 粘る / 寄ってくる / ジャンプ」を繰り返す。引きの強さは**体重 × 魚種の引き係数 × 個体値（力）× 残りスタミナ**。
- **ラインテンション**がライン強度を超えると**ラインブレイク**。ドラグ値を超える引きには**糸が出ていく**（テンションはドラグ値で頭打ち）。
- ドラグを強くするほど寄せやすいが切られやすい。弱くするほど安全だが糸を出され、**糸巻量を使い切ると切られる**。
- 魚の走る向きと**逆側に竿を倒す**とスタミナを多く削れ、横走りも抑えられる。
- **テンションが抜けすぎる**（魚が寄ってくる・ジャンプ中のたるみ）と**フックアウト**。
- 竿のクッション性・ラインの伸びが急な突っ込み（衝撃）を吸収する。
- 底に張り付く魚（コイ・ナマズ類など）とのやり取りが長引くと**根ズレでラインが摩耗**し、強度が落ちる（フロロは強く、PEは弱い）。軽いタックルで大物を時間をかけて獲る戦法に上限を設ける。
- HUD：テンションゲージ（ライン強度とドラグ位置の目盛り付き）、ドラグ値、出ている糸の長さ/糸巻量、魚の勢い。

### 1.6 魚
#### 魚種
- **実在の魚が中心＋少数の伝説の魚**。図鑑には学名・解説（実在の生態トリビア）を載せる。
- MVP（湖）：実在20種＋伝説1種。

#### サイズ・重さ
- 体長は魚種ごとの分布（平均・標準偏差・最小・最大）から決定。
- 重さ = 魚種の肥満係数 × 体長³ × **体格（個体値）**による補正。同じ体長でも痩せ型・太型がある。

#### 個体値（IV）
4項目、各 **0〜31**。

| 項目 | 影響 |
|---|---|
| 力 | ファイト中の引きの強さ |
| 持久 | スタミナ（粘り） |
| 速さ | 走る速度 |
| 体格 | 体長に対する重さ（痩せ〜太り） |

- **グレード**：個体値の合計で S（≥105） / A（≥88） / B（≥62） / C（≥36） / D。S は約1%。
- 売値 = 基本価格 × 重さ補正 × グレード倍率 × 色・模様の倍率。

#### 色違い・模様違い
- 魚種ごとに**色違い 1〜3種**（アルビノ・黄金・黒化・青など、出現率 1/200〜1/1000）。
- 魚種ごとに**模様違い**（無斑・婚姻色・鏡ゴイ・錦など、出現率 1/50〜1/300）。
- **出現率アップ条件**：天候・時間帯・季節・ルアーで確率が上がる（例：霧の日はアルビノ×4、夜は黒化×3、春は婚姻色×5）。
- 釣り上げ画面で色違い・模様違いを演出付きで表示。

#### 伝説の魚
- **悪天候（嵐・霧）や夜などの悪条件で出やすくなるが、基本は超低確率**。
- 大物用のタックルが無いとまず獲れない（太いライン・大糸巻量・強いドラグ）。専用演出あり。

### 1.7 図鑑・記録（メイン要素）
- 魚種一覧（未発見はシルエット＋「？？？」、釣り場ごとのタブ）。
- 魚種ごとの記録：**最大体長・最大重量・最高グレード**、釣った回数、初めて釣った日時・場所・天候・時間帯・使用タックル。
- **色違い・模様のコンプリート表**（未発見は「？」）。
- 生息のヒント（よく釣れる時間帯・天候・季節・タナ・ポイント）は**釣ってから解放**。
- 3Dプレビュー（回転表示）。
- 達成率（種 / 色 / 模様）。

### 1.8 進行・経済
- 釣った魚は**クーラーボックスに保管**（容量制限あり、拡張可能）。釣り上げ時に**図鑑には即登録**。
- 釣り小屋で**売却**→お金→**タックル購入・クーラー拡張・新しい釣り場の入漁券**。
- **リリース**すると売値の一部が「放流協力金」として入る。
- 図鑑の達成報酬（登録種数・色違い発見数の節目で賞金）。

### 1.9 グラフィック・サウンド
- 地形・桟橋・小道具のテクスチャ/モデル：**Poly Haven（CC0）**などの外部無料素材。空は時間で変わる大気シェーダ、水面は反射・波紋付きの水シェーダ（three.js 同梱）。
- 天候演出：雨粒・霧・嵐の雷光と強風の波、曇天の光量低下。
- 魚：**体型ベースを共有＋テクスチャ（色・模様）差し替え**方式。数種類の体型（紡錘型・側偏型・細長型・ナマズ型・古代魚型…）をパラメータで作り、色と模様（縦縞・横帯・斑点・鏡鱗・錦…）をシェーダで描く。色違い・模様違いも同じ仕組み。外部の魚モデルが手に入ったら体型ごとに差し替えられる構造にする。
- サウンド：環境音（風・波・雨・虫）、SE（キャスト・着水・リール・ドラグ音・アタリ・ライン切れ・取り込み）、**釣り場ごとのBGM**。ファイト中は**音でも状況が分かる**（ドラグ音・リール音）。
  - MVPでは WebAudio によるコード生成音で実装し、外部音源を `public/audio/` に置けば差し替わる構造にする。

### 1.10 画面
タイトル → 釣り場（徒歩）⇔ 釣り画面 / 釣り小屋（売却・ショップ・休憩）/ 図鑑（Tab）/ マップ（M）/ タックル変更（I）/ 設定（Esc）

### 1.11 非機能
- 60fps目標（中程度のノートPC）。釣りシミュレーションは固定ステップ（60Hz）。
- 出現・個体値・ファイトのロジックは描画から分離し、**ユニットテスト**で確率と難易度を検証できるようにする。
- 魚種・タックル・釣り場は**データ駆動**（1ファイルに追記すれば増やせる）。

## 2. 実装計画

### ディレクトリ構成
```
fishing/
  index.html / package.json / vite.config.ts / tsconfig.json
  public/assets/{textures,models,audio}
  scripts/fetch-assets.sh     外部素材の取得スクリプト
  src/
    main.ts
    core/      ループ・入力・セーブ・乱数・ゲーム内時計/天候/季節
    data/      魚種・タックル・釣り場（データ駆動）
    sim/       出現判定・個体生成(サイズ/IV/色/模様)・アタリ・ファイト（描画非依存・テストあり）
    world/     湖の地形・水・空・植生・小屋・桟橋・天候演出・プレイヤー移動
    fishing/   釣りモード（キャスト・ルアー挙動・ライン/竿の描画・ファイトの見た目）
    render/    魚メッシュ生成（体型）＋色・模様シェーダ、プレビュー
    ui/        HUD・図鑑・ショップ・クーラー・釣果画面・マップ
    audio/     環境音・SE・BGM
```

### フェーズ
| フェーズ | 内容 | 完了条件 |
|---|---|---|
| P0 基盤 | Vite+TS+Three.js、テスト(Vitest)、CI | ビルド・テストがCIで通る |
| P1 湖と移動 | 地形・水・空・時間/天候/季節、一人称移動、釣り可能エリア | 湖を歩けて時間と天気が変わる |
| P2 釣りコア | キャスト・ルアー挙動・アタリ・アワセ・ファイト・取り込み | 魚が釣れる |
| P3 魚と図鑑 | 20種＋伝説、個体値・グレード・色/模様違い、図鑑・記録 | 図鑑が埋まっていく |
| P4 経済 | クーラー・売却・リリース・ショップ・セーブ | 稼いで道具を揃えるループ |
| P5 演出と音 | 天候演出、釣果演出、環境音/SE/BGM | **MVP完成** |
| P6 釣り場追加 | 渓流 → 港・磯 → 沖合（ボート）、各20〜25種 | 4釣り場・100種 |
| P7 拡張 | サンゴ礁・深海など拡張エリア、外部魚モデルへの差し替え、外部音源 | — |

### 進捗（MVP）
P0〜P5 を実装済み（湖1箇所・実在20種＋伝説1種）。

- 確率・難易度はテストで確認：初期装備で平均的なバスは9割以上獲れて1匹30秒前後、初期装備の80cmのコイは根ズレでほぼ切られる、伝説の魚は専用装備で獲れて平均75秒、Sグレードは約1%、色違いは条件で出現率が上がる、など（`tests/`）。
- 開発用：`lab.html`（全魚種・色/模様違いの見た目確認）、URLパラメータで時刻・天候・位置を指定して開始。

# SIGVerse コンビニ素材について

店舗什器・レジ・コーヒーマシン・コピー機・ATM・電子レンジ・買い物カゴ・一部テクスチャは
[SIGVerse/convenience-store-3d-models](https://github.com/SIGVerse/convenience-store-3d-models) を元にしています。

- This work is based on the SIGVerse project by Inamura's group at NII (National Institute of Informatics).
  本作品は、NII 稲邑グループによる SIGVerse プロジェクトの素材を元にした二次著作物です。
- 改変内容: Unity 形式（FBX / prefab / Mesh アセット）から glTF (GLB) へ変換し、テクスチャの縮小・メッシュ圧縮を行いました。
- 全体ライセンス: `../SIGVerse-LICENSE.txt`（英語） / `../SIGVerse-LICENSE.jp.txt`（日本語）
  商用利用には NII 稲邑氏の事前承諾が必要です。本プロジェクトは非商用（個人・趣味）で利用しています。

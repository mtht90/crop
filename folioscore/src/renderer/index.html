    楽譜の設定

    キーボードショートカット

    入力

    N
    音符入力モードの切替
    A〜G
    音名を入力（入力モード外でも選択位置から開始）
    Shift+A〜G
    直前の音に和音を追加
    1〜7
    音価: 1=64分 2=32分 3=16分 4=8分 5=4分 6=2分 7=全音符
    .
    付点
    0
    休符
    +
    タイ（入力中は同じ音をタイで追加）
    ↑ / ↓
    半音上げる / 下げる
    Ctrl+↑ / ↓
    オクターブ上げる / 下げる
    Backspace
    直前の入力を取り消し
    鍵盤クリック
    その音を入力（Shift で和音）
    MIDI 鍵盤
    接続すると自動で入力に使えます

    選択・編集

    クリック
    音符を選択（入力モードでは譜表上の位置に入力）
    ← / →
    前 / 次の音符
    Shift+← / →
    範囲選択
    Ctrl+← / →
    前 / 次の小節
    Alt+↑ / ↓
    上 / 下の譜表へ
    Delete
    休符にする
    Ctrl+C / X / V
    コピー / 切り取り / 貼り付け
    Ctrl+Z / Y
    元に戻す / やり直し
    Ctrl+B
    小節を末尾に追加
    Ctrl+Insert / Delete
    小節の挿入 / 削除
    Esc
    入力モード終了・選択解除

    再生・ファイル

    Space
    選択位置から再生 / 停止
    Home
    先頭へ
    Ctrl+S
    保存
    Ctrl+O
    開く
    Ctrl+N
    新規作成
    Ctrl+P
    PDF に書き出し
    Ctrl+T
    楽譜の設定
    F9
    ピアノ鍵盤の表示切替

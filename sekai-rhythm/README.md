# Sekai Rhythm

プロジェクトセカイ風のリズムゲーム（PC・キーボード6キー版）。
楽曲は YouTube の動画をそのまま再生し、それに合わせて譜面を作って遊びます。
Windows / macOS のデスクトップアプリ（Electron）として動き、ブラウザでも遊べます。

> 非商用の個人制作です。楽曲はダウンロードせず、YouTube の公式埋め込みプレイヤーで再生します。
> 埋め込みが許可されていない動画は再生できません（公式 MV の別アップロード等を指定してください）。

## 遊び方

| 操作 | キー（設定で変更可） |
| --- | --- |
| レーン（左から） | `S` `D` `F` `J` `K` `L` |
| フリック | レーンキーを押しながら `Space`（Space を先に押してもOK） |
| スライド | 始点でキーを押し、そのまま押し続ける。動いたら隣のキーに持ち替える |
| なぞり | 通過するときにそのレーンのキーを押していればOK |
| ポーズ | `Esc` |
| 全画面 | `F11` |

- 12レーンを2レーンずつ6キーに割り当てています。幅の広いノーツは、重なっているどのキーでも取れます。
- スライドは直線で動きます。中継点（◆）と半拍ごとにコンボが入ります。
- 判定幅はノーツの種類ごとに本家と同じ値です（60fps のフレーム数。下表）。GOOD 以下でコンボが切れます。
- スコア倍率は PERFECT 1 / GREAT 0.7 / GOOD 0.5。ライフはミスで −80（スライド中継点は −40）。
- ノーツスピードは本家と同じ 1.0〜12.0。音ズレは「設定 → タイミング調整」（自動計測あり）。

| ノーツ | PERFECT | GREAT | GOOD / BAD |
| --- | --- | --- | --- |
| タップ・スライド始点 | ±2.5F | ±5F | ±6.5F / ±7.5F |
| クリティカルタップ | ±3.3F | ±4.5F | ±6.5F / ±7.5F |
| フリック | ±2.5F（クリティカル ±3.5F） | −6.5F〜+7.5F | 〜−7.5F〜+8.5F |
| スライド終点 | −3.5F〜+4F | −6.5F〜+8F | 〜−7.5F〜+8.5F |
| なぞり | ±3.5F | | |

判定幅・スコア倍率・ライフ・中継点（半拍ごとのコンボ）の規則は、本家の挙動を再現した Sonolus 版エンジン（[sonolus-pjsekai-engine](https://github.com/NonSpicyBurrito/sonolus-pjsekai-engine)）のソースに合わせています。

## 譜面を作る（YouTube の曲）

1. 選曲画面の「＋ 新しい譜面」で曲名・YouTube URL・BPM を入れて作成
2. エディタ右側で BPM を確認（「BPM 計測」でクリックして測れます）
3. 再生して曲の最初の強拍で止め、「現在の位置を『拍0』にする」→ ±10ms で微調整
4. 左のツールでノーツを置く

| エディタの操作 | |
| --- | --- |
| `1`〜`6` | タップ / フリック / なぞり / スライド / 選択・移動 / 消しゴム |
| 左クリック | 配置（横ドラッグで幅指定） |
| 右クリック | 削除（スライド作成中は終点を置いて確定） |
| スライド | クリックで点を追加、Shift+クリックで見えない折れ点、Enter / 右クリックで確定 |
| `C` / `Q` `W` `E` / `[` `]` | クリティカル / フリック方向 / 幅 |
| ホイール・`↑` `↓`・`PageUp` `PageDown` | スクロール（`Ctrl`+ホイールでズーム） |
| `Space` | 再生・停止（ヒット音つき） |
| `P` | 現在位置からテストプレイ |
| `Ctrl+Z` / `Ctrl+Y` / `Ctrl+S` | 元に戻す / やり直し / 保存 |

## SUS の読み込みと 6 レーン変換

「読み込み」から `.sus`（プロセカの譜面で使われる Ched 系の形式）と、このアプリで書き出した `.json` を読み込めます。
SUS の解釈は Sonolus 版エンジンの変換処理を移植しているので、次のものも本家どおりに読み込みます。

- クリティカル / フリック（上・左上・右上）/ なぞり / トレースフリック
- スライドの中継点・不可視中継点・経路に沿う中継点（タップ種別3）・始点や終点のないスライド（種別7/8）・なぞり始点/終点
- ガイド（判定なしのライン, `#mmm9xy`）、拍子変化、`#MEASUREBS`、`#WAVEOFFSET`

ただし、カーブ指定は無視して直線スライドにします。ハイスピード変化（`#TIL`）は未対応です。

読み込むときに **12レーンのまま / 6レーンに変換 / 両方** を選べます。選曲画面の「6レーン版を作成」からも変換できます。

| 変換のしかた | |
| --- | --- |
| 位置 | ノーツの中心に近い 1 キーへ。境目ちょうどの場合は、直前のノーツと同じキーを避ける |
| 同時押し | 左右の並びを保って別々のキーに割り当てる。上限（2 / 3 / 制限なし）を超えたら、スライド > クリティカル > フリック > タップ > なぞり の順で残す。押しっぱなしのスライドも指 1 本と数える |
| 偽の連打 | 元の譜面では動いているのに同じキーに潰れる連打は、動いた方向の隣のキーへ逃がす（トリルがトリルのまま残る） |
| スライド | 元の経路がキーの境目をまたぐ瞬間に、1 キーずつ階段状に移動させる |
| 重なり | スライドで押さえているキーと重なるノーツは空いているキーへ移す。無理なら省く |
| 間引き | なし / やさしめ（8分より細かいノーツを省く）/ かんたん（4分より細かいノーツを省く） |

読み込み後は、エディタの右側で YouTube の URL とオフセットを設定してください。

## 内蔵デモ曲

内蔵曲はネット接続なしで遊べます。その場でシンセ演奏します。

- **Starlight Signal**（BPM 128）: NORMAL / HARD / EXPERT / MASTER
- **Neon Parade**（BPM 172）: HARD / EXPERT / MASTER

2曲とも楽譜として書いてあります（`src/music/song.ts`）。セクション構成・コード進行・メロディ・ドラムがあり、シンセはその楽譜どおりに演奏します。
譜面は同じ楽譜から、人が譜面を作るときの定石に沿って作っています（`src/charts/arranger.ts`、乱数なし）。そのため、すべてのノーツが実際に鳴っている音の上に来ます。

- 基本はメロディの音の頭に置き、音程の高低で左右に動かす。同じ音の連打は左右交互にする
- 伸ばす音はスライドにして次の音へ流す。フレーズの終わりはフリックで締める
- サビ頭はクリティカル。EXPERT 以上は外向きフリックの同時押しにする
- サビは片手でメロディ、もう片方の手でキック・スネアを取る。MASTER は 8分のハイハットも取る
- フィルは、HARD が階段、EXPERT が交互、MASTER が 16分の交互からなぞりへつなぐ形
- 最後は全幅のクリティカルフリック

テストでは、全ノーツが楽譜の音と一致すること、6 キー・両手で押せること、難易度順に密度が上がることを確認しています。

## 開発

```bash
npm install
npm run dev        # ブラウザで開発（http://localhost:5173）
npm test           # 判定・SUS読み込みなどのテスト
npm run app        # Electron で起動
npm run dist:win   # Windows 用インストーラ / ポータブル版を release/ に作成
```

GitHub Actions（`.github/workflows/build.yml`）が push のたびにテストし、Windows (.exe) と macOS (.dmg) のビルドを Artifacts に置きます。

### 構成

| パス | 内容 |
| --- | --- |
| `src/core/` | 譜面形式・BPM計算・SUS読み込み・6レーン変換・設定・保存 |
| `src/music/` | 内蔵曲の楽譜 |
| `src/charts/` | 楽譜から譜面を作るアレンジャー |
| `src/game/runtime.ts` | 譜面を判定用オブジェクトに変換（スライド中継・同時押しライン） |
| `src/game/engine.ts` | 判定エンジン（タップ / フリック / スライド / なぞり、スコア・ライフ） |
| `src/game/renderer.ts` | 描画（奥行きのあるレーン、ノーツ、エフェクト、HUD） |
| `src/game/game.ts` | プレイ画面（入力・音源との同期・ポーズ） |
| `src/audio/` | YouTube プレイヤー、内蔵シンセ曲、効果音 |
| `src/editor/` | 譜面エディタ |
| `electron/` | デスクトップアプリ（ローカルサーバーで配信、保存は userData/store/*.json） |

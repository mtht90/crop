# CREDITS

画面に出るグラフィック・音・フォントは、すべて下の素材から使います。
素材を組み込んだら、その都度ここに「素材名・作者・ライセンス・URL」を追記します。

## 使用中の素材

マイルストーン1の時点では、外部素材はまだ組み込んでいません（仮の図形と CSS のみ）。

# 百鬼祓い（Hyakki-Barai）— プロトタイプ

陰陽師になって百鬼夜行（妖怪の大群）に立ち向かうヴァンサバライク。
自分は動くだけ、攻撃は自動。レベルアップで「攻撃の術」か「式神召喚」を選び、**敵の物量に式神の数で対抗する**。

今回の目的は「操作して気持ちいいか」「式神を呼んで数をぶつけるのが楽しいか」の検証。

## 遊び方

ビルド不要。ES Modules を使っているので、`file://` ではなくローカルサーバ経由で開く。

```bash
cd hyakki
npx http-server -p 8000 -c-1 .     # または python3 -m http.server 8000
# → http://localhost:8000/
```

スマホで試す場合は同じLAN内で PC の IP（例 `http://192.168.x.x:8000/`）を開くか、GitHub Pages 等の静的ホスティングにこのフォルダを置く。

| 操作 | PC | スマホ |
|---|---|---|
| 移動 | WASD / 矢印キー | 画面のどこでもドラッグ（フローティングスティック） |
| 術を選ぶ | 1 / 2 / 3 キー or クリック | タップ |
| 一時停止 | Esc / P / 右上ボタン | 右上ボタン |

- **勝利**: 14:00（夜明け）まで生き残る、または 12:00 に現れるボス「酒呑童子」を倒す
- **敗北**: HP が 0

### デバッグ用 URL パラメータ

| パラメータ | 内容 |
|---|---|
| `?debug` | FPS・処理時間・各エンティティ数を表示 |
| `?t=600` | 開始時刻を指定（秒）。例: `?t=595` で本隊襲来直前、`?t=715` でボス直前 |
| `?lv=30` | ランダムに 30 回レベルアップした状態で開始 |
| `?god` | 無敵 |
| `?speed=4` | 時間を 4 倍速（最大8） |

例: `index.html?debug&t=715&lv=40&god` でボス戦を即確認。

## 決めたこと（判断メモ）

### 技術選定
- **素の JavaScript + Canvas 2D、ライブラリ・ビルド無し**。「遊べる状態に早く到達する」を最優先。依存ゼロなので `index.html` を置けばどこでも動く。
- 大量描画は事前に描いたスプライト（オフスクリーン Canvas）を `drawImage` するだけにして軽量化。影・発光もスプライトに焼き込み、`shadowBlur` 等の重い機能は不使用。
- 当たり判定は**一様グリッドの空間分割**（毎フレーム counting sort で再構築、型付き配列）。敵・式神・弾はすべて**オブジェクトプール**で GC を抑制。
- パーティクルは Structure-of-Arrays（Float32Array）で最大 2,600 個。
- 同時数の上限: 敵 1,500 / 式神 360 / 弾 800 / 経験値 700（超えた分は既存の魂に合算）。スマホ（`pointer: coarse`）では敵 1,100 などに自動で下げ、描画解像度も DPR 1.5 までに制限。
- 画面外に置き去りにした敵は進行方向の画面外へ再配置（本家と同じ方式）して、常に画面に敵がいる状態を保つ。
- 将来 WebGL（PixiJS 等）に移行する場合も、描画は `game.js` の `render()` に集約してあるので差し替えやすい。
- 効果音・BGM は WebAudio で合成（素材ファイル不要）。BGM は太鼓＋陰旋法のつま弾きで、百鬼夜行やボスでテンポが上がる。

### 召喚は「自動」にした
- 本家と同じ「移動だけ」の操作感を崩さない／スマホで追加ボタンを押させない、のが理由。
- 召喚系スキルはそれぞれクールダウンで自動召喚。召喚時に足元へ五芒星の魔法陣が開き「紙人形 ×12」のように数が表示される。
- 任意発動（必殺技的な一斉召喚ボタン）は、自動版が楽しいか確認した後の検討事項とした。

### 式神の「数で対抗」をどう表現したか
- **紙人形・前鬼は物理的な壁になる**：妖怪は式神を押し退けられず、接触している式神は削られていく。紙人形を大量に出すと群れを堰き止められる。
- 開始時から「護符（攻撃）」と「紙人形（召喚）」を所持し、最初の1分で式神の手応えが分かるようにした。
- レベルアップ時の抽選でも召喚系を少し出やすくしている（`PICK_WEIGHT`）。
- HUD に「式神 ○ / 妖 ○」を常時表示して、数のぶつかり合いを見える化。

### スキル一覧（各 Lv1〜6、補助は Lv1〜5）

**攻撃**
| 名前 | 内容 | 主な成長 |
|---|---|---|
| 護符 | 近い敵へ追尾する札 | 枚数・貫通・威力・連射 |
| 狐火 | 周囲を回る青い炎 | 個数・半径・威力 |
| 雷符 | 画面内の敵に落雷（範囲） | 落雷数・範囲・頻度 |
| 結界 | 足元の結界で継続ダメージ＋減速 | 範囲・威力・頻度 |
| 破魔矢 | 進行方向へ全貫通の矢 | 本数・威力・連射 |

**召喚（式神）** — 一定間隔で自動召喚、時間で消える
| 名前 | 役割 | 主な成長 |
|---|---|---|
| 紙人形 | 大量・脆い。群がって殴り、壁になる | 数 4→16、威力、持続、耐久 |
| 白狐 | 高速で敵陣を駆け抜け貫通ダメージ | 数 2→7、威力、持続 |
| 前鬼 | 重量級。叩きつけで範囲ダメージ＋吹き飛ばし、壁 | 数 1→3、威力、範囲、耐久 |
| 烏天狗 | プレイヤーの周囲を飛び羽を射る | 数 2→7、威力、連射 |

**補助**: 霊力（全威力）/ 式神強化（式神の威力・持続・召喚数）/ 速詠（間隔短縮）/ 韋駄天（移動速度）/ 吸魂（吸引範囲・経験値）/ 長命（最大HP・自然回復）

所持枠は 攻撃＋召喚で 6、補助で 4。取り尽くした後は「霊薬（全回復）」「大祓（画面一掃）」が出る。
具体的な数値はすべて `js/config.js` にある。

### 妖怪と流れ（約14分）
| 妖怪 | 特徴 |
|---|---|
| 鬼火 | 速い・脆い |
| 小鬼 | 基本の雑魚 |
| 一つ目小僧 | やや硬い |
| 唐傘お化け | 跳ねて素早く詰めてくる |
| がしゃどくろ | 硬い・重い |
| 赤鬼（エリート） | 70秒ごと。倒すと**宝箱**（所持スキルが1〜3段階上がる） |
| 酒呑童子（ボス） | 12:00 出現。突進（予告線あり）・火球の弾幕・手下召喚 |

- 通常湧きは時間とともに 2体/秒 → 55体/秒 まで増加。敵HPも時間で増える。
- 2:30 / 6:30 などに**包囲**（円形に取り囲む）
- 4:30「百鬼夜行 ─ 先触れ」、8:00「百鬼夜行」、10:00〜「百鬼夜行 ─ 本隊襲来」：**妖怪の行列が画面を横切る大群ウェーブ**
- 12:00 ボス、14:00 夜明けで勝利

### 気持ちよさの演出（ドーパミン要素）
- 被弾時の白フラッシュ・ノックバック、会心の大きな金色ダメージ数字
- 撃破時のパーティクル、経験値（人魂）が吸い込まれる際に**連続取得で音程が上がる**
- 「○○ 連祓」の連続撃破カウンター（数が増えるほど文字が大きくなる）、100/300/500/1000…体の撃破マイルストーン
- レベルアップ時：霊波で周囲の敵を吹き飛ばし、魔法陣＋光輪＋ファンファーレ、カードが弾けて登場（式神カードは光が周回）
- 落雷・前鬼の叩きつけ・エリート撃破での画面揺れ／ヒットストップ／スローモーション
- レアドロップ：おにぎり（回復）、勾玉（画面中の魂を全回収）、浄の札（画面の敵を一掃）
- 大群ウェーブ・ボス出現時の警告バナー、太鼓、赤いパルス
- ボス撃破・夜明けで全画面の敵が一斉に弾け飛ぶ勝利演出

## ファイル構成

```
hyakki/
├── index.html        画面（HUD・カード・各画面の DOM）
├── css/style.css     UI のスタイル・アニメーション
└── js/
    ├── main.js       起動・メインループ・画面遷移・デバッグパラメータ
    ├── config.js     ★ バランス調整用の数値すべて（敵・スキル・湧き・イベント）
    ├── game.js       ゲーム状態・更新・描画・出現管理・ボスAI
    ├── skills.js     攻撃スキルと式神の行動
    ├── grid.js       空間分割グリッド
    ├── fx.js         パーティクル・リング・落雷・魔法陣・ダメージ数字
    ├── sprites.js    仮スプライトの生成と外部素材での差し替え
    ├── input.js      キーボード＋仮想スティック
    ├── audio.js      効果音・BGM（WebAudio 合成）
    └── ui.js         HUD・レベルアップカード・バナー
```

## 外部素材への差し替え

いまのキャラクターは全て Canvas で描いた仮絵。`js/config.js` の `ASSETS` に画像パスを書くと差し替わる。

```js
export const ASSETS = {
  kooni: 'assets/kooni.png',
  player: 'assets/onmyoji.png',
};
```

- 名前: `player` / 妖怪 `onibi kooni hitotsume karakasa gashadokuro oni shuten` / 式神 `kami byakko zenki karasu` / 弾 `ofuda arrow feather foxfire fireball` / アイテム `gem0〜3 heal magnet bomb chest` / 魔法陣 `seal sealBlue sealRed`
- 画像は各スプライトの枠（`sprites.js` の `make(name, w, h, …)`）に縦横比を保って収まる。透過 PNG・正面向きを想定。
- 現状は1枚絵（アニメは伸縮のみ）。スプライトシートのアニメ対応は素材確定後に追加予定。

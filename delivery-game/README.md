# あおば町 宅配日誌

宅配会社の新人ドライバーとして、小さな街「あおば町」で荷物を届ける仕事シミュレーションゲームです。
運転そのものより、**荷物の積み方・回る順番・不在時の判断**といった「段取り」を楽しむことを中心にしています。

## 遊び方

ブラウザで `index.html` を開くだけで遊べます（ビルド不要・外部ライブラリなし）。

```bash
# ローカルサーバーで開く場合（推奨）
cd delivery-game
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

- 進行状況はブラウザの localStorage に自動保存されます（タイトル画面の「続きから」）。
- 効果音は OGG 形式です。Safari では鳴らないことがあります（ゲームは問題なく遊べます）。

## 1日の流れ

| 手順 | 内容 |
|---|---|
| 朝礼 | 天気、道路工事（終日通行止め）、渋滞しやすい時間帯の連絡 |
| 1. 荷物確認 | 伝票を1枚ずつ確認。宛先・時間指定・サイズ・取扱注意・置き配の可否を見る。**担当エリア外（わかば町）の荷物**が1個混ざっているので仕分けに戻す |
| 2. 積み込み | 荷台は6列×3段。**扉側・上段ほど早く取り出せる**。ワレモノの上に積まない／重量物は下段／クール便は保冷ボックスへ |
| 3. ルート計画 | 地図のピンをクリックして配達順を決める。到着予想と時間指定の◎・早着・遅れが一覧で分かる |
| 4. 配達 | 車が道路を走り、時間が進む。配達先で「取り出し → 小さな状況への対応 → 呼び鈴 → 手渡し／不在対応」 |
| 5. 結果 | 配達完了数・時間指定・誤配・破損・持ち戻り・残業から評価（S〜D）、給料と経験値 |
| 改善ショップ | 台車、車内の棚、手袋、保冷ボックス、地図アプリ、在宅お知らせサービス |

1手順〜3手順は、出発するまで上部のタブで自由に行き来できます（ルートを決めてから積むと、荷台に配達順の番号が出ます）。

### 配達先で起きること

- **在宅** → 手渡しでサイン。常連になるほど住民のセリフが変わる（結果画面「今日、町で聞いた言葉」に残る）
- **不在** → もう一度鳴らす／電話する／置き配（指定場所を選ぶ）／不在票を入れて持ち戻り
  - 不在票を入れると、あとで**再配達の電話**がかかってくることがある（ルートに自動で追加）
  - 置き配不可・クール便の置き配は規定違反、指定と違う場所は減点
- **小さな状況**：入口が分からない家、呼び鈴がない家、吠える犬、同じ苗字が並ぶ家（確認を怠ると誤配）、アパートの入口が2か所…
- **時間の出来事**：昼すぎに事故で新たな通行止め（走行中なら自動で迂回）、12時台・17時台の商店街の渋滞、朝の駅前通りの渋滞、19時から残業、21時で強制帰庫

## ファイル構成

```
delivery-game/
├── index.html
├── css/style.css
├── js/
│   ├── data.js   … 街・建物・住民（18人）・荷物の種類・改善アイテムなどのデータ
│   ├── map.js    … タイル地図の生成と描画、経路探索（左側通行を考慮したダイクストラ法）、似顔絵の合成
│   └── game.js   … ゲーム進行（各手順の画面、荷台、配達先イベント、評価、セーブ）
└── assets/       … 外部素材（下記）
```

住民・荷物・建物は `data.js` を書き換えるだけで追加できます。

## 相談したいポイント

1. **時間の密度**：今は1マス0.8分・定時19時。時間指定の待ち時間が長めに出ます。待ち時間を短くする（勤務時間を短く・荷物を増やす）か、待ち時間に別のこと（集荷・休憩）を入れるか。
2. **積み込みの細かさ**：今は「列×段」の簡易モデル。重さのバランスや、箱の向き（天地無用）をもっと細かく扱うか。
3. **難易度カーブ**：レベルごとに荷物が1個ずつ増えます（最大16個）。新しい区域や荷物の種類で変化をつけるか。
4. **運転の操作感**：今は「行き先を選ぶと自動で走る」方式。方向キーで運転する要素を入れるかどうか。

## 拡張アイデア

**仕事の幅を広げる**
- **集荷**：住民から「荷物を出したい」と電話が入り、伝票を書いて集荷する。帰り道のルートに組み込む判断
- **再配達の時間変更・営業所止め・コンビニ受け取り**：不在対応の選択肢を増やす
- **代引き・着払い**：おつりの準備、支払い方法の確認
- **大型家具・家電の2人作業**：先輩と一緒に回る日、設置まで行う日
- **年末・お中元シーズン**：荷物が一気に増える繁忙期イベント、臨時のアルバイトに指示を出す
- **天気**：雨の日は濡らさない工夫（ビニールカバー）、雪の日は道路の所要時間が増える

**街と人の物語**
- **住民の小さな物語**：常連になると続きが見える（大学生の山本さんが就職して引っ越す、鈴木家の子どもが小学生になる、花屋の新商品…）
- **季節の移り変わり**：春は桜通りに花、夏は打ち水、秋は落ち葉、冬はイルミネーション（タイルの差し替え）
- **お礼の品と手紙**：もらったみかんやパンが休憩時の回復になる／営業所の掲示板に住民からの手紙が貼られる
- **町の変化**：空き地に新しいマンションが建つ → 配達先が一気に増える、商店街の店が入れ替わる

**段取りと成長**
- **新しい区域**：わかば町（坂の多い住宅街）、駅前の商業地区（オフィスビル・受付）、郊外（距離が長い）
- **車のグレードアップ**：軽バン → 2tトラック（荷台が広いが細い道に入れない）
- **自転車・台車での配達**：車を停めて一帯をまとめて回る「拠点配達」
- **評価の記録**：日ごとの成績グラフ、称号（「時間指定の達人」「無事故100日」など）
- **後輩の指導**：経験を積むと新人に荷物確認や積み込みを任せられる
- **1日の振り返り**：走ったルートを地図上で再生し、もっと良い順番があったかを見られる

**素材面**
- BGM：OpenGameArt などの CC0 の落ち着いた曲を、朝・昼・夕方で切り替え
- 建物の種類を増やす：Kenney の同シリーズ（Roguelike Indoors など）で配達先の玄関まわりを描く

# 一人称3D 1対1格闘ゲーム 仕様書 & 実装計画（ドラフト v0.1）

> ヒアリング（Q1〜Q14）の回答をもとに作成。イメージ画像：浮遊島に囲まれた円形アリーナ、トゥーン調、観客席あり（背景のみ）。

---

## 1. 仕様書

### 1.1 基本
| 項目 | 決定内容 |
|---|---|
| ジャンル | 一人称視点 3D 1対1 対戦アクション（格闘＋射撃キャラ混在） |
| プラットフォーム | Webブラウザ（PC） |
| 技術 | Three.js + TypeScript + Vite |
| 対戦形式 | CPU対戦のみ（オンライン無し） |
| 操作 | マウス＋キーボード（Pointer Lock） |
| 配置 | `mtht90/crop` リポジトリの `game/` サブディレクトリ（既存のMinecraftプラグインとはビルド分離） |

### 1.2 試合ルール
- **2ラウンド先取**、各ラウンド **90秒**。
- ラウンド勝利条件：
  1. 相手のHPを0にする（KO）
  2. 相手を**場外に落とす**（リングアウト：Y座標が一定以下で即敗北）
  3. 時間切れ時は**残りHP割合**が多い方の勝ち（同率は引き分け→両者に1本 or 延長、要決定）
- ステージ：**円形アリーナ1つ**（壁なし・縁から落下可）。複雑なオブジェクトは置かない。浮遊島・観客・旗は**背景の飾り**のみ（当たり判定なし）。

### 1.3 共通アクション
| 操作 | キー | 内容 |
|---|---|---|
| 移動 | WASD | 地上移動 |
| 視点 | マウス | 一人称視点 |
| 通常攻撃 | 左クリック | キャラ固有武器の基本攻撃（近接 or 射撃） |
| ガード | 右クリック長押し | 被ダメージ・ノックバック軽減。ガード耐久あり（削り切られるとブレイク） |
| ジャンプ | Space | 空中攻撃あり |
| ダッシュ/回避 | Shift | 短距離高速移動＋短い無敵、スタミナ or CT制 |
| 固有スキル | E | キャラ固有、クールタイム制 |
| 必殺技 | Q | 与ダメ/被ダメで溜まるゲージ100%で発動 |
| ポーズ | Esc | ポーズメニュー |

### 1.4 ダメージ/吹っ飛び
- HP制（暫定 1000）。攻撃ごとに `damage` / `knockback`（方向・強さ）/ `hitstun` を持つ。
- 場外があるため**ノックバックが戦略の中心**。重い攻撃・必殺技は大きく吹き飛ばす。
- ガード中はダメージ80%軽減・ノックバック大幅軽減（数値は調整項目）。

### 1.5 キャラクター（全8体、各自固定の固有武器）
実装済みは ✅ の4体。剣・ショットガン・ブーメラン・杖は**保留**。

| # | 名前 | 武器 | 間合い | 通常 / ダッシュ攻撃 / 上昇技（空中Space） / スキル(E) / 必殺(Q) |
|---|---|---|---|---|
| ✅ | ブレイズ | 拳（ガントレット） | 近 | 3段コンボ・空中パンチ / ダッシュストレート / **ライジングアッパー** / ロケットストレート / 連打→アッパー |
| ✅ | スター | 二丁拳銃 | 中 | **右・左の2連射→少し間**（押しっぱなしでも連射し過ぎない）＋リロード / スライディング射撃 / なし / バック宙射撃 / 乱射→極太弾 |
| ✅ | アロー | 弓 | 遠 | **長押しで溜め撃ち**（重力で弧を描く矢） / 前転撃ち / なし / 3方向拡散矢 / 矢の雨→極太の矢 |
| ✅ | ピコ | ピコピコハンマー | 近 | 2連振り→叩きつけ（小衝撃波）・空中叩き落とし / ダッシュスイング / **ヘリコプター回転** / 地面叩き衝撃波 / 巨大化ハンマー |
| 保留 | — | 剣 / ショットガン / ブーメラン / 杖 | | |

#### 技の型（全キャラ共通の仕組み、各技はキャラごとに任意）
| 型 | 操作 | 内容 |
|---|---|---|
| 通常攻撃・コンボ | クリック | 段数・連射・溜めはキャラごと |
| 溜め攻撃 | クリック長押し→離す | 溜め時間に応じて威力・吹っ飛ばし・弾速・弾サイズが上がる（現在はアロー） |
| 空中攻撃 | 空中でクリック | 叩き落とし系は着地で終了 |
| ダッシュ攻撃 | ダッシュ中にクリック | ダッシュの勢いのまま攻撃 |
| 上昇技（復帰技） | 空中でSpace | 1回のジャンプにつき1回。被弾でリセット。**全キャラ必須ではない** |
| 範囲攻撃 | — | 自分中心の衝撃波（床にリングが出る） |
| 降り注ぐ弾 | — | 相手の頭上から降らせる（矢の雨） |

#### 場外と復帰
- 場外に飛ばされた場合も、一定時間後に操作が戻る（上昇技・ダッシュで戻れる）
- **ジャンプ中の反動は約1.7倍**：空中で床や浮島を撃つと大きく跳ね返る（ロケットジャンプ）
- **射撃の反動（遠距離キャラ）**：床・浮島・浮遊パッドなど**相手以外**に向けて撃つと、着弾点から押し返される（近いほど強い、上向きの反動は落下を打ち消す）。アリーナの縁の外側に小さな浮島が8つあり、これを撃って縁に戻れる。足元を撃てば小ジャンプにもなる。CPUも同じ方法で復帰する
- **ジャストガード**：攻撃が当たる10フレーム（約0.17秒）前までにガードを出すと成立。ダメージ0・ガード耐久回復・必殺ゲージ獲得、近距離（4.5m以内）の攻撃側は弾かれて少し吹き飛ぶ（必殺技などのアーマー中は弾かれない）。ガード連打で狙えないよう、ガードを離してから24フレーム以内の出し直しは対象外
- **タッチ操作**：タッチ端末では自動で仮想コントローラーに切り替え（ブロスタ風）。左側どこでも出現する移動スティック、右側ドラッグで視点、大きな攻撃ボタン（押したまま動かすと狙える／弓は離すと発射）、必殺（ゲージがボタンの縁に溜まる）・スキル（クールタイム表示）・ジャンプ・ダッシュ（残り回数表示）・ガード・リロード・ポーズ。縦持ちでは横向き推奨の案内を表示
- **視点補正（タップ操作のみ）**：全キャラ共通。相手が照準から約70°以内・32m以内なら視点を強く相手へ寄せる（攻撃中はほぼロックオン、視点ドラッグ中は弱める）。マウス操作では補正なし。ポーズ画面の設定でオフにできる
- 縁より少し下（約1.5m）までなら**縁に手をかけて登れる**。それより下は壁に当たり、Y=-14で場外負け

- キャラは**データ駆動**（1キャラ=1設定ファイル：HP、移動速度、攻撃定義、スキル、必殺技、モデル/アニメ参照）で追加できる構造にする。

### 1.6 CPU
- 難易度 **3段階**（かんたん / ふつう / むずかしい）。
- 差を付けるパラメータ：反応遅延、エイム誤差、ガード/回避率、スキル・必殺の使用判断、場外際の立ち回り（むずかしいは相手を縁に追い込む）。
- 構造：状態機械（接近 / 間合い維持 / 攻撃 / 防御 / 回避 / 縁から離脱）＋キャラごとの得意間合い。

### 1.7 カメラ・視認補助
- 一人称。画面下に**自キャラの武器/腕（ビューモデル）**を表示（画像の構図）。
- 相手は全身モデル＋アニメーション。
- **場外接近警告**：縁に近づくと画面端が赤く発光＋床に境界ライン。
- ※補助表示は**今後変更の可能性あり**（ミニマップ・敵方向矢印・ロックオンを後で追加できる余地を残す）。
- 被弾時の画面揺れ・吹っ飛ばし中の視点演出は酔いに配慮して控えめ（設定でOFF可）。

### 1.8 画面遷移
タイトル → キャラ選択（自分）→ 相手キャラ＆難易度選択 → 試合（ラウンド開始演出 / HUD）→ リザルト（再戦 / キャラ選択へ / タイトルへ）

HUD：両者HP、ラウンド取得数、タイマー、スキルCT、必殺ゲージ、弾数（射撃キャラ）、ガード耐久。

### 1.9 グラフィック・サウンド
- 3Dモデル/アニメ：**無料素材**（第一候補：Quaternius等のCC0。Mixamoは利用規約上リポジトリ同梱に注意）。トゥーン調のマテリアル＋アウトラインで画像の雰囲気に寄せる（詳細は1.11）。
- 素材は GLB に統一、アニメ名の命名規約を定めて差し替え可能に。
- サウンド：**無料素材（CC0優先）**でBGM（メニュー/試合）とSE（打撃・射撃・ガード・ダッシュ・KO・リングアウト・カウントダウン）をMVPから入れる。
- `game/CREDITS.md` で素材ライセンスを管理。

### 1.10 キャラクターアニメーション（重点項目）
**方針**：無料素材（Mixamo / Quaternius 等）を土台に、**コード側の補正で質を上げる**。テイストは**アニメ的に誇張**（溜め → 一瞬で振り抜く → 余韻）。自分の腕・武器（ビューモデル）と相手の全身は**同じくらい重視**する。

#### 攻撃モーションの3区間
すべての攻撃を「予備動作 → 攻撃判定 → 後隙」の3区間で定義し、アニメとヒット判定を同じタイムラインで同期させる。

| 区間 | 演出 |
|---|---|
| 予備動作 | 素材アニメを**スロー再生＋ポーズを強調**（大きく引く・沈む）。相手の予兆として読める長さを確保 |
| 攻撃判定 | **時間を圧縮して一瞬で振り抜く**。武器の軌跡、残像、モーションブラー風のスミア |
| 後隙 | 振り抜いた姿勢でわずかに止まってから戻る。次の行動へは短いブレンドでつなぐ |

#### プログラム補正（コード側で加える動き）
- **ヒットストップ**：命中時に攻撃側・被弾側を数フレーム停止（重い攻撃ほど長く）＋被弾側を小刻みに揺らす
- **再生速度カーブ**：区間ごとに再生速度を変えて「溜めと解放」を作る（データで調整可能）
- **スクワッシュ＆ストレッチ**：着地・ダッシュ開始・強打時に体を軽く伸縮
- **加算レイヤー**：被弾リアクション（上半身ののけぞり）、呼吸、移動時の傾き（リーン）を本体アニメに重ねる
- **IK**：足の接地、相手の方向への頭・上半身の向き
- **揺れもの**：髪・服の裾・ポニーテールに簡易スプリング
- **ブレンド**：アニメ同士の切り替えは短いクロスフェード（キャンセル時は数フレーム）

#### 自分の腕・武器（ビューモデル）
- 待機中の揺れ（呼吸・歩き/走りの上下）、視点を振ったときの遅れ（スウェイ）
- 攻撃：拳は左右交互の突き＋コンボ最終段の大振り、銃は反動・スライド・マズルフラッシュ・薬莢・**リロード**
- 回避：視点の素早い横ロール＋腕が流れる、ガード：腕を上げて構える、被弾：視点が揺れる
- 固有スキル/必殺技はビューモデル専用の大きめの演出（必要ならカメラ演出も）

#### 相手の全身
- 待機・歩き（8方向ブレンド）・走り・ジャンプ（踏切/上昇/頂点/落下/着地）・ダッシュ/回避
- 攻撃・スキル・必殺技（**予兆が読めること**を最優先）
- 被弾（弱/強/方向別）・**吹っ飛び（空中で回転）→ 受け身 or ダウン → 起き上がり**・ガード/ガードブレイク
- リングアウト時の落下、KO、勝利/敗北ポーズ

#### キャンセル仕様
- 攻撃中も**ほぼ常に回避・スキルでキャンセル可**（操作の反応を優先）
- 動きが途切れて見えないよう、キャンセル時は短いブレンド＋回避側の初動を強めにして違和感を消す
- キャンセルし放題にならないよう、回避はスタミナ/クールタイムで回数を制限する

#### 素材と工具
- 必要なアニメの一覧（**アニメリスト**）をキャラごとに作り、素材から集めてリターゲットする。足りないものは近いアニメの加工や加算レイヤーで補う
- 開発用の**アニメーションビューア**（デバッグ画面）を作る：単体再生、コマ送り、再生速度カーブ/ヒットボックスの表示、パラメータのライブ調整
- アニメ名は命名規約で統一し、後から手付けアニメに差し替えられるようにする

### 1.11 アートディレクション・エフェクト（参考：ARMS）
**方針**：ARMS（Nintendo Switch）の雰囲気とエフェクトを参考にする。ただし参考は「質感とテンポ」のみで、キャラデザイン・ロゴ・UI・音などの素材を真似たりそのまま使ったりはしない。キャラごとの「属性」は**設けない**（イメージカラーで色分けするだけ）。

#### 全体の雰囲気
- **明るいポップな配色**：高彩度、空は青く晴れた昼、影も暗くしすぎない
- **セル調シェーディング**：2〜3段の陰影＋太めのアウトライン、リムライト（輪郭の光）でキャラを背景から浮かせる
- **スポーツ大会の空気感**：スタジアム的なアリーナ、観客、旗やバナー、ラウンド開始・KO時の大きな文字演出と実況風アナウンス（素材があれば）
- 背景は彩度と情報量を抑え、キャラとエフェクトが一番目立つようにする

#### 打撃・命中エフェクト
- **コミック調のヒットスパーク**：星形・トゲ形の閃光、衝撃のリング、放射状の線
- 強さで段階を付ける（弱：小さな火花 → 強：大きな閃光＋衝撃波＋画面揺れ＋ヒットストップ長め）
- **ガード**：盾状の六角形バリアが光って割れそうに揺れる。ガードブレイクは大きく砕ける演出
- **決着の一撃**：スローモーション＋カメラ演出＋画面の一瞬のフラッシュ

#### 動きの軌跡
- 攻撃・弾・回避に**太い光の軌跡（トレイル）**。キャラのイメージカラーで色分け
- ダッシュ/回避：残像＋足元の砂煙・風の線、画面端に集中線

#### キャラのイメージカラー
軌跡・ヒットスパーク・オーラの色に使う（属性ではない）。ブレイズ＝赤橙、スター＝黄・水色、アロー＝緑、ピコ＝ピンク・黄。

#### 必殺技の演出
- 必殺ゲージ満タン時、ビューモデル（自分の腕・武器）がイメージカラーのオーラを纏う
- 発動時は画面の色調が一瞬変わり、エフェクトを大きく出す

#### UI
- 太く丸みのある書体、大きなHPバー、ポップな配色。ラウンド表示・カウントダウンは画面中央に大きく弾む動きで出す

### 1.12 非機能
- 60fps目標（中程度のノートPC）、ロジックは固定タイムステップ（60Hz）。
- 物理エンジンは使わず自前の簡易判定（カプセル/球、円形床判定）。
- 対象ブラウザ：最新 Chrome / Edge / Firefox。

## 3. 実装状況（v0.1 / ブランチ `game/mvp`）

### 仕様からの差分・仮対応（要確認）
1. **素材**：キャラは Quaternius の CC0 素体（女性・男性）に、ジャケット・パンツ・グローブ・銃・靴をコードで作って骨に取り付けています。無料版のアニメには横移動・後退・アッパー・二丁拳銃専用の動きがないため、腰のひねり・逆再生・既存アニメの組み合わせで補っています（詳細は `CREDITS.md`）。
8. **新キャラ4体の仕組み**
   - **カゲツ（日本刀）**：E＝居合の構え。構え中に攻撃を受けると無効化し、相手の背後へ瞬間移動して斬り返す（自分の視点も相手の方へ向き直る）。ダッシュ中クリック＝相手をすり抜けて背後へ抜ける斬り。空中Space＝燕返し（上昇斬り）。必殺＝月影一閃（踏み込み→連続斬り→大斬り）。
   - **ララ（ヨーヨー）**：通常攻撃はヨーヨーが照準方向に伸びて戻る（行きと帰りの2回判定、帰りは少し引き寄せる）。3段目は周囲を一周。E＝遠くまで伸ばして相手を手元へ引き寄せる。必殺＝巨大ヨーヨー。
   - **ジップ（グラップラー）**：**通常攻撃（地上・空中）＝吸盤フック**。紐を引いた吸盤が約15m飛び、地形（床・壁・浮島・パッド）に刺さるとそこへ飛ぶ（壁で止まると跳ね上がって登れる）。相手に刺さると相手めがけて飛んでいき、到着時に飛び膝蹴り（40ダメージ、ガード可）。フックの後は隙が大きい。E＝近距離のパンチ連打（ジャブ→ストレート→フック）。空中Space＝フック（復帰）。必殺＝相手を手元まで引き寄せてアッパー。刺さるたびに空中で撃てる回数が戻る。
   - **アメリ（傘）**：傘は OpenGameArt「Cute umbrella」（CC0）をキャラの色に染めて使用。**通常攻撃（長押し）＝傘を開く**：傘を前に向けて盾にし、移動は半分の速さ。中〜遠距離の弾だけを撃った相手へ跳ね返し（近接攻撃は防げない）、先端から弱い弾を一定間隔で撃つ。空中でも同じ（降下しながら撃てる）。傘には耐久値（HUDのゲージが紫で表示）があり、弾を跳ね返すと減って0で壊れ、5秒間開けない（その間のクリックは閉じた傘の突き、スキルと滑空も不可。よろけはしない）。**E＝中ジャンプ**：その場から約3.6m跳び、落下は傘でふわふわ降りる（約2秒、少しだけ位置調整可）。右クリックは通常のガード。空中Space＝上昇＋Space長押しで滑空。必殺＝傘を盾にしたまま先端から連射し、最後に強い一発。
   - アロー：溜め撃ちの最大溜めを0.6秒に短縮、最大溜めの矢はガードを大きく削る（1発で約半分）。ピコ：E（地面たたき）で前方3方向へ地面を走る衝撃波（約12m、当たると打ち上げ）。
   - CPU同士の総当たり（128試合）で調整。CPUの遠距離ロジックが単純なため、アローはCPU同士だと負け越しやすい（プレイヤー操作では別）。
7. **外部素材への置き換え**：エフェクトの画像（ヒットの閃光・火花・斬撃の弧・煙・破片・リング・ジャストガードの紋章・回転の渦）は Kenney Particle Pack、スターの銃は Kenney Blaster Kit（いずれもCC0）に置き換えた。コミック調の集中線・六角形バリア・軌跡はコードのまま。弓（弦を引く動きが必要）とピコピコハンマー（該当する素材がない）はコード製を継続。ファイルが読めない場合は従来のコード製表示に戻る。
2. **サウンド**：効果音は Kenney の CC0 素材（空振り・ダッシュ・ハンマーの「ピコッ」は合成音）。BGM は Juhani Junkala 氏の CC0 チップチューン。Safari 対応のため MP3 に変換。
6. **一人称の腕**：キャラ自身の素体モデルから前腕〜手〜指だけを切り出し、指を武器に合わせて曲げた本物の手を使う（銃・刀・傘は握り込み、弓は弦側を軽く開く）。ブレイズのみボクシンググローブ（親指・紐付きの形）。
11. **演出（カメラ・必殺技）**：必殺技の発動時は時間が一瞬ゆっくりになり（約0.6秒、通常の0.22倍から元に戻る）、カメラが使用者を正面斜め下から映す三人称ショットに切り替わってから一人称へ戻る（自分の必殺でも相手の必殺でも）。カットインは上下の黒帯（シネマ風）＋白い閃光＋細い暗色の帯に目元のアップと技名（キャラ名は小さく字間を空けて）。発動時に光の柱・地面のリング・衝撃のアニメーション。決着の一撃ではスロー中にカメラが吹っ飛ぶ相手を横から追う。
12. **小物と和装**：ピコとアメリはリボン、ジップはあごひげ（素体キットのCC0素材）、カゲツは帯。ヘアバンド・キャップ・ツインテール・鉢巻は見た目が不評のため外した（ララは元のロングヘアに戻した）。カゲツはレンジャーの上着を羽織、ペザントのズボンを袴に見立てた和装。衣装は2系統の部位を混ぜられる。
14. **新スキル**：ジップのE「テザー・スロー」は光る吸盤を撃ち、相手に吸着したら背後から頭上へ大きく振りかぶって前方へ投げ飛ばす（80ダメージ、投げ中はスーパーアーマー、クールタイム5秒）。外れ・ガードされたら不発。アメリのE「パラソル・ミサイル」は開いた傘を投げ、相手を追尾して当たる（72ダメージ）と跳ね返って素早く手元に戻る（投げてから約0.8秒）。戻るまで傘ガードと通常攻撃は使えない（以前のEの中ジャンプ→ふわふわ降下は、ジャンプ長押しの滑空で代用）。
15. **顔の描き分け**：無料版の素体キットは顔が男女1種ずつ（顔違いは有料版のみ）のため、体のテクスチャをキャラごとに複製して描き足す。肌の色（`look.skin` で色調補正）、瞳の色（虹彩だけ色替え）、そばかす・チーク・口紅・アイライン・ほくろ、傷（カゲツ）・絆創膏（ブレイズ）・鼻の絆創膏（ジップ）・迷彩ペイント（アロー）・星（スター）・ハート（ララ）、ひげの剃り跡を消す。
16. **アメリの傘ガード**：傘を開いたままの状態では弾を止めるだけ（傘が削れる）。開いてから約0.17秒以内に当たった弾だけジャストではね返す（必殺技中は常にはね返す）。
17. **ステージ**：配置と当たり判定は共通のまま見た目だけ切り替えるテーマ方式。「空中闘技場」（従来）と「夕桜の庭」（夕焼けの空・大きな月・朱の鳥居・石灯籠・桜の浮島と五重塔・舞う花びら・板張りと砂紋の土俵）。キャラ選択画面で選ぶと背景もその場で切り替わる。
18. **ドン（9人目・腕キャノン）**：改造した右腕の大砲（Kenney Blaster Kit の大口径ブラスター、CC0）から砲弾（Kenney Pirate Kit の砲丸、CC0）を撃つ。弾は重く山なりで、着弾（地形・相手・射程切れ）すると小爆発して周囲にも当たる。左クリック長押しでより重い弾を装填：重いほど遅く・落ちるのが早く（射程が短い）、そのぶん威力と爆発範囲が大きい（軽い弾は約28m、最大装填は約12m・爆発半径約1.9倍）。E は地面を叩いて周囲を爆破、空中 Space は真下に撃って爆風で上昇、ダッシュ攻撃はショルダータックル、必殺「フルバースト」は連射＋巨大砲弾。常時アーマーはなし（必殺中のみ）。重量級としてふっとびにくい（ノックバック1/1.25）。
19. **ステージ「海賊の入り江」**：Kenney Pirate Kit（CC0）の海賊船・帆船・難破船・小舟が眼下の海を周回し、浮島はヤシの木と砦、リングの外にマストと海賊旗・大砲・樽・木箱・宝箱。床は甲板の板張りにロープの縁と羅針盤。配置と当たり判定は他のステージと共通。
20. **トリック（10人目・デコイ）**：トランプを3枚ずつ投げる（長押しで連続）。E「ミラージュ」でその場に自分と同じHPの分身が現れ、相手へ歩み寄ってトランプを投げる。分身は殴られる・撃たれると本物と同じようにのけぞり（ヒット演出も同じ）、HPが尽きるか6秒経つと爆発して近くの相手にダメージ。本人は横へ跳んで約1.7秒ほぼ透明（名札も消える、攻撃で解除）。CPU は透明中は分身を本物だと思って狙う。必殺「ミラーハウス」は相手を4体の分身で囲み、分身がトランプを投げ続けたあと爆発（こちらは一撃で消える分身）。
21. **レイ（11人目・スナイパー）**：狙撃銃（Kenney Blaster Kit の長銃身・スコープ付き、CC0）。左クリック長押しでスコープ（画面ズーム＋照準、相手にも見える赤いレーザー）、ためるほど威力最大約2.3倍。装弾6発。E のマーカー弾が当たると5秒間、通常弾が相手へ曲がって追尾。空中 Space はブーツの噴射で上昇。必殺「デッドアイ」は追尾する重い弾3発。
22. **バランス調整（11人の総当たり×3回）**：勝率40〜61%に収束。主な調整：射撃の反動（ロケットジャンプ）は空中のみに（地上で撃つと自分が場外へ押し出されていた）、CPU のため撃ちを武器ごとに最適化（ドンは距離に合わせて装填、レイは短いスコープ）、スター弾数12→10・弾23、カゲツHP900・3段目72、ジップ膝30・HP880、アメリ先端弾14、ピコ打撃強化・HP1230、アローHP1180・矢56・間合い短め、ドンHP1200。
13. **傘の見た目**：キャンバスを8枚のパネルで2色の縞（キャラのメインカラーと白）に塗り分け、内側は明るい裏地、木の柄と金の口金・石突き（ここから弾が出る）。開くときに少し行き過ぎて戻る動きと回転をつけた。
10. **髪の黒いはみ出し**：髪の輪郭線を「拡大した黒い複製」で描いていたため、モデルの足元を中心に拡大されて頭の上に黒い髪のようにずれて見えていた。法線方向に押し出す輪郭線に変更して解消。
9. **外部素材（第3弾）**：衣装は全員 Quaternius「Modular Character Outfits - Fantasy」（CC0、素体と同じ骨格）。テクスチャを灰色化し、部位ごとにキャラの色で着色（アローはフード付きレンジャー、カゲツ・ジップはレンジャー、ほかはペザント）。衣装を着ると素体は頭・首・手だけを表示。日本刀は OpenGameArt「Katana」（pfunked、CC0：赤い柄巻・透かし鍔・反りのある刀身）、鞘は Clint Bellanger の CC0 素材。攻撃エフェクトに Cethiel の CC0 素材（刀身の軌跡のアニメーション、着弾の爆発・破片のアニメーション）を追加し、近接攻撃の振り始めに武器ごとの軌跡、命中時にアニメーションする衝撃を出す。
3. **時間切れで同率の場合**：引き分けとしてラウンドをやり直す実装にしました（未決定事項2、変更可）。
4. **一人称の酔い対策**：スターのバク転スキルは、自分視点ではカメラが一回転せず軽く上を向くだけにしています（相手から見ると全身で一回転）。
5. **HPと吹っ飛び**：HPが減るほど吹っ飛びが大きくなる補正（最大2.2倍）を入れています。

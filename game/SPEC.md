# 一人称3D 1対1格闘ゲーム 仕様書 & 実装計画（ドラフト v0.1）

> ヒアリング（Q1〜Q14）の回答をもとに作成。イメージ画像：浮遊島に囲まれた円形アリーナ、トゥーン調、観客席あり（背景のみ）。

---

## 1. 仕様書

### 1.1 基本
| 項目 | 決定内容 |
|---|---|
| ジャンル | 一人称視点 3D 1対1 対戦アクション（格闘＋射撃キャラ混在） |
| プラットフォーム | Webブラウザ（PC） |
| 技術 | Three.js + TypeScript + Vite |
| 対戦形式 | CPU対戦のみ（オンライン無し） |
| 操作 | マウス＋キーボード（Pointer Lock） |
| 配置 | `mtht90/crop` リポジトリの `game/` サブディレクトリ（既存のMinecraftプラグインとはビルド分離） |

### 1.2 試合ルール
- **2ラウンド先取**、各ラウンド **90秒**。
- ラウンド勝利条件：
  1. 相手のHPを0にする（KO）
  2. 相手を**場外に落とす**（リングアウト：Y座標が一定以下で即敗北）
  3. 時間切れ時は**残りHP割合**が多い方の勝ち（同率は引き分け→両者に1本 or 延長、要決定）
- ステージ：**円形アリーナ1つ**（壁なし・縁から落下可）。複雑なオブジェクトは置かない。浮遊島・観客・旗は**背景の飾り**のみ（当たり判定なし）。

### 1.3 共通アクション
| 操作 | キー | 内容 |
|---|---|---|
| 移動 | WASD | 地上移動 |
| 視点 | マウス | 一人称視点 |
| 通常攻撃 | 左クリック | キャラ固有武器の基本攻撃（近接 or 射撃） |
| ガード | 右クリック長押し | 被ダメージ・ノックバック軽減。ガード耐久あり（削り切られるとブレイク） |
| ジャンプ | Space | 空中攻撃あり |
| ダッシュ/回避 | Shift | 短距離高速移動＋短い無敵、スタミナ or CT制 |
| 固有スキル | E | キャラ固有、クールタイム制 |
| 必殺技 | Q | 与ダメ/被ダメで溜まるゲージ100%で発動 |
| ポーズ | Esc | ポーズメニュー |

### 1.4 ダメージ/吹っ飛び
- HP制（暫定 1000）。攻撃ごとに `damage` / `knockback`（方向・強さ）/ `hitstun` を持つ。
- 場外があるため**ノックバックが戦略の中心**。重い攻撃・必殺技は大きく吹き飛ばす。
- ガード中はダメージ80%軽減・ノックバック大幅軽減（数値は調整項目）。

### 1.5 キャラクター（全8体、各自固定の固有武器）
MVPは ★ の2体。残り6体は提案（要承認）。

| # | 仮名 | 武器 | 間合い | 特徴 / 固有スキル案 / 必殺技案 |
|---|---|---|---|---|
| ★1 | ブレイズ | 拳（ガントレット） | 近 | 3段コンボ。スキル：突進ストレート。必殺：連打→アッパーで大吹っ飛ばし |
| ★2 | スター | 二丁拳銃 | 中 | 左右交互連射、弾数＋リロード。スキル：バックステップ射撃。必殺：全方位乱射 |
| 3 | 剣士 | 剣 | 近〜中 | 横薙ぎで範囲広め。スキル：カウンター構え。必殺：回転斬り |
| 4 | 重戦士 | ハンマー | 近 | 遅いが吹っ飛ばし最大。スキル：地面叩き衝撃波。必殺：跳躍叩きつけ |
| 5 | 射手 | 弓 | 遠 | 溜め撃ちで威力/弾速上昇。スキル：3方向拡散矢。必殺：追尾矢の雨 |
| 6 | 砲手 | ショットガン | 近〜中 | 拡散弾、近いほど高威力・高ノックバック。スキル：反動ジャンプ |

- キャラは**データ駆動**（1キャラ=1設定ファイル：HP、移動速度、攻撃定義、スキル、必殺技、モデル/アニメ参照）で追加できる構造にする。

### 1.6 CPU
- 難易度 **3段階**（かんたん / ふつう / むずかしい）。
- 差を付けるパラメータ：反応遅延、エイム誤差、ガード/回避率、スキル・必殺の使用判断、場外際の立ち回り（むずかしいは相手を縁に追い込む）。
- 構造：状態機械（接近 / 間合い維持 / 攻撃 / 防御 / 回避 / 縁から離脱）＋キャラごとの得意間合い。

### 1.7 カメラ・視認補助
- 一人称。画面下に**自キャラの武器/腕（ビューモデル）**を表示（画像の構図）。
- 相手は全身モデル＋アニメーション。
- **場外接近警告**：縁に近づくと画面端が赤く発光＋床に境界ライン。
- ※補助表示は**今後変更の可能性あり**（ミニマップ・敵方向矢印・ロックオンを後で追加できる余地を残す）。
- 被弾時の画面揺れ・吹っ飛ばし中の視点演出は酔いに配慮して控えめ（設定でOFF可）。

### 1.8 画面遷移
タイトル → キャラ選択（自分）→ 相手キャラ＆難易度選択 → 試合（ラウンド開始演出 / HUD）→ リザルト（再戦 / キャラ選択へ / タイトルへ）

HUD：両者HP、ラウンド取得数、タイマー、スキルCT、必殺ゲージ、弾数（射撃キャラ）、ガード耐久。

### 1.9 グラフィック・サウンド
- 3Dモデル/アニメ：**無料素材**（第一候補：Quaternius等のCC0。Mixamoは利用規約上リポジトリ同梱に注意）。トゥーン調のマテリアル＋アウトラインで画像の雰囲気に寄せる（詳細は1.11）。
- 素材は GLB に統一、アニメ名の命名規約を定めて差し替え可能に。
- サウンド：**無料素材（CC0優先）**でBGM（メニュー/試合）とSE（打撃・射撃・ガード・ダッシュ・KO・リングアウト・カウントダウン）をMVPから入れる。
- `game/CREDITS.md` で素材ライセンスを管理。

### 1.10 キャラクターアニメーション（重点項目）
**方針**：無料素材（Mixamo / Quaternius 等）を土台に、**コード側の補正で質を上げる**。テイストは**アニメ的に誇張**（溜め → 一瞬で振り抜く → 余韻）。自分の腕・武器（ビューモデル）と相手の全身は**同じくらい重視**する。

#### 攻撃モーションの3区間
すべての攻撃を「予備動作 → 攻撃判定 → 後隙」の3区間で定義し、アニメとヒット判定を同じタイムラインで同期させる。

| 区間 | 演出 |
|---|---|
| 予備動作 | 素材アニメを**スロー再生＋ポーズを強調**（大きく引く・沈む）。相手の予兆として読める長さを確保 |
| 攻撃判定 | **時間を圧縮して一瞬で振り抜く**。武器の軌跡、残像、モーションブラー風のスミア |
| 後隙 | 振り抜いた姿勢でわずかに止まってから戻る。次の行動へは短いブレンドでつなぐ |

#### プログラム補正（コード側で加える動き）
- **ヒットストップ**：命中時に攻撃側・被弾側を数フレーム停止（重い攻撃ほど長く）＋被弾側を小刻みに揺らす
- **再生速度カーブ**：区間ごとに再生速度を変えて「溜めと解放」を作る（データで調整可能）
- **スクワッシュ＆ストレッチ**：着地・ダッシュ開始・強打時に体を軽く伸縮
- **加算レイヤー**：被弾リアクション（上半身ののけぞり）、呼吸、移動時の傾き（リーン）を本体アニメに重ねる
- **IK**：足の接地、相手の方向への頭・上半身の向き
- **揺れもの**：髪・服の裾・ポニーテールに簡易スプリング
- **ブレンド**：アニメ同士の切り替えは短いクロスフェード（キャンセル時は数フレーム）

#### 自分の腕・武器（ビューモデル）
- 待機中の揺れ（呼吸・歩き/走りの上下）、視点を振ったときの遅れ（スウェイ）
- 攻撃：拳は左右交互の突き＋コンボ最終段の大振り、銃は反動・スライド・マズルフラッシュ・薬莢・**リロード**
- 回避：視点の素早い横ロール＋腕が流れる、ガード：腕を上げて構える、被弾：視点が揺れる
- 固有スキル/必殺技はビューモデル専用の大きめの演出（必要ならカメラ演出も）

#### 相手の全身
- 待機・歩き（8方向ブレンド）・走り・ジャンプ（踏切/上昇/頂点/落下/着地）・ダッシュ/回避
- 攻撃・スキル・必殺技（**予兆が読めること**を最優先）
- 被弾（弱/強/方向別）・**吹っ飛び（空中で回転）→ 受け身 or ダウン → 起き上がり**・ガード/ガードブレイク
- リングアウト時の落下、KO、勝利/敗北ポーズ

#### キャンセル仕様
- 攻撃中も**ほぼ常に回避・スキルでキャンセル可**（操作の反応を優先）
- 動きが途切れて見えないよう、キャンセル時は短いブレンド＋回避側の初動を強めにして違和感を消す
- キャンセルし放題にならないよう、回避はスタミナ/クールタイムで回数を制限する

#### 素材と工具
- 必要なアニメの一覧（**アニメリスト**）をキャラごとに作り、素材から集めてリターゲットする。足りないものは近いアニメの加工や加算レイヤーで補う
- 開発用の**アニメーションビューア**（デバッグ画面）を作る：単体再生、コマ送り、再生速度カーブ/ヒットボックスの表示、パラメータのライブ調整
- アニメ名は命名規約で統一し、後から手付けアニメに差し替えられるようにする

### 1.11 アートディレクション・エフェクト（参考：ARMS）
**方針**：ARMS（Nintendo Switch）の雰囲気とエフェクトを参考にする。ただし参考は「質感とテンポ」のみで、キャラデザイン・ロゴ・UI・音などの素材を真似たりそのまま使ったりはしない。属性は**見た目だけ**（ゲームの仕組みは変えない）。

#### 全体の雰囲気
- **明るいポップな配色**：高彩度、空は青く晴れた昼、影も暗くしすぎない
- **セル調シェーディング**：2〜3段の陰影＋太めのアウトライン、リムライト（輪郭の光）でキャラを背景から浮かせる
- **スポーツ大会の空気感**：スタジアム的なアリーナ、観客、旗やバナー、ラウンド開始・KO時の大きな文字演出と実況風アナウンス（素材があれば）
- 背景は彩度と情報量を抑え、キャラとエフェクトが一番目立つようにする

#### 打撃・命中エフェクト
- **コミック調のヒットスパーク**：星形・トゲ形の閃光、衝撃のリング、放射状の線
- 強さで段階を付ける（弱：小さな火花 → 強：大きな閃光＋衝撃波＋画面揺れ＋ヒットストップ長め）
- **ガード**：盾状の六角形バリアが光って割れそうに揺れる。ガードブレイクは大きく砕ける演出
- **決着の一撃**：スローモーション＋カメラ演出＋画面の一瞬のフラッシュ

#### 動きの軌跡
- 攻撃・弾・回避に**太い光の軌跡（トレイル）**。キャラの属性色で色分け
- ダッシュ/回避：残像＋足元の砂煙・風の線、画面端に集中線

#### キャラ別の属性カラー（見た目のみ）
スキルと必殺技の演出、攻撃の軌跡、ヒットスパークの色に使う。

| キャラ | 属性 | 色 |
|---|---|---|
| ブレイズ（拳） | 炎 | 赤・オレンジ |
| スター（二丁拳銃） | 電気 | 黄・水色 |
| 剣士（剣） | 光 | 白・金 |
| 重戦士（ハンマー） | 爆発 | オレンジ・黒煙 |
| 射手（弓） | 氷 | 水色・白 |
| 砲手（ショットガン） | 衝撃波 | 紫 |
| 投擲手（ブーメラン） | 風 | 緑 |
| 魔導士（杖） | 闇 | 紫・ピンク |

#### 必殺技の演出
- 必殺ゲージ満タン時、ビューモデル（自分の腕・武器）が属性色のオーラを纏う
- 発動時は画面の色調が一瞬変わり、属性エフェクトを大きく出す

#### UI
- 太く丸みのある書体、大きなHPバー、ポップな配色。ラウンド表示・カウントダウンは画面中央に大きく弾む動きで出す

### 1.12 非機能
- 60fps目標（中程度のノートPC）、ロジックは固定タイムステップ（60Hz）。
- 物理エンジンは使わず自前の簡易判定（カプセル/球、円形床判定）。
- 対象ブラウザ：最新 Chrome / Edge / Firefox。

## 2. 実装計画

### ディレクトリ構成（予定）
```
game/
  index.html / package.json / vite.config.ts / tsconfig.json
  public/assets/{models,audio,textures}
  src/
    main.ts
    core/      ゲームループ(固定ステップ)・入力(PointerLock)・シーン管理
    arena/     円形アリーナ・背景・場外判定
    combat/    Fighter状態機械・攻撃/ヒットボックス・弾・ダメージ/ノックバック
    characters/ キャラ定義データ（blaze.ts, star.ts, ...）
    ai/        CPU（状態機械・難易度パラメータ）
    view/      一人称カメラ・ビューモデル・相手モデル/アニメ
    ui/        HUD・メニュー（DOMオーバーレイ）
    audio/     BGM/SE管理
```

# FOG TRIAL

Dead by Daylight を再現した、ブラウザで遊べる **3D 非対称マルチプレイ対戦ゲーム** です (Three.js)。
1 人の **キラー** と最大 4 人の **サバイバー** に分かれて戦います。人数が足りないときはボットが入るので、ソロでも遊べます。
PC (キーボード + マウス) とスマホ・タブレット (タッチ操作) の両方に対応しています。

- サバイバー: マップに散らばった **発電機** を修理して **脱出ゲート** に通電させ、脱出する
- キラー: サバイバーを攻撃してダウンさせ、担いで **フック** に吊るし、生贄に捧げる

見た目は斜め見下ろしの固定カメラ (Escape from Duckov のようなイメージ) で、視界の外は暗く沈みます。

## 起動

```bash
cd fog-trial
npm install
npm start          # http://localhost:3000
```

`PORT=8080 npm start` でポート変更。同じ LAN の端末からは `http://<PCのIP>:3000` で参加できます。
ロビーの「招待リンクをコピー」で部屋のリンク (`?room=ABCD`) を共有できます。

### サーバー無しのオフライン版

`node scripts/build-artifact.mjs <出力先>` で、サーバー不要のオフライン版 (ボット戦・ローカルロビー) を静的ファイル一式として書き出せます。
ゲームロジックとボットをブラウザ内で動かし、three.js は CDN から読み込みます。`.glb` を配信できないホスティング向けに、モデルはバイナリを埋め込んだ glTF (`.json`) に変換されます。
開発中は `http://localhost:3000/?offline` でも同じオフライン動作を確認できます。

```bash
npm test                          # ルール・視界・通信のテスト
node scripts/simulate.js 5        # ボット同士の試合をヘッドレスで 1 回 (seed=5)
node scripts/simulate.js many 30  # 30 試合して勝率などを集計 (バランス調整用)
```

## 操作

| | PC | スマホ |
| --- | --- | --- |
| 移動 | `WASD` | 画面左側をドラッグ (バーチャルスティック) |
| 向き | マウス | 移動方向 (キラーの攻撃は近くの相手に少し吸い付く) |
| しゃがむ | `Shift` / `C` | 「しゃがむ」ボタン (切り替え) |
| 修理・治療・救出・ゲート | `E` 長押し | 大きいボタン長押し |
| ロッカー・ハッチ | `E` | 大きいボタン |
| 板・窓枠 | `Space` | 「板/窓枠」ボタン |
| スキルチェック | `Space` / 左クリック | 画面かボタンをタップ |
| もがく (担がれ中) | `A` `D` 交互連打 | 「もがく」ボタン連打 |
| 攻撃 (キラー) | 左クリック | 「攻撃」ボタン |
| 突進 (キラー) | 右クリック長押し → 離す | 「突進」ボタン長押し → 離す |
| 咆哮 (キラー) | `Q` | 「咆哮」ボタン |
| キラーのアクション | `Space` | 「アクション」ボタン (担ぐ・吊るす・板破壊・発電機破壊・ロッカー捜索・ハッチを閉じる) |

## ルール (DbD 準拠の部分)

- 発電機はサバイバー人数分 (4 人なら 4 台) 修理で脱出ゲートに通電。修理中のスキルチェック失敗は進捗が下がり、キラーに物音で通知される
- キラーは発電機を破壊すると進捗が少しずつ後退する
- サバイバーは 2 回攻撃されるとダウン。被弾直後はスプリント
- 担がれたサバイバーはもがいて脱出できる。板を当ててもキラーは担いだサバイバーを落とす
- フック: 1 回目は段階 1 (待機・4% の自力脱出)、2 回目は段階 2 (抵抗のスキルチェック)、3 回目は即座に生贄
- 救出されたサバイバーは「与えられた猶予」で 1 回だけ攻撃を防ぐ
- 最後の 1 人になるとハッチが出現。キラーが閉じるとエンドゲーム崩壊 (ゲート開放でも開始)
- ロッカーに隠れられる。キラーは捜索して引きずり出せる
- 恐怖範囲 (心音)、キラーの赤い視線、スクラッチマーク、血痕、うめき声

| サバイバー | パーク相当の個性 |
| --- | --- |
| ナイト | 発電機の修理が 15% 速い |
| バーバリアン | 窓枠越えが速く、被弾後のスプリントが長い |
| メイジ | 仲間の治療とフック救出が速い |
| ローグ | 足跡が半分しか残らず、しゃがみ移動が速い |

## 素材

3D モデル・効果音はすべて **CC0** の外部素材です (KayKit / Kenney)。詳細は [public/assets/CREDITS.md](public/assets/CREDITS.md)。
取り込みは `scripts/prepare-assets.mjs` で行い、使わない武器メッシュやアニメーションを削っています。
心音とスキルチェックの音だけは該当する素材が無いため WebAudio で合成しています。

## 技術構成

```
fog-trial/
├─ shared/      サーバーとクライアントで共有する ES モジュール
│   ├─ constants.js  チューニング値 (速度・時間・視界など)
│   ├─ map.js        シード付きマップ生成 (ループ用テンプレートの配置・到達性チェック)
│   ├─ physics.js    円 vs タイルの当たり判定、DDA による視線判定
│   └─ characters.js サバイバーの個性
├─ server/
│   ├─ index.js      HTTP 静的配信 (three.js も node_modules から配信) + WebSocket
│   ├─ room.js       ロビー・固定ステップのゲームループ・イベント配送
│   ├─ game.js       権威サーバーのゲームロジック (ネットワーク非依存)
│   ├─ bots.js       ボット AI (人間と同じ入力を生成し、同じ視界ルールで判断)
│   └─ pathfinding.js A* 経路探索
├─ public/
│   ├─ js/world3d.js Three.js の描画 (マップ構築・キャラアニメ・視界の暗転・壁の透過)
│   ├─ js/main.js    通信・入力・クライアント予測・HUD
│   ├─ js/touch.js   タッチ操作
│   ├─ js/vision.js  視界ポリゴン
│   ├─ js/audio.js   効果音
│   └─ assets/       モデル (glb)・効果音 (ogg)
├─ scripts/     素材取り込み・ボット試合のシミュレーション
└─ test/        node:test によるテスト
```

- **権威サーバー**: 30Hz 固定ステップでシミュレーションし、20Hz でスナップショットを送信。各プレイヤーには視界内の情報しか送らない (霧の中は覗けない)。
- **クライアント予測 + リコンシリエーション**: 自分の移動は即座に予測し、サーバー確認済みの入力以降を再適用して補正。他プレイヤーは 100ms 遅れで補間。
- **視界の暗転**: 視界ポリゴンを上から見た 2D マスクに描き、全マテリアルのシェーダーでワールド座標から参照して暗くする。
- **壁の透過**: 自分とカメラの間にある壁・木は網目状に透けて、キャラクターが隠れない。
- 試合中に切断したプレイヤーはボットが引き継ぐ。

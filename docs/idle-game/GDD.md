# 農業放置ゲーム 企画書（GDD）v0.1

> 第1〜3回のヒアリング結果をまとめた初版。タイトルは未定（仮称：**Idle Farm 3D**）。
> 「仮」と書いた項目は、ユーザー未回答のため Claude の提案で仮決めしたもの。

---

## 1. 概要

| 項目 | 内容 |
|---|---|
| ジャンル | 放置 × 経営（数字インフレ型） |
| 一言で | 小さな畑を手で耕すところから始め、農夫と機械で自動化し、お金を無限に稼いでいく3D農業放置ゲーム |
| 参考作品 | Cookie Clicker（インフレの爽快感・アップグレードの手触り） |
| プラットフォーム | ブラウザ（PC・スマホ） |
| 収益化 | ゲームポータル掲載（CrazyGames / Poki など）の広告収益 |
| 見た目 | 3D・ローポリ・のどかでリアル寄り |
| 素材 | 外部の無料素材のみ（商用利用可。クレジット表記OK） |
| ボリューム | エンドレス。転生なし |
| 言語 | 日本語＋英語（仮） |

## 2. コアループ

```
 ┌──────────────────────────────────────────────┐
 │ 植える → (育つ) → 収穫 → 倉庫 → 売る（相場） │
 │      ↑                                │       │
 │      └──── アップグレード購入 ← お金 ←┘       │
 └──────────────────────────────────────────────┘
      アップグレード ＝ 唯一のお金の使い道
      （土地 / 作物 / 農夫 / 機械 / 研究 / 倉庫 / オフライン上限 …）
```

- ゲームの目的は**お金を稼ぎ、アップグレードに使うこと**だけ。規模を示す物語（村→国…）は用意しない
- エンドレスを支えるのは、コストが指数的に増えるアップグレードと、レベル上限のない品種改良

## 3. 手作業

- 操作は**畑のマスを直接タップ・クリック**する（キャラクターは操作しない）
- 工程（仮）：
  - 序盤の作物は「植える → 収穫」の2工程
  - 中盤以降の高級作物は「耕す」「水やり」が必要になる（手間がかかる分、高く売れる）
  - 増えた工程は、農夫や機械で自動化していく
- 自動化後も手作業が得になる要素：**手で収穫すると品質が上がる**（★1〜★3。品質が高いほど高く売れる）

## 5. 季節・天候（ゲームの仕組みに影響する）

- 実時間の **1季節 ＝ 15分（仮）**。春 → 夏 → 秋 → 冬の順に巡る
- 旬の作物は成長速度 ×1.0。旬以外は ×0.5（植えられない、とはしない。放置ゲームで遊べない時間を作らないため）
- 「温室」アップグレードで、旬以外のペナルティを軽くする
- 天候：
  - 雨：水やりが不要になる
  - 晴天続き：成長がわずかに速くなる
  - 嵐（まれ）：見た目の演出のみ

## 6. 倉庫と市場

- 収穫物はまず**倉庫**に入る。容量の上限はアップグレードで増やせる
- **相場は作物ごとに変動する**（基準価格の ±40%程度。季節の影響もある：旬の作物は安く、旬以外は高い）
- 売るのは手動。後半のアップグレードで「自動出荷（指定した価格以上になったら売る）」を解放する
- 倉庫が満杯になると収穫が止まる → 放置中に「売る」動機が生まれる

## 7. 農夫と機械（自動化）

- **農夫**：職種ごとに人数とレベルを上げる
  - 職種：耕す係 / 種まき係 / 水やり係 / 収穫係
  - 人数で同時に作業できる数が増え、レベルで作業速度が上がる
  - 農夫は畑の上を実際に歩き回って作業する
- **機械**（中盤以降。農夫より強力だが高価）：スプリンクラー（水やり）→ トラクター（耕す）→ 種まき機 → コンバイン（収穫）
- 自動で収穫したものは品質★1固定。手収穫との差を残す

## 8. 研究

- **お金で研究する**（専用の通貨は作らない）
- 研究ツリーの例：
  - 新しい作物の解放
  - 温室
  - 自動出荷
  - 品質ボーナス
  - オフライン上限の延長
  - 農夫の上限人数

## 9. 村人の注文

- 注文ボードに3〜5件が並び、好きなものを受けて納品する。期限なし
- 報酬は相場より高いお金。一定時間ごとに新しい注文が補充される

## 10. 土地

- 最初は 3×3 マス。お金で区画を買い足して広げていく
- 土地が広がるとカメラが自動でズームアウトし、箱庭がだんだん大きくなる

## 11. 放置（オフライン）進行

- ゲームを閉じている間も自動化した分は進む
- 上限は8時間。研究で延長できる
- 戻ってきたら「留守中の成果」を表示する

## 12. 3Dでの見せ方

- 斜め上からの固定カメラで、操作はズームのみ
- ローポリ素材で統一感を出す
- スマホでも滑らかに動くことを最優先し、描画数とモデル数を抑える

## 13. 技術

| 項目 | 選定 |

| 言語 | TypeScript |
| 3D | Three.js |
| ビルド | Vite |

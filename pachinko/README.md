## Phase 1: 物理プロトタイプの内容

- `scenes/Main.tscn` — 最小盤面(釘12本、始動チャッカー1つ、左右壁)
- `scenes/Ball.tscn` — 玉。RigidBody2D、質量5.5g(実機の一般的な玉重量に準拠)、`continuous_cd`有効
- `scenes/Peg.tscn` — 釘。StaticBody2D、反発係数0.62・摩擦0.15
- `scripts/Launcher.gd` — 発射ハンドル。強度0.0〜1.0で発射速度を連続制御
- `scripts/StartChucker.gd` — 始動チャッカー。入賞で保留を加算(最大4)
- `scripts/GameManager.gd` — 発射数/入賞数/保留数をデバッグ表示

**操作方法**: スペースキーまたはマウス左クリックで玉を1発発射(`launch_ball`アクション)。

**物理設定の意図**:
- `physics_ticks_per_second=120` — 標準の60から倍増し、高速で釘に絡む挙動の精度を優先(AAA基準)
- 玉の反発係数0.28・摩擦0.35、釘の反発係数0.62・摩擦0.15という非対称設定により、
  「釘に当たると跳ねるが、盤面上を転がる玉自体は粘る」という実機の質感に寄せている
- 発射方向は右下から左上へわずかに角度をつけており(`launch_direction`)、
  実機のレールで玉が弧を描いて盤面に落ちてくる挙動を模している

## アセット/技術方針(このリポジトリでの合意事項)

- エンジン: Godot 4.x(Unity不使用)
- AI動画生成: Klingの**無料枠のみ**を使用する前提で設計する。有料課金前提の演出物量には
  しない。生成コストの高いキャラクター/機体カットには使わず、戦況モニター背景や宇宙空間の
  粒子映像など「主役を映さない汎用背景素材」のみに限定し、機体覚醒・僚機カットインは
  2Dイラスト+CGパーティクル(自作)で表現してAI生成への依存を下げる。
- 商用利用可・著作権クリーンな素材のみ使用する(詳細は元プロジェクトプロンプト6章を参照)。

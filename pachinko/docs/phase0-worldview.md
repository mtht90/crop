# Phase 0: オリジナル世界観 3案

いずれも完全オリジナル。実在作品・IP・固有ロゴ・キャラクターデザインは一切参照しない。
「ゲージ蓄積→解放」「覚醒/変身/解放の一段階アップ」「派手な視覚効果を正当化できるモチーフ」
「高揚感/カタルシス」の4条件を軸に設計した。

---

## 案A: 「深層域 -ABYSSAL BLOOM-」(深海発光生態系)

- **あらすじ**: 誰も潜ったことのない深海の底に、光を溜め込んで発光する未知の生命体の楽園がある。
  保留=深海生物の卵が水圧に耐えながら光を蓄積し、大当たり=発光生物が群れで海面まで浮上し、
  海全体を発光させる「ブルームイベント」。
- **大当たり演出イメージ**: 暗い深海が徐々に発光粒子で満たされ、最終的に画面全体が
  極彩色のバイオルミネセンスで埋め尽くされる。ラウンド中は発光生物が群泳し光の帯を作る。
- **カラーリング**: ディープブルー×ティール×蛍光グリーン/マゼンタのアクセント。
- **メリット**: 幻想的で差別化しやすい。**デメリット**: 「高揚感・爆発力」の点では次点の案より弱め。

## 案B: 「蒼雷絶界 -THUNDER ASCENSION-」(雷雲・嵐モチーフ)

- **あらすじ**: 天空に眠る巨大な雷雲の意思。保留=空に集まる暗雲の欠片が蓄積し、
  リーチ=空が唸り緊張感が高まり、大当たり=雷雲が「覚醒」して天地を割る大落雷が画面全体に落ちる。
  確変中は常時遠雷が響き、稲光が明滅し続ける。
- **大当たり演出イメージ**: 暗雲が渦を巻いて中央に収束→一瞬の静寂→画面全体を切り裂く巨大な
  雷撃が炸裂し、閃光が画面をホワイトアウトさせてからロゴが浮かび上がる。
- **カラーリング**: 漆黒×紫紺×金色の稲妻、ラウンド中は紫→金のグラデーション発光。
- **メリット**: 「閃光・爆発」的な視覚効果と非常に相性が良く、覚醒/解放の物語化が容易。
  雷・稲妻はパーティクル/シェーダーでも十分な説得力を出しやすく、AI生成映像(嵐/雷雲の
  タイムラプス)とも相性が良い。**AAA級の高揚感を狙う上で最も演出映えする**。

## 案C: 「灼心鉱脈 -EMBER CORE-」(鉱石・マグマエネルギー)

- **あらすじ**: 地底深くで眠る鉱石の心臓部。保留=鉱脈の結晶が熱を帯びていく過程、
  大当たり=結晶が臨界に達し、マグマの奔流とともに巨大な炎の心臓が地上に顕現する。
- **大当たり演出イメージ**: 結晶にひびが入り、亀裂から溶岩光が漏れ出し、最終的に画面全体が
  溶岩の奔流と火の粉で埋め尽くされる。
- **カラーリング**: 黒曜石のような漆黒×深紅×金色のマグマ発光。
- **メリット**: 力強さがあるが、案Bと比べるとモチーフのバリエーション(音・動き)が単調になりやすい。

## 選定(初期): 案B「蒼雷絶界 -THUNDER ASCENSION-」

## 改訂版 世界観: 「富岳 -銀河防衛戦線 ラスト・ディフェンダー-」

完全オリジナル。実在ロボットアニメ作品の固有デザイン・機体名・キャラクター・専用演出名は
一切使用しない。「総力戦」「新型ロボットの覚醒」「仲間との絆」という**業界共通の王道
ロボットアニメの型**のみを踏襲し、ビジュアル・ロゴ・機体デザインはすべてこのプロジェクト用に
新規制作する前提とする。方針として**ストーリーの精緻さより画面の見た目(色・光・構図・
情報密度)の説得力を最優先**する。

### あらすじ(骨子のみ・簡潔)

未知の宇宙生命体「ゲイザー」の侵攻で地球の防衛線は次々突破され、残る拠点は
最終防衛都市「ネオ・エデン」のみ。主人公は試作型人型機動兵器**「富岳」**のパイロットに
選ばれた若き兵士。仲間の僚機と共に、敵母艦を撃破し反撃に出る。

「富岳」は本プロジェクトの機体名であり、プロジェクト/タイトルロゴの名称としても統一して使う。

### カラーリング(最優先で固める視覚アイデンティティ)

| 用途 | 色 |
|---|---|
| 基調(筐体/UI/HUD枠) | ガンメタリック×スチールブルー |
| 警戒/保留/緊張 | 深紅(警告灯レッド) |
| 覚醒/大当たり/勝利 | 黄金(ゴールド) |
| 敵性(ゲイザー) | 紫〜黒のバイオメカ発光 |
| 味方増援/カットイン背景 | 白〜シアンのエネルギー光 |

黄金(覚醒)と深紅(警戒)のコントラストを画面設計上の最重要軸とする。
保留・液晶枠・ラウンドカウンターなど、あらゆるUIパーツはこの配色に統一する。

### 2.1節テンプレートの具体化(富岳版)

| ゲーム状態 | 演出内容(具体化) |
|---|---|
| 保留(1〜4個) | 保留アイコン=僚機/警告灯モチーフのアイコン。入賞のたびに指令室の警告ランプ風エフェクトが点滅 |
| 通常変動 | **基地指令室ステージ**。司令官の管制モニター越しに戦況マップが常時動いており、通常時から緊迫感を演出 |
| リーチ | 「敵性反応、複数!」の文字とともに画面トーンが赤みを帯びる。雑魚敵の大群が押し寄せる映像がリーチ背景に展開 |
| SPリーチ | ボスとの一騎打ちへ発展。劣勢に見えた瞬間、僚機/ヒロイン機が「間に合ったぜ!」のセリフ風カットインで参戦(=群予告的な合流演出) |
| 大当たり演出 | 機体エネルギーが限界突破し、メインモニターに「SYSTEM: MAXIMUM」の文字と共に機体が黄金色に発光する完全覚醒カットイン。閃光でホワイトアウトしロゴ「富岳」が確定表示 |
| ラウンド中 | ラウンドごとに僚機との合体攻撃、または新装備への換装演出(継続確定を兼ねる)+出玉カウントアップ |
| 確変中(RUSH) | 「超・銀河決戦モード」。高速テンポの変動で敵幹部機を次々撃破していく専用ステージに切り替え、常時ゴールドのエネルギー発光を背景に持続表示 |

### AI動画生成(Kling無料枠)への反映

雷雲モチーフと異なり、機体合成カットや戦闘シーンの実写/AI映像は生成コストが高いため、
Kling無料枠では**背景の戦況モニター映像(戦艦シルエット/爆発の遠景/宇宙空間の粒子)**など
「主役を映さない汎用背景素材」に絞って生成する。僚機カットイン・機体覚醒などキャラクター性の
強いカットは、2Dイラスト+CGパーティクル(自作)で表現し、AI映像への依存を最小化する設計とする。

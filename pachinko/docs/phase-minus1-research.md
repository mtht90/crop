# Phase -1: 業界標準リサーチまとめ

本ドキュメントは、実在機種の固有デザイン・演出名を模倣する目的ではなく、
**業界全体で共有されている汎用的な仕組み・用語・設計原則**を把握し、
Phase 3.4の演出テーブル設計に反映するためのものである。

## 1. 保留変化(先読み予告)の色階梯

一般的な信頼度序列(業界共通の型):

```
白(通常) < 青 < 緑 < 赤 < 金 < 虹
```

- 保留の「入賞した瞬間」に変化する場合と、「変動中に格上げされる」場合の2パターンがある。
- 同じ色でも機種内での出現頻度によって実質信頼度が変わる。**頻出する色ほど信頼度を下げ、
  レアな色ほど信頼度を上げる**という出現頻度と信頼度の反比例関係が業界標準の設計思想。
- 保留の「育ち方」(青→緑→赤と段階的に変化していく過程)自体も評価材料になる。
- 低信頼度帯(白・青)は「ガセ」になる割合の方が高く設計されるのが一般的
  (毎回当たりを示唆すると演出のありがたみが薄れるため)。

→ 本プロジェクトの設計への反映: `HoldColor` 列挙型を白/青/緑/赤/金/虹の6段階とし、
各色に「出現頻度」と「大当たり時选択率」を独立パラメータとして持たせ、
実質信頼度 = 大当たり時選択率 / 総合出現率 で算出できるようにする。

## 2. 予告演出の種類と発生ロジック

| 種別 | 概要 | 信頼度設計の要点 |
|---|---|---|
| ゾーン演出 | 背景/ステージが一定区間だけ変化し期待感を持続させる | 該当保留が消化されるまで効果継続。ゾーン中の演出発生率が変化する |
| 群予告 | 複数のキャラ/オブジェクトが画面に集結する | 集結数(個数)が多いほど信頼度上昇の段階構造 |
| 擬似連(擬似連続予告) | 1回の変動を複数回の変動に見せかける | 擬似2→擬似3→擬似4と回数が増えるほど信頼度上昇。停止図柄パターンで示唆されることが多い |
| チャンス目 | 図柄の停止パターン自体が期待度を示唆 | 通常のハズレ目とは異なる特定の並びで発生 |
| カットイン | 変動途中に割り込む形の演出 | 発生の有無・柄(色/エフェクト強度)で信頼度が変化。プレミア級は大当たり濃厚 |

## 3. 内部抽選と演出選択の処理順序(最重要原則)

業界標準の処理フローは以下の順序で固定されている:

1. **主基板(メイン)側で抽選** — 大当たり/ハズレ、大当たり種別、確変有無などを乱数で先に確定する
2. **サブ基板(演出側)で、確定した結果に応じた演出テーブルから抽選** — 「当たり時演出テーブル」と
   「ハズレ時演出テーブル」が別に用意されており、同じ演出でも当落で選択率が全く異なる
   (例: あるカットインは当たり時1/10、ハズレ時1/3000)
3. 従って「派手な演出が出た=当たり」ではなく、**極めて低確率ながらハズレでも激熱演出が選ばれる
   ことがある**(いわゆる「激熱ハズレ」)。これは信頼度が100%未満のあらゆる演出で起こり得る仕様。
4. 信頼度100%(当たり確定)の演出=プレミア演出は、当たり時演出テーブルにのみ存在し、
   ハズレ時演出テーブルには一切登録されていない演出として設計される。

→ 本プロジェクトの実装への反映: `LotteryResult`(抽選結果)を確定させてから、
その結果を引数として `EffectSelector` が「結果別演出テーブル(Resource)」を参照して
演出を抽選する、という**2段階抽選**を必ず守る。演出側のロジックが抽選結果を
先に知ってしまう(逆算できる)実装は禁止。

## 4. リーチの発展構造

- ノーマルリーチ → (発展条件を満たすと)SPリーチへ発展、という階層構造が一般的。
- 発展するほど信頼度が上がる設計が業界標準(発展先の種類が多いほど「奥」に行くイメージ)。
- ノーマルリーチのまま停止する場合と、発展して負ける場合とで信頼度が異なる。

## 5. 大当たり中演出

- ラウンド管理: R数(4R/8R/16Rなど)をラウンド開始時に表示し、ラウンドごとに獲得出玉をカウントアップ。
- 昇格演出: ラウンド中に大当たり種別(通常大当たり→確変大当たり)が「昇格」する形で示唆されることがある。
- 確変示唆演出: エンディングや最終ラウンドで、次回の確率状態(確変/時短/通常)を示唆する演出を挟む。

## 6. 用語集

| 用語 | 意味 |
|---|---|
| 信頼度 | ある演出が発生した際に、実際に大当たりへ至る確率 |
| テンパイ | あと1つの図柄が揃えば大当たりという状態(リーチ成立の前提) |
| 前兆 | 大当たり抽選に当選した後、実際にリーチ/大当たり報知に至るまでの変動区間 |
| ステージ | 液晶下部・盤面演出のモード(背景/BGM単位の状態) |
| プレミア演出 | 出現=大当たり確定(信頼度100%)の激レア演出 |
| 激熱ハズレ | 高信頼度の演出が出たにも関わらずハズレる事象 |

以上を踏まえ、Phase 3.4の演出テーブルは「結果確定→テーブル参照→演出抽選」の
2段階構造をGodotの `Resource` ベースで実装する。

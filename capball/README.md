# キャップ・スタジアム

ペットボトルのキャップで遊ぶ「キャップ野球」を、ブラウザで遊べる3D野球ゲームにしたもの。
ルールは日本キャップ野球協会の公式ルール（解説ページ）に合わせ、操作はパワプロのような野球ゲームを手本にしている。

## 遊び方の全体

ホーム画面から遊びを選ぶ。コイン・集めたキャップ・リーグの途中経過・ベスト記録は、この端末のブラウザに保存される。

- **リーグ戦**：競馬の重賞のように格付けのある「〇〇杯」を勝ち抜く。6チームの総当たり（5試合）で、勝ち＝3点・引き分け＝1点、いちばん多いチームが優勝。優勝すると次の杯に挑戦できる（空き地ステークス G3 → ラムネカップ G3 → サイダー記念 G2 → ペットボトル賞典 G2 → キャップ大賞典 G1）。上の杯ほど相手が強く、賞金も多い。相手チームはそれぞれ自分のキャップを使ってくる
- **自販機**：100コインでキャップを1本買う。何が出るかはランダムで、レア度は N・R・SR・SSR。ダブるとコインが少し戻る。最初に持っているのは2本だけ
- **マイキャップ**：集めたキャップの図鑑。使うキャップを選ぶ
- **チャレンジ**：的当て（12球で9枚のパネルを撃ち抜く）と、ホームラン競争（10アウトまでに何本打てるか）。結果と記録更新でコインがもらえる
- **フリー試合**：チームと設定を選んで1試合

コインは試合（勝ち・得点・本塁打・奪三振）、リーグの順位、チャレンジで貯まる。

## ルール（公式キャップ野球に準拠）

- 5人制：投手・捕手・内野手2人が守り、残る1人は指名打者。打順は1〜5番
- 投球距離9.22m、球速の目安は30〜100km/h。フェンスは両翼13m・センター16m、高さ75cm
- 6回制（3回・4回も選べる）。4ボールで四球、3ストライクで三振、3アウトで攻守交代。首・頭に当たればデッドボール
- 走塁はない。走者は仮想で、打撃の結果に応じて進む（ダブルプレーもない）
- 打球の判定
  - ノーバウンドで捕る・止める → アウト（ファウルフライも）
  - アウトゾーン（本塁・両翼8mの点・マウンドを結ぶ区域）で止まる → アウト
  - ヒットゾーンに届く → 単打（走者は全員1つ進む）
  - 1バウンド以上でフェンスに届く → 二塁打 / ノーバウンドでフェンス直撃 → 三塁打 / ノーバウンドでフェンス越え → 本塁打
- パスボールはなし（捕手は必ず捕る）
- 帽子はかぶらない。バットは滑らかなプラスチック棒
- 一度降板した投手は再登板できない。交代した投手は前の投手の打順を引き継ぐ

球種は、キャップの面の向きと傾きで投げ分ける：ストレート（面を進行方向・回転を抑える）、カーブ（面を約45度傾けて弾く）、スライダー（面を上向きに約30度傾ける）、ライズ（手元で浮き上がる）、ナックル（90度立てて無回転）。

**キャップの銘柄**：試合の前に、使うキャップを16種類から選ぶ（すべて架空の銘柄）。守るときに投げるのは自分のキャップで、相手は別の銘柄を使う。銘柄ごとに「球速・変化・制球・重さ」が違い、重いキャップほど打たれたときに飛ぶ。さらに、キャップごとに**投げられる球種（持ち球）**が違う。回し方は6通りで、同じ回し方でもキャップによって出る球種が変わり、キャップによっては投げられない回し方もある。球種は全22種類（ストレート・ツーシーム・ジャイロボール／ナックル・チェンジアップ・パーム／スライダー・カットボール・スイーパー・高速スライダー／カーブ・スローカーブ・スラーブ・パワーカーブ／ライズ・ホップボール・アップシュート／ドロップ・フォーク・スプリット・シンカー・縦スライダー）。銘柄の一覧と能力・持ち球は `src/game/caps.ts`、球種は `src/game/data.ts`。

スマホ（縦画面）向けに作っていて、PC でも遊べる。

## 遊び方

**投げる（守備のとき）**（投手の目線で、ポケモンGOのように投げる）
1. 画面下のキャップをつまんで、**投げたい所まで払って指を離す**。ストレートは指を離した所に来る（変化球はそこから曲がる）。払う速さで球速が決まる。回してから指を離さずそのまま払ってよい
2. 回し方で変化球が決まる（出る球種はキャップの持ち球による）
   - **少し大きめに右回り／左回り**：右回り＝右へ、左回り＝左へ曲がる。半周ほど（スライダー系）と、たくさん回す（カーブ系）
   - **縦長に左回り**：浮き上がる球（ライズ系）
   - **縦長に右回り**：落ちる球（ドロップ・フォーク系）
3. 回さずに速く投げるとストレート系、ゆっくり投げるとナックル系
4. 投手が得意な投げ方ほど変化が大きい。キャップが投げられない回し方をすると、ストレート系になる

**打つ（攻撃のとき）**
1. 画面をドラッグして黄色いミートカーソルを動かす
2. キャップが来たら**指を離してスイング**（投げる前に離しても振らない）
3. カーソルの中心で捉えるほど強い当たりになる。早く振ると引っ張り、遅いと流し打ち。キャップがカーソルの上側を通ると打ち上がり、下側だとゴロ（アウトゾーンで止まるとアウト）
4. 「強振」はカーソルが小さい代わりに飛ぶ。「バント」はカーソルが大きく、転がすだけ

守備は自動。走者は仮想なので走塁の操作はない。

**PC の操作**：投球はマウスでキャップをドラッグして回し、上へ払う（スペースで真ん中にストレート）。打撃は矢印キーでカーソル移動、スペースでスイング、Q/E/R でミート・強振・バント。

## 開発

```bash
npm install
npm run fetch-assets   # 素材を配布元から取得して public/assets に置く（初回のみ）
npm run dev
```

- `npm run build` … 型チェックと本番ビルド（`dist/`）
- `npm run sim -- 3000` … 打球判定を描画なしで大量に流し、結果の割合（アウト・単打・二塁打…）を調べる
- `npm run build:artifact -- <出力先>` … Claude のアーティファクトとして公開できる形（1枚の HTML＋素材）にまとめる
- `?auto` を付けると CPU 同士で試合が進む（確認用）。`&ts=4` で早送り、`&inn=1` で1回だけ（開発時のみ）

効果音は手で取り込む必要がある（[SOUNDS.md](SOUNDS.md)）。使った素材とライセンスは [CREDITS.md](CREDITS.md)。

| `src/game/batting.ts` | ミートカーソルとタイミングから打球を決める |
| `src/game/flight.ts` | 打球の物理（空気抵抗・キャップの横揺れ・バウンド・フェンス） |

| `src/game/ai.ts` | CPU の配球と打撃 |
| `src/game/rules.ts` | カウント・アウト・仮想走者・パスボール・得点・成績 |
| `src/game/data.ts` | チーム・選手・球種・難易度 |
| `src/game/caps.ts` | キャップの銘柄と能力・持ち球・レア度 |
| `src/game/teams.ts` | リーグに出るチーム |
| `src/game/league.ts` | 杯・総当たりの日程・順位 |
| `src/game/save.ts` | コイン・キャップ・記録の保存 |
| `src/ui/menus.ts` | ホーム・リーグ・自販機・図鑑・チャレンジの画面 |
| `src/render/character.ts` | 選手（ユニフォームの塗り替え、IK による投球・打撃フォーム） |
| `src/render/motions.ts` | 投球フォームとスイングのキーフレーム |
| `src/render/field.ts` | 空き地の球場と町並み |
| `src/ui/` | HUD・操作・タイトル/設定/結果画面 |
| `scripts/` | 素材の取得と加工 |

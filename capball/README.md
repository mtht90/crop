# キャップ・スタジアム

ペットボトルのキャップで遊ぶ「キャップ野球」を、ブラウザで遊べる3D野球ゲームにしたもの。
試合の進め方はパワプロのような野球ゲームを手本にしている（球種とコースを選んで投げる、ミートカーソルで打つ、選手の能力をS〜Gで表す）。
キャップは軽いので、本物の野球よりずっと大きく曲がり、揺れながら飛ぶ。

スマホ（縦画面）向けに作っていて、PC でも遊べる。

## 遊び方

**投げる（守備のとき）**
1. 下のボタンで球種を選ぶ（矢印は曲がる向き、点の数は変化量）
2. 画面をドラッグして、赤い狙いをゾーンのどこに投げるか決める
3. 下のキャップを押さえると白い輪が縮み始める。**緑の輪に重なった瞬間に上へはじく**と狙いどおりに行く
   - はじく速さで球速が変わる
   - 指を左右に**曲げながら**はじくと回転がかかり、同じ向きの変化球はさらに曲がる（ストレートはその向きに少し曲がる）

**打つ（攻撃のとき）**
1. 画面をドラッグして黄色いミートカーソルを動かす
2. キャップが来たら**指を離してスイング**（投げる前に離しても振らない）
3. カーソルの中心で捉えるほど強い当たりになる。早く振ると引っ張り、遅いと流し打ち。キャップがカーソルの上側を通ると打ち上がり、下側だとゴロ
4. 「強振」はカーソルが小さい代わりに飛ぶ。「バント」はカーソルが大きく、転がすだけ

守備（捕球・送球）と走塁は自動で行う。

**PC の操作**：矢印キーで狙い・カーソル移動、1〜6 で球種、スペースを押して離すと投球、スペースでスイング、Q/E/R でミート・強振・バント。

## 開発

```bash
npm install
npm run fetch-assets   # 素材を配布元から取得して public/assets に置く（初回のみ）
npm run dev
```

- `npm run build` … 型チェックと本番ビルド（`dist/`）
- `npm run sim -- 3000` … 守備・走塁ロジックを描画なしで大量に流し、結果の分布と異常（走者の取り残し・アウト数の不整合など）を調べる
- `?auto` を付けると CPU 同士で試合が進む（確認用）。`&ts=4` で早送り
- `?dev` で素材の確認用ビューア

効果音は手で取り込む必要がある（[SOUNDS.md](SOUNDS.md)）。使った素材とライセンスは [CREDITS.md](CREDITS.md)。

### 構成

| ファイル | 役割 |
|---|---|
| `src/game/match.ts` | 試合の進行（打席・投球・打球・攻守交代・カメラ） |
| `src/game/pitch.ts` | 投球の軌道（変化球・ナックルの揺れ） |
| `src/game/batting.ts` | ミートカーソルとタイミングから打球を決める |
| `src/game/flight.ts` | 打球の物理（空気抵抗・キャップの横揺れ・バウンド・フェンス） |
| `src/game/play.ts` | 自動守備と自動走塁（捕球・送球判断・フォースアウト・タッチアップ・進塁判断） |
| `src/game/ai.ts` | CPU の配球と打撃 |
| `src/game/rules.ts` | カウント・アウト・塁・得点・成績 |
| `src/game/data.ts` | チーム・選手・球種・難易度 |
| `src/render/character.ts` | 選手（ユニフォームの塗り替え、帽子、IK による投球・打撃フォーム） |
| `src/render/motions.ts` | 投球フォームとスイングのキーフレーム |
| `src/render/field.ts` | 空き地の球場と町並み |
| `src/ui/` | HUD・操作・タイトル/設定/結果画面 |
| `scripts/` | 素材の取得と加工 |

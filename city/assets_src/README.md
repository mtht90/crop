# assets_src/

ダウンロードした素材を **zip のまま** ここに置く。**このフォルダの中身は git に入れない**（ライセンス上、素材単体を公開・再配布できないため）。

| 置くもの | ファイル名 |
|---|---|
| 3D：dglopez「Low Poly City Builder Asset Pack」無料版 | `FREE_VERSION_65_MODELS.zip` |
| UI：Prinbles「Bliss GUI」 | `Prinbles_GUI_Asset_Bliss_1.0.0.zip` |
| 効果音：Shapeforms Audio Free SFX | `Shapeforms Audio Free Sound Effects.zip` |
| BGM：JDSherbert Minigame Music Pack | `JDSherbert - Minigame Music Pack [FREE].zip` |
| BGM：SunixMuz Casual Music Pack 無料版 | `Casual-mobile-Platformer Music Pack FREE.zip` |

置いたら `npm run import-assets` を実行する。

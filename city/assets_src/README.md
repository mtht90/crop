# assets_src/

ダウンロードした素材をここに置く。**このフォルダの中身は git に入れない**（ライセンス上、公開リポジトリに置けない素材があるため）。

| 置くもの | ファイル例 |
|---|---|
| SimplePoly City（Unity Asset Store） | `SimplePoly City - Low Poly Assets.unitypackage` |
| Bliss GUI（Prinbles） | zip のまま |
| Shapeforms Audio Free SFX | zip のまま |
| Minigame Music Pack（JDSherbert） | zip のまま |
| Casual Music Pack 無料版（SunixMuz） | zip のまま |

置いたら `npm run import-assets` を実行する。

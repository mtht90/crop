# 『みんなのため』

グループトーク型の長編ホラーゲーム。テーマは「善意による破壊・正義の暴走」。プレイ時間の目安は40〜60分。

`index.html` をブラウザで開くだけで遊べます（1ファイル完結）。

## 遊び方
- タイトルで名前を入力して開始（初期値は「ユイ」）。
- 入力欄から自由に文字を打って送信できる。
  - 返事を待たれている場面では、送った文章の内容によって反応が変わる。
  - 約2.4秒以内に連投したメッセージは、まとめて一つの返答として判定する。
  - 黙っていると催促され、最終的には「無視」として扱われる。入力欄に文字がある間はタイマーが止まる。
- 「‹」でトーク一覧に戻れる。グループのほかに、カナ・ソウタ・ミサキ・お母さん・店長・テニス部・知らないアカウントとのトークがある。
  - 返事を求められた場面では、そのトークが自動で開く。
  - 別のトークに届いたメッセージは通知で表示される。通知をタップするとそのトークを開く。
  - 過去の履歴もそれぞれのトークで読める。例えば、カナが打ち明けた夜のトークや、テニス部グループでプレイヤーが漏らした発言。
- 画面をタップすると待ち時間をスキップする。⏩で早送り、🔔で通知音のON/OFF。

## 入力の判定
`RULES`（正規表現）で入力を分類し、場面ごとの `branches` を再生する。分類の判定順は次のとおり：
`plea` → `apology` → `anger` → `deny` → `excuse` → `question` → `short` / `other`。
未入力は `silence` になる。台詞中の `{name}` はプレイヤー名、`{q}` は直前の発言に置き換わる。

## シナリオの編集
シナリオ本体は `<script>` 内の章ごとの配列。過去の履歴は `seedAll()` に入っている。

```js
to('kana')                            // 以降のメッセージを送るトーク
m('misaki', 'セリフ')                 // メッセージ（第3引数は待ち時間ms）
img('aya', S => shot(...))            // スクショ・写真・SNS投稿などの画像
bg('x1', 'x1', '本文')                // 別のトークに届くメッセージ（通知になる）
unsend('kana', '本文')                // 送信してから取り消す
kick('tennis', '…を退会させました')    // トークから外される
ask({ timeout, pressureAt, pressure:[who, text], save:'変数名', branches:{ apology:[...], default:[...] } })
```

`npm` などは不要。公開用のアーティファクト版は、このファイルから `<html>` `<head>` `<body>` の外枠を外したもの。

# 『みんなのため』

LINEグループトーク型のホラーゲーム。テーマは「善意による破壊・正義の暴走」。

`index.html` をブラウザで開くだけで遊べます（外部ライブラリなし・1ファイル完結）。

## 遊び方
- タイトルで名前を入力（初期値「ユイ」）して開始。
- 下の入力欄から自由に文字を打って送信できる。
  - メンバーが返事を待っている場面では、送った文章の内容で反応が変わる。
  - 連投した場合は約2.4秒以内のものを一つの返答としてまとめて判定する。
  - 何も送らずにいると「既読ついてるよね」と催促され、最終的には「無視」と見なされる（入力欄に文字がある間はタイマーが止まる）。
  - 返事を待たれていない場面で送ると、既読はつくが基本的には流される。
- 画面をタップすると待ち時間をスキップ。⏩で早送り、🔔で通知音のON/OFF。

## 構成
| 章 | 日付 | 内容 |
|---|---|---|
| プロローグ | 10/2 | いつもの雑談 |
| 1 発覚 | 10/3 | カナの通院を部活グループで漏らしたスクショ、嘘をついていたDM |
| 2 話し合い | 10/4 | 謝罪の強要、ノート「約束」 |
| 3 掘り返し | 10/7 | 中学時代の過去、アルバム「記録」、昔のストーリー |
| 4 晒し | 10/9 | SNSでの晒し投稿。**プレイヤーの返答（無視を含む）がそのまま追記として晒される**。カナ自身の秘密も拡散される |
| 5 制裁 | 10/12 | バイト先・顧問・親への通報。止めようとしたソウタも過去を晒され加担側に戻る |
| エピローグ | 5か月後 | 誕生日、プリ、ディズニーの約束。「あの頃はみんな大変だったよね笑」 → 退会する／何も言わずに残る → 「今日も楽しかったね！」 |

## 入力の判定
`RULES`（キーワード正規表現）で次のカテゴリに分類し、場面ごとの `branches` を再生します。

`plea`（やめて/許して/消して…）→ `apology`（ごめん/すみません…）→ `anger`（うざい/は？…）→ `deny`（違う/知らない…）→ `excuse`（でも/だって/冗談…）→ `question`（なんで/？）→ `short` / `other`、未入力は `silence`。

分岐が見つからなければ `default` を使います。台詞中の `{name}` はプレイヤー名、`{q}` はプレイヤーの直前の発言に置き換わります。

## シナリオの編集
`<script>` 内の `PROLOGUE` 〜 `EPILOGUE` 配列がシナリオ本体です。

```js
m('misaki', 'セリフ')                 // メッセージ（第3引数で待ち時間ms）
img('aya', S => shot(...))           // スクショ・写真・SNS投稿などの画像
stamp('rina', '😂')                  // スタンプ
sys('…が退会しました')                // システムメッセージ
notify('LINE', '#06c755', '店長', '本文') // 端末の通知
ask({ timeout, pressureAt, pressure:[who, text], branches:{ apology:[...], default:[...] } })
fn(S => 条件 ? [...] : null)          // 状態に応じた分岐
```

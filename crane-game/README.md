# クレーンゲームセンター（3D クレーンゲームシミュレーター）

Three.js（描画）と cannon-es（物理演算）で作った、ゲームセンターのクレーンゲームを再現したブラウザゲームです。
ビルド不要で、ライブラリは CDN（jsDelivr）から読み込みます。

## 起動方法

```bash
cd crane-game
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

`index.html` を直接開くと ES Modules の制限で動かないので、ローカルサーバー経由で開いてください。

## 遊び方

1. 100円玉（1回）か500円玉（6回）を入れる（Cキーでも100円投入）
2. **① を押している間**アームが右へ、**② を押している間**奥へ動く。離すと止まり、戻せない
3. ② を離すとアームが自動で降りて、掴んで、取り出し口まで運ぶ

設定でレバー式（WASD / 矢印で自由移動、スペースで降下）にも切り替えられます。V キーか「横から覗く」で横から奥行きを確認できます。

## 台

| 台 | 種類 | 内容 |
| --- | --- | --- |
| 3本爪 ぬいぐるみ | 確率機 | ぬいぐるみを並べて山積み。落とし口の手前に「見せ」の景品、アクリルガードにもたれた景品あり |
| 2本爪 橋渡し | 実力機 | 2本のバーの上に箱入りフィギュア。端を持ち上げる、押す、縦にしてバーの間に落とす |

### 確率機のしくみ

実機の確率機と同じく、プレイ料金が台に「貯金」され、**設定金額に届いた回だけアームが強く**なります（当たり）。
景品が取れると貯金から設定金額が引かれます。通常時はアームが弱く、上まで上がると爪がゆるんで落ちやすくなります。
「ランダム当たり」を設定すると、貯金に関係なく一定確率で当たりになります。

店員設定の「店員モード」をオンにすると、貯金の額と当たりかどうかが見えます。

### 実力機のしくみ

アームパワーは常に一定で、箱をまるごと持ち上げる力はありません。掴んだ位置で吊るされるので、端を持てば端だけが浮きます。

## お店の方針（プリセット）

| | 設定金額 | 通常時パワー | 上でゆるむ確率 | ランダム当たり | 橋渡しパワー |
| --- | --- | --- | --- | --- | --- |
| 良心的 | ¥1,500 | 40% | 60% | 1/30 | 60% |
| 標準 | ¥2,500 | 30% | 85% | 1/50 | 45% |
| 渋い | ¥4,000 | 20% | 95% | なし | 30% |

自動テストでの目安（標準設定）: 3本爪は当たり時の獲得率が約9割、通常時はほぼ上で落ちます。橋渡しは端を狙った場合に約10回に1回落ちました。

## 財布

- 財布の残高、使った金額、獲得した景品とその参考価格、1個あたりの金額、収支を表示
- 獲得履歴には「その景品に使った金額」が残ります
- 今日の予算を設定でき、超えると知らせます
- クレジットは台ごとに残ります（実機と同じく、台を移ると前の台に残る）
- データはブラウザの localStorage に保存されます

## 操作の重さ

- アームの横移動は加速・減速つき（離してもすぐには止まらない）
- ケーブルで吊られたアームが振り子のように揺れる
- 上昇しきったときの「ガクッ」という揺れ
- 移動速度は設定で変更可。慣性・揺れはオフにもできます

数値は `main.js` 冒頭の `CLAW3` / `CLAW2`（爪の形）、`MOTION`（動き）、`SHOPS`（お店の設定）で調整できます。

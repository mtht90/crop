# 3D クレーンゲームシミュレーター

Three.js（描画）と cannon-es（物理演算）で作った、ブラウザで遊べるクレーンゲームです。
ビルド不要で、ライブラリは CDN（jsDelivr）から読み込みます。

## 起動方法

ES Modules を使っているので、`index.html` を直接開くのではなくローカルサーバー経由で開いてください。

```bash
cd crane-game
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

GitHub Pages などの静的ホスティングにそのまま置いても動きます。

## 操作

| 操作 | キーボード | 画面ボタン |
| --- | --- | --- |
| アーム移動 | WASD / 矢印キー | 左下の十字ボタン |
| 降下 | スペース | DROP |
| 降下を途中で止めて掴む | 降下中にもう一度スペース | 降下中にもう一度 DROP |
| 視点切替（正面/側面） | C | 右下の「正面」「側面」 |
| カメラ回転 | マウスドラッグ / スワイプ | |

アームは降下 → 爪を閉じる → 上昇 → 投入口（手前左）へ移動 → 開く、の順に自動で動きます。
景品が投入口に落ちれば獲得です。移動方向はカメラの向きに合わせて変わるので、側面視点で奥行きを合わせると狙いやすくなります。

## 掴みやすさの仕組み

爪はキネマティックな剛体として実際に景品を押したり引っ掛けたりします。そのうえで、爪を閉じ終えた時点で
**設定した本数以上の爪が触れている景品**を、上限付きの拘束（保持力）でハブにつなぎます。
保持力が景品の重さと揺れに負けると、景品はずり落ちます。

右上の「⚙ 設定」で調整できます。

| 項目 | 意味 |
| --- | --- |
| 難易度プリセット | 下の値をまとめて切り替え |
| アームの強さ | 保持力。`3 + 強さ% × 22` N（景品は 0.3〜0.55 kg） |
| 掴み判定に必要な爪の数 | 1 にすると爪1本が触れただけでも掴める |
| 上昇後にアームが弱まる確率 | 上まで上がったとき、保持力が落ちて爪が少し緩む確率（ゲーセンっぽさ） |
| 降下ガイド | アームの真下にレーザーを表示 |

プリセットの目安（真上から正確に狙った場合の獲得率を自動テストで計測）:

- かんたん: ほぼ 100%
- ふつう: 約 70%
- むずかしい: 約 25%

細かい数値は `main.js` 冒頭の `CLAW` と `PRESETS` で変更できます。

# ちいさな王国

金鉱石を叩いて金貨を集め、島の王国を育てるブラウザ向けの放置クリッカーです。

- **クリック**: 金鉱石を叩いて金貨を得ます。連打で「熱気」がたまり、稼ぎが最大 2 倍になります。4% の確率で会心（7 倍）が出ます。
- **作業員**: 鉱夫・木こり・羊飼い・大工を雇うと、島の上で実際に働いて資源を運んできます。
- **建設**: 家・見張り塔・兵舎・弓術場・修道院を建て、城を増築します。建物は島の上に下から組み上がっていきます。
- **研究**: 道具の改良（8 段階）、クリック強化、相乗効果、経済、軍事など 49 種類あります。
- **遠征**: 剣士・槍兵・弓兵・僧侶を訓練し、周りの 4 つの敵国（各 5 拠点）を攻めます。合戦は敵の島で演出つきで行われます。
- **王位継承**: 治世で金貨を 1000 万枚稼ぐと、王位を譲って王冠を得られます。王冠は永続ボーナスになり、「王家の遺産」10 種と交換できます。
- **その他**: 黄金の輝き（30 秒間生産 ×7 か、金貨の大当たり）、実績 27 種、放置中の生産、自動セーブ、データの書き出しと読み込み。

PC とスマホの両方に対応しています。スマホでは操作パネルが画面下半分に出ます。

## 遊び方（開発環境）

```bash
npm install
```

```bash
npm run dev
```

## ビルド・テスト

```bash
npm run build
```

```bash
npm test
```

`npm test` では、数値表示・コスト計算・セーブ・放置進行の単体テストに加えて、自動プレイによるバランス確認（12 時間分のシミュレーション）を実行します。

サブパスに配置する場合は、ビルド時に `BASE_PATH` を指定します。

```bash
BASE_PATH=/crop/ npm run build
```

## 素材の再生成

`public/assets/` の素材は `tools/build_assets.py` で作られています。元の素材パックを差し替えたときは再実行します（Python 3、Pillow、NumPy、ffmpeg が必要です）。

```bash
python3 tools/build_assets.py "<Tiny Swords (Free Pack) のフォルダ>" "<音声素材のフォルダ>"
```

## 構成

| パス | 内容 |
|---|---|
| `src/core/data.ts` | 職業・建物・兵・研究・敵国・遺産・実績の定義と数値バランス |
| `src/core/sim.ts` | 経済計算、購入、建設、合戦、王位継承、放置進行 |
| `src/core/state.ts` | セーブデータの形式と読み書き |
| `src/world/` | PixiJS による島の描画、キャラクターの動き、演出、カメラ |
| `src/ui/` | パネル・HUD・ダイアログ（Tiny Swords の UI パーツを 9 分割で使用） |
| `src/audio.ts` | BGM のクロスフェード、効果音、波の環境音 |

素材の出典とライセンスは [CREDITS.md](CREDITS.md) にまとめています。

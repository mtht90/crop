# 星海開拓記 — Stellar Frontier

星をクリックして星屑を集め、宇宙を開拓していく超大規模な放置クリッカーゲームです。
ブラウザだけで遊べ、数ヶ月単位でじっくり進行するように調整されています。

## 遊び方

```bash
npm install
npm run dev      # 開発サーバー (http://localhost:5173)
npm run build    # 型チェック + 本番ビルド (dist/)
npm test         # ユニットテスト
npm run sim      # バランス確認用のシミュレーション (SIM_DAYS=60 などで期間を指定)
```

`main` に push すると GitHub Actions がビルドし、GitHub Pages に公開します
(リポジトリの Settings → Pages → Source を「GitHub Actions」にしてください)。

## ゲームの要素

| 要素 | 内容 |
| --- | --- |
| 施設 | 星屑コレクターから無限の特異点まで 40 種類 |
| アップグレード | 施設強化 600 / クリック 25 / 全体倍率 60 / シナジー 35 — 計 720 個 |
| 実績 | 約 880 個。1 個ごとに生産 +1% (複利) |
| 転生 (4 層) | 超新星 → 銀河崩壊 → ビッグクランチ → 多元宇宙転生。各層に専用通貨とショップ |
| 研究 | 現実の時間で進む研究ツリー (約 50 ノード、最長 30 日、無限研究あり) |
| 遠征と遺物 | 艦隊を送り出し、5 段階のレア度を持つ 30 種の遺物を集める |
| チャレンジ | 8 種 × 5 段階。制約付きで目標を目指し、永続報酬を得る |
| 彗星 | 画面を横切る彗星をクリックすると生産ブーストなどの効果 |
| 自動化 | クリック・施設・アップグレード・研究・遠征・各転生を自動化 |
| 放置報酬 | ページを閉じている間も進行 (効率・上限は強化可能) |
| その他 | 巨大数対応 (break_infinity.js)、4 種の数値表記、セーブのエクスポート/インポート、宇宙ニュース |

## 構成

```
src/
  core/    状態・修正値・セーブ・Game クラス (メインループ)
  data/    施設・アップグレード・実績・研究・ショップ・遺物・チャレンジ・バランス定数
  logic/   経済・生産計算・転生・研究・遠征・彗星・自動化・放置報酬
  ui/      DOM を直接組み立てる軽量 UI (タブごとに mount / update)
tests/     ユニットテスト (vitest)
sim/       バランス確認用ボット
```

転生まわりのバランスは `src/data/balance.ts` に集約しています。
値を変えたら `npm run sim` で進行速度を確認してください。

# 漢字でGO! 再現版(非公式ファンメイド)

落ちてくる漢字の読みを、終点(黄色い点字ブロック)に着く前に入力するタイピングゲームです。
「漢字でGO!」のゲーム性をもとにした非公式作品で、問題・デザイン・効果音はすべてオリジナルです。

## 遊び方

`index.html` をブラウザで開くだけで遊べます(ビルド不要・1ファイル完結)。

- 読みは **ひらがな(IME)** でも **ローマ字** でも入力可(`kanji` → かんじ、`nn` / `n'` で「ん」)
- 正しい読みになった瞬間に自動で正解。`Enter` で決定して間違えると、漢字が少し進むペナルティ
- 5問正解ごとにレベルアップ(Lv1 各駅停車 → Lv10 銀河鉄道)。速度と難易度が上がる
- 早く答えるほどスピードボーナス。読みが複数ある語はどれでも正解
- `Esc` で一時停止(停止中は漢字が隠れます)

## モード

| キー | モード | 内容 |
| --- | --- | --- |
| 1 | ノーマル | Lv1 から。1問でも終点に着いたらゲームオーバー |
| 2 | 難読 | Lv6 の難読漢字からスタート |
| 3 | 練習 | 終点に着いても続行し、答えを表示 |

## 問題データ

`index.html` 内の `RAW` に 10 レベル × 約45問、計450問を収録しています。
1行 = `漢字|よみ[,別のよみ]|ひとこと` の書式なので、行を足すだけで問題を追加できます。
ハイスコアと効果音の設定はブラウザの localStorage に保存されます。

# ♻ リサイクルショップ・シミュレーター

客の持ち込み品を **査定・買取** し、**清掃・修理** して **値札をつけて売る**、一人称 3D のショップ経営シミュレーターです。
TCG Card Shop Simulator 系の「お店を回す」手触りを、リサイクルショップ (目利き・交渉・真贋) に置き換えています。

- エンジン: [three.js](https://threejs.org/) + TypeScript + Vite (ブラウザで動作・インストール不要)
- グラフィック・サウンド・アイコンは **すべて外部のオープンライセンス素材** (→ [CREDITS.md](./CREDITS.md))

## 遊び方

```bash
npm install
npm run dev        # http://localhost:5173 を開く
npm run build      # dist/ に静的ファイルを出力 (GitHub Pages 等にそのまま置ける)
```

claude.ai の Artifact として公開する場合は `node tools/build-artifact.mjs` を実行します。
JS/CSS を 1 枚の HTML に埋め込み、Artifact が配信できない `.glb` / `.hdr` は base64 テキスト (`.txt`) に変換して `dist-artifact/` に出力します。
マウスを固定できない環境では、自動で「ドラッグで視点移動」に切り替わります。

| 操作 | キー |
|---|---|
| 移動 / 走る / 視点 | `WASD` / `Shift` / マウス |
| 商品を持つ・置く | 左クリック |
| 使う (レジ・査定・作業台・在庫・看板・PC) | `E` |
| 値札をつける | `F` (陳列中の商品を見ながら) |
| 持っている品を在庫へ | `Q` |
| 店長タブレット (相場・什器・設備・鑑定ガイド) | `Tab` |
| 什器を移動 / 回転 | `G` / `R` |
| メニュー | `Esc` |

### 1 日の流れ

1. **開店準備** — 在庫置き場から商品を出して棚に並べ、値札をつける
2. **開店** — 入口の立て看板を「営業中」に
3. **買取** — 持ち込み客が来たら買取カウンターで査定
   - 3D で品物を回して **傷・凹みを探してクリック** (見落とすと実際の価値は低い)
   - 家電は **通電テスト**、ブランド品・美術品は **刻印ルーペ** で刻印・シリアル・重量を確認して真贋判定
   - 推定販売価格を見ながら **買取額を提示して交渉** (安すぎると怒って帰る)
4. **販売** — 買い物客は値札と自分の見立てを比べて購入を判断。レジでスキャン → 値引き交渉 → **お釣り計算 / カード決済**
5. **作業台** — 汚れは **ドラッグでこすって** 落とし、故障品は **タイミングゲームで修理** して価値アップ
6. **閉店・精算** — 家賃・光熱費・維持費を払い、翌朝のニュースで相場が動く

利益で什器 (陳列棚・陳列台・ショーケース・床展示) や設備 (看板・値付けガン・鑑定ルーペ Pro・エアコン・レジ係・店舗拡張 など) を増やし、店を大きくしていきます。

### ゲームシステム

- **商品 約 100 種** × 6 カテゴリ (家電 / 家具 / キッチン / ブランド / ホビー / 骨董)。状態グレード S〜J・付属品・動作・真贋で価値が決まる
- **客 10 タイプ** (学生・主婦/主夫・コレクター・せどらー・セレブ・怪しい客・謎の紳士 など)。予算・相場知識・強気さ・我慢強さ・好みが違う
- **相場変動** — カテゴリごとのランダムウォーク + ニュースイベント (「昭和レトロブーム」「偽ブランド大量摘発」など)
- **評判・店舗レベル・目標** — 評判で客足が増え、レベルで商品・客層・設備が解放される
- **まとめ仕入れ** — 店舗 PC からジャンク箱・引っ越し整理品・遺品整理ロット・ブランド品オークションを仕入れ (未検品なので作業台で確認)
- **探し物依頼** — 欲しい物が見つからなかった客が依頼を残す。期限までに条件を満たす品を用意すると、相場より高く買ってくれる
- **スタッフ** — レジ係 (自動会計) と品出しスタッフ (自動陳列・値付け)
- 偽物を本物の値段で売ると、後日 **クレームと返金** が発生することも
- 序盤は目標の場所に **案内マーカー** が出る。重いときは画質を自動で下げる
- 自動セーブ (ブラウザの localStorage) ・ 設定 (音量・感度・画質・1 日の長さ)

## 構成

```
src/
  core/      エンジン (レンダラー・ポストエフェクト)・入力・素材読み込み・サウンド・イベント
  data/      商品・客・什器・設備・ニュース・セリフの定義 (バランス調整はここ)
  game/      ゲーム状態・経済 (価値計算・真贋・相場)・Game (全体の組み立てとループ)
  world/     店舗と街並み・昼夜・什器・経路探索 (A*)
  entities/  プレイヤー・客・商品の 3D 表示
  systems/   客 AI・視線インタラクション (持つ/置く)・建築モード
  ui/        HUD・査定・レジ・作業台・値札・在庫・店舗 PC・メニュー
tools/
  asset-manifest.mjs  外部素材の一覧 (取得元・コミット・ライセンス)
  fetch-assets.mjs    素材の取得と最適化 (glTF-Transform: テクスチャ縮小/WebP・meshopt・アニメ共有化)
  playtest*.mjs       Playwright による自動プレイテスト
  balance.mjs         ボットが数日プレイして収支を出す (バランス調整用)
```

### 素材の追加・差し替え

`tools/asset-manifest.mjs` に 1 行追加して `npm run assets` を実行すると、取得・最適化・`CREDITS.md` の再生成まで行われます。
商品として使うには `src/data/items.ts` に定義を追加してください (サイズ・カテゴリ・基準価格・偽物の仕様など)。

## 動作環境

PC のデスクトップブラウザ (Chrome / Edge / Firefox の最新版、WebGL2 対応 GPU)。マウスとキーボードが必要です。
重い場合は設定の「画質」を「標準」「軽量」にしてください。

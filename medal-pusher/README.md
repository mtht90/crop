# MEDAL PUSHER 3D

ブラウザで遊べる 3D メダルプッシャーゲーム（three.js + Rapier 物理エンジン）。
所持メダル **100 枚** からスタートします。

## 遊び方

| 操作 | PC | スマホ |
|---|---|---|
| 投入位置の移動 | マウスを左右 / ← → / A D | 画面を左右にドラッグ |
| メダル投入 | クリック / スペース（長押しで連射） | 投入ボタン（長押しで連射） |
| オート投入 | AUTO ボタン / B キー | AUTO ボタン |

- 投入したメダルはピンの間を落ち、中央の **START** レーンを通るとスロット抽選（最大 4 つまで保留）。
- スロットは荒めの配分：チェリー 10 / ベル 20 / **BAR** 30＋**サイドウォール・チャンス**（20 秒間、左右に壁がせり上がり手前の全幅が獲得口に）/ **7** で 100 枚＋次の 5 回当たり確定のフィーバー。払い出しはプッシャー上に降ってくる。
- スロット当選の払い出しには 25% で **黄金メダル** が混ざる。獲得口に落とすと JP ボール投入（ボールが既にあれば 20 枚払い出し）。
- **蹄鉄**揃いで JP ボール。ボールを手前に押し出すと、その瞬間に筐体上部の **3段クルーン抽選機** が始まる。
  - ボールは透明なシュートを転がって皿に入り、穴の開いたすり鉢状の皿（ゆっくり回転）を何周も回って、穴の縁で粘って吸い込まれる。
  - STAGE 1（ピンク）→ STAGE 2（青）→ FINAL（金）。各段の中央の穴は NEXT（透明なシュートで次の段へ）、FINAL の中央が **JACKPOT**。周りの穴はメダル配当（10〜200 枚）。
  - シミュレーションでの実測：1回あたり平均約12秒、JP 当選率 約 1/11〜1/13。
- JP は 300 枚から始まり、投入 1 枚ごとに 0.08 枚ずつ積み上がる。
- 手前は中央の獲得口だけが当たり。両端の LOST ゾーンや左右に落ちたメダルはハズレ（盤面に入ったメダルの約 59% が戻る）。
- **報酬はすべて払い出し**：スロット・クルーン・JP・黄金メダルの配当は、左右のシュートからプッシャー上に降ってくる（大量のときは払い出しが速くなる）。投入 1 枚あたりの平均還元は約 88%（見積もり）。
- メダルが無くなったら「¥」の **メダル貸出機**（疑似課金。実際の支払いは無し）で買い足せる。使った金額は記録される。
- 所持メダル・JP・盤面のメダル配置は自動でブラウザ（localStorage）に保存。「？」→「データをリセット」で 100 枚から再スタート。

## 開発

```bash
cd medal-pusher
npm install
npm run dev      # 開発サーバ
npm run build    # dist/ に静的ファイルを出力（どこにでも置ける相対パス構成）
```

物理挙動・払い出しバランスはブラウザなしで確認できます。

```bash
node --experimental-strip-types scripts/sim.ts 300          # 300秒ぶん投入し続けて獲得/ロスト/チェッカー回数を表示
AIM=1 node --experimental-strip-types scripts/sim.ts 300    # 中央付近を狙った場合
node --experimental-strip-types scripts/croon-sim.ts 100     # クルーンの所要時間・穴ごとの確率・JP率を確認
```

```bash
python3 scripts/build-embedded.py dist out   # .hdr/.bin を配信できないホスト（Claude のアーティファクト等）向けに変換
```

`?debug` を付けて開くと `window.__pusher` からゲームの状態を操作できます。

### 構成

| ファイル | 役割 |
|---|---|
| `src/config.ts` | 筐体寸法・バランス調整用の定数 |
| `src/physics.ts` | Rapier の物理ワールド（盤面・プッシャー・メダル・ボール・判定） |
| `src/scene.ts` | three.js の描画（筐体・照明・ブルーム・メダルのインスタンス描画） |
| `src/slot.ts` | 上部液晶のスロットのロジックと描画 |
| `src/croon.ts` | 上部の3段クルーン抽選機（穴あきの回転皿）の物理と判定 |
| `src/game.ts` | クレジット・払い出し・セーブなどのゲーム進行 |
| `src/audio.ts` | 効果音・BGM |
| `src/main.ts` | 起動・入力・HUD |

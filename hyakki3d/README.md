# 百鬼祓い 3D（背後視点版）— プロトタイプ

2D 版（`../hyakki/`）と同じゲームロジック（湧き・スキル・レベルアップ・バランス）を、Three.js の 3D・背後カメラで描き直した版。
攻撃・召喚は自動のまま、移動とカメラ旋回だけを操作する。

## 遊び方
```bash
cd hyakki3d && npx http-server -p 8000 -c-1 .   # → http://localhost:8000/
```
| 操作 | PC | スマホ |
|---|---|---|
| 移動 | WASD / 矢印（カメラ基準） | 画面左側をドラッグ |
| 視点 | マウスドラッグ / Q・E | 画面右側をドラッグ |
| 術を選ぶ | 1 / 2 / 3 | タップ |

デバッグ用パラメータは 2D 版と同じ（`?debug` `?t=秒` `?lv=n` `?god` `?speed=n`）。

## 決めたこと
- **技術**：Three.js r160（CDN の import map）＋ ES Modules、ビルド無し。PC 優先、スマホは最低限（影なし・敵上限 500・ブルーム弱め）。
- **大群の描画**：敵・式神は歩行／攻撃アニメを 8 フレーム分の静的メッシュに「焼き込み」、フレームごとの InstancedMesh で描く。何百体でも描画呼び出しは「種類 × フレーム数」で一定。プレイヤーとボスだけ本物のスケルタルアニメ。
- **式神は霊体表現**：縁が光る半透明シェーダ（式霊＝水色、影忍＝紫、前鬼＝金、飛龍＝橙）で、敵と一目で区別できるように。
- **カメラ**：プレイヤーのやや前方を注視する背後見下ろし。敵が増えると少し引く。カメラとプレイヤーの間の木はディザで透ける。

## エフェクト（こだわった点）
- ブルーム＋最終パス（色収差・周辺減光・夜の色調・被弾の赤・閃光・フィルムグレイン）
- GPU パーティクル（加算合成の光点）：撃破時に魂が抜けて昇る、弾の軌跡、狐火の尾
- シェーダで描く晴明桔梗の魔法陣（召喚・結界・レベルアップ）、地面を走る衝撃波
- 落雷：空から地面へのギザギザの光の帯＋点光源の閃光＋火花
- 斬撃の弧、爆炎、レベルアップの光の柱、FOV キック、スローモーション、ヒットストップ、画面揺れ
- 倒した妖怪は白く光って跳ね、縮んで消える
- 背景：月・星・霧、提灯色の手元灯、石灯籠・鳥居・桜・枯れ木、蛍と舞い散る花びら

## 術の進化・宝箱・陰陽師の解放
- **術の進化**：対応する「術」と「加護」を両方持ち、術が最大レベルのときに宝箱を開けると進化する（例：護符＋霊力 → 八方天符、狐火＋速詠 → 九尾の狐火、雷符＋丸薬 → 雷神招来、前鬼＋霊力 → 前鬼・後鬼）。全 9 種。選択カードに「◆進化：〇〇＋〇〇」と組み合わせを表示する
- **宝箱**：エリート（土蜘蛛）が落とす。拾うと時間が止まり、リールが回って 1／3／5 個の報酬が決まる。進化できる術があれば最優先で進化。金の光の柱が立ち、画面外なら矢印で方向を示す
- **陰陽師の解放**：通算記録はこの端末のブラウザに保存（`localStorage`）
  - 安倍晴明（最初から）：護符＋式霊。癖のない万能型
  - 源頼光（5 分生存）：雷符＋白虎。術の間隔が短い
  - 葛の葉（1 回のランで 1500 体祓う）：狐火＋式霊。式神が長く居座る
  - 鬼一法眼（宝箱を通算 5 個開ける）：破魔矢＋前鬼。体力が多く足は遅い
  - 式部（夜明けまで生き延びる）：式霊＋白虎＋八咫烏。式神が 1 体多い

## 見やすさ（立ち回りのため）
- 拾える物には光の柱（経験値玉は控えめ、回復・宝箱は太く高く）。宝箱とエリート・ボスは画面外でも縁に矢印
- 陰陽師の足元に輪、回収範囲の薄い輪。敵の弾には地面の影を落とし、着弾位置を読めるように
- エリートは足元に赤い輪、ボスの大技は地面に予告帯
- カメラと陰陽師の間に入った大きな木・岩は網目状に透ける
- 終盤の乱戦でも陰陽師を見失わないように
  - 敵や岩の陰に入った部分は、白く光る影絵で透けて見える
  - カメラと陰陽師の間にいる敵は網目状に透け、式神は陰陽師の周りで薄くなる
  - 足元の輪は体力で金から朱に変わり、危ないときは脈打つ
  - 敵が 220 体を超えたら、式神の通常ダメージ数字を消し、自分の数字も間引く
- レベルアップのアイコンは文字ではなく、起動時に 3D で描いた絵（進化後は金の輪つき）

## 気持ちよさ
- 会心時の輪と火花、50 体連続で倒すごとの衝撃波、爆発する弾は範囲ダメージで周囲をまとめて吹き飛ばす
- 進化時は光の柱・魔法陣・周囲の雑魚の一掃・大きな見出し
- 連鎖する雷は敵から敵へ稲妻が走る

## 書体
Yuji Boku（筆文字）・Zen Maru Gothic（本文）・Dela Gothic One（数字）。Google Fonts の通常配信は日本語を細かな断片に分けて、初めて画面に出た文字の断片をその場で取りに行くため、術名やバナーが一瞬だけ別の書体で表示されていた。ゲーム内の全文字を `tools/font_glyphs.py` で集め、`text=` 指定の 1 ファイルとして最初に読み込む。文言を足したら再実行する。

| 背景 | Quaternius Stylized Nature MegaKit（桜・枯れ木・松・岩・草花）＋手続き生成の石灯籠・鳥居 |
| 効果音・BGM | Ninja Adventure Asset Pack（2D 版と共通） |

すべて CC0。取り込みは `tools/build_models.mjs`（不要アニメの削除・頂点結合・キーフレーム間引き）と `tools/build_env.mjs`（テクスチャ縮小）で GLB を作り、`tools/glb2json.py` で埋め込み glTF（.json）に変換する（アーティファクトの配信が .glb 非対応のため。.glb は git 管理外）。
Quaternius の FBX は FBX2glTF（npm `fbx2gltf`）で glTF に変換してから取り込む。

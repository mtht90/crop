操作方法

PC

  • W A S D / 矢印 … 移動
  • Shift … ダッシュ
  • Space … ジャンプ
  • マウス … カメラ（クリックでロック）
  • ホイール … ズーム
  • R … チェックポイントへ
  • Esc / P … ポーズ

スマホ

  • 左半分ドラッグ … 移動（倒し切るとダッシュ）
  • 右半分ドラッグ … カメラ
  • ▲ … ジャンプ ／ DASH … ダッシュ切替
  • ⟲ … チェックポイントへ

ゲームパッド

  • 左スティック移動・右スティック視点
  • A ジャンプ ・ RT/LB ダッシュ ・ Start ポーズ

ギミック

  • 動く足場 乗ると一緒に運ばれる
  • 回転梁 回る梁に乗って対岸へ
  • 崩れる足場 乗ると数秒で落下
  • 薙ぎ払いバー ジャンプで避けないと吹き飛ばされる
  • 氷 とても滑る
  • 突風 空中で流される
  • ジャンプパッド 大きく跳ね上がる
  • ビーコン チェックポイント（ONLY UP以外）

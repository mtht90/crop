操作方法

PC

  • W A S D / 矢印 … 移動
  • Shift … ダッシュ
  • Space … ジャンプ（長押しで高く）
  • 壁に向かって跳ぶ … 縁をつかむ → W/Space でよじ登る・S で離す
  • マウス … カメラ（クリックでロック）
  • ホイール … ズーム
  • Esc / P … ポーズ

スマホ

  • 左半分ドラッグ … 移動（倒し切るとダッシュ）
  • 右半分ドラッグ … カメラ
  • ▲ … ジャンプ ／ DASH … ダッシュ切替
  • 縁をつかんだら ▲ か 壁へスティック でよじ登る

ゲームパッド

  • 左スティック移動・右スティック視点
  • A ジャンプ ・ RT/LB ダッシュ ・ Start ポーズ ・ 十字キー上下でズーム

ルール

チェックポイントはありません。落ちたら、着地した場所からまた登ります。海に落ちるとスタートの岩へ。中断しても、最後に立っていた場所から再開できます。

ギミック

  • 縁つかみ 届かない段差も、跳んで縁をつかめばよじ登れる
  • 電線・ロープ 細い線の上を綱渡り（ダッシュ不可）
  • 列車・トロッコ・バス 走る乗り物の屋根に乗って運ばれる
  • ベルトコンベア 乗っていると流される
  • 罠のエレベーター 乗るとしばらく上がり、突然落ちる
  • 観覧車 ゴンドラを乗り継いで上へ
  • 巨大扇風機 上昇気流で一気に舞い上がる
  • マットレス 乗ると大きく跳ねる
  • 吊られた車 梁から吊られて往復する車に乗って渡る
  • クレーンの腕 回る腕に乗って対岸へ
  • 動く足場・昇降台 乗ると一緒に運ばれる
  • 崩れる足場 乗ると約1秒で落ちる
  • 薙ぎ払いバー 跳んで避けないと吹き飛ばされる
  • 氷と突風 滑る床、空中で流される風
  • 軌道 重力が弱く、高く遠くまで跳べる

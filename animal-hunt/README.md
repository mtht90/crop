# 🐾 もふもふハント

Dead by Daylight をベースにした、かわいい動物たちの **非対称マルチプレイ対戦ゲーム** です。
ブラウザで遊べて、1 匹の **ハンター (オオカミ)** と最大 4 匹の **サバイバー (うさぎ・ねこ・たぬき・ペンギン)** に分かれて戦います。

- サバイバー: 森に散らばった **オルゴール** を修理してゲートに電気を通し、脱出する
- ハンター: サバイバーをかみつき → 担ぎ → **鳥かご** に入れて、風船で飛ばす

人数が足りないときはボットが入ります。ソロでも遊べます。

## 起動

```bash
cd animal-hunt
npm install
npm start          # http://localhost:3000
```

ポートは `PORT=8080 npm start` のように変えられます。同じ LAN の友だちは `http://<あなたのIP>:3000` で参加できます。
ロビーの「招待リンクをコピー」で部屋のリンク (`?room=ABCD`) を共有できます。

```bash
npm test                          # ルール・視界・通信のテスト
node scripts/simulate.js 5        # ボット同士の試合をヘッドレスで 1 回 (seed=5)
node scripts/simulate.js many 30  # 30 試合して勝率などを集計 (バランス調整用)
```

## あそびかた

### 🐰 サバイバー

| 操作 | 内容 |
| --- | --- |
| `WASD` | 移動 |
| `Shift` | しのび足 (遅いが足あとが残らず、遠吠えにも見つからない) |
| `E` 長押し | オルゴール修理 / 仲間の治療・救出 / ゲートを開ける / 自分の傷をなめて治す |
| `E` | 木のうろに隠れる・出る / ハッチに飛び込む |
| `Space` | 丸太を倒す・乗り越える / 柵の切れ目 (窓) を越える / スキルチェック |
| `A` `D` 交互連打 | 担がれたときにもがく |

- 修理中・治療中に **スキルチェック** が出ます。針が白いゾーンに入ったら `Space`。黄色ならグレート (ボーナス)。
  失敗すると進捗が下がり、**ハンターに物音で居場所が伝わります**。
- 2 回かまれるとダウン。仲間に起こしてもらいましょう。
- 鳥かごは 1 回目が段階 1 (待つ)、2 回目以降は段階 2 (スキルチェックでもがく)、**3 回目で即風船**。
- 救出された直後は **お守り** で 1 回だけ攻撃を防げます。
- 最後の 1 匹になると **秘密の巣穴 (ハッチ)** が開きます。

| どうぶつ | 個性 |
| --- | --- |
| うさぎ | 窓越えが速く、被弾後のダッシュが長い |
| ねこ | 足あとが半分しか残らず、しのび足が速い |
| たぬき | オルゴール修理が 15% 速い |
| ペンギン | 仲間の治療と救出が速い |

### 🐺 ハンター

| 操作 | 内容 |
| --- | --- |
| `WASD` + マウス | 移動 / 向き (視界は前方のコーンだけ) |
| 左クリック | かみつき (踏み込み攻撃。外すと少しスキができる) |
| 右クリック長押し → 離す | 突進 (速いが曲がれない。壁にぶつかると気絶) |
| `Q` | 遠吠え: 走っている (しのび足でない) サバイバーの居場所が一瞬わかる |
| `Space` | 担ぐ / 鳥かごに入れる / 丸太を壊す / 窓を越える / オルゴールを蹴る / うろを調べる / ハッチを閉じる |

- 赤い **足あと**、ピンクの **毛玉** (負傷者の痕跡)、**物音の輪** はハンターにだけ見えます。
- 修理の進み具合は、オルゴールが視界に入っているときしかわかりません。

## 心理戦を生むしくみ (設計メモ)

| 仕組み | 狙い |
| --- | --- |
| **視界の非対称**: ハンターは遠くまで見えるが前方 110° だけ。サバイバーは 360° だが近距離のみ。壁は視線を遮る | ハンターの背後に回り込む・壁の陰でやり過ごす駆け引き |
| **サーバー側の視界判定**: 各クライアントには「見えているもの」しか送らない | 霧の中の情報はチートでも見えない。ハンターには修理進捗も隠す |
| **心音 (恐怖範囲 15 タイル)** | 姿が見えなくても「近くにいる」ことだけは伝わる。修理を続けるか逃げるかの判断を迫る |
| **赤い視線**: ハンターの向きがサバイバーに見える | どちらに曲がるかの読み合い |
| **速度差 115%** | 直線では必ず追いつかれる → 窓と丸太を使った「ループ」で時間を稼ぐ必要がある |
| **丸太**: 早めに倒せば安全だが消耗、ギリギリなら気絶を狙える | 丸太前での立ち止まり・フェイント |
| **足あと / 毛玉 / うめき声 / 物音** | 逃げる側の行動がすべて痕跡になる。しのび足・木のうろはその対抗手段 |
| **スキルチェック失敗 = 物音** | 修理は「速さ」と「静かさ」のトレードオフ |
| **遠吠え**: 動いている者だけをあぶり出す | 「止まる / しのび足」で隠れるか、急いで修理を続けるか |
| **鳥かごの段階制 + お守り** | 救出に行くか修理を優先するかのチーム判断。ハンターの張り付き (キャンプ) への対抗 |
| **ハッチと夜明けのカウントダウン** | 最後まで勝敗が揺れる終盤 |

## 技術構成

```
animal-hunt/
├─ shared/      サーバーとクライアントで共有する ES モジュール
│   ├─ constants.js  チューニング値 (速度・時間・視界など)
│   ├─ map.js        シード付きマップ生成 (ループ用テンプレートの配置・到達性チェック)
│   ├─ physics.js    円 vs タイルの当たり判定、DDA による視線判定
│   └─ animals.js    動物ごとの個性
├─ server/
│   ├─ index.js      HTTP 静的配信 + WebSocket
│   ├─ room.js       ロビー・固定ステップのゲームループ・イベント配送
│   ├─ game.js       権威サーバーのゲームロジック (ネットワーク非依存)
│   ├─ bots.js       ボット AI (人間と同じ入力を生成し、同じ視界ルールで判断)
│   └─ pathfinding.js A* 経路探索
├─ public/      ブラウザクライアント (Canvas 2D、外部アセットなし・効果音は WebAudio 合成)
├─ scripts/simulate.js  ボット同士のヘッドレス試合
└─ test/        node:test によるテスト
```

- **権威サーバー**: 30Hz の固定ステップでシミュレーションし、20Hz でスナップショットを送信。
- **クライアント予測 + リコンシリエーション**: 自分の移動は `shared/physics.js` で即座に予測し、サーバーが確認した入力番号以降を再適用して補正 (ズレは滑らかに吸収)。
- **補間**: 他プレイヤーは 100ms 遅れで 2 つのスナップショット間を補間。
- **スキルチェック**: 予兆と判定は手元で行い、結果だけ送信 (ラグの影響を受けないように)。サーバーは発行済み ID 以外を無視。
- 試合中に切断したプレイヤーはボットが引き継ぎます。

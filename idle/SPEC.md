# 百魔の王（仮） 仕様書（叩き台 v0.4）

> 構想段階。方針：ガチャで引いたキャラ1体が戦う／フィールド討伐→エリアボス→次ステージ／装備・スキルもガチャ／パッシブ要員は「守護霊」。
> 参考：「気づいたら魔王」（gameberry studio）の**仕組み**のみ（オートバトル・放置報酬・ガチャ・ステージ周回）。名前・キャラクター・絵・UI・文章は参考にしない。

---

## 1. コンセプト
- **一言**：ガチャで引いた魔物1体が、守護霊の加護を受けながらフィールドにはびこる魔物を勝手に狩り続け、エリアボスを倒して奥へ奥へ進んでいく放置RPG。
- **1回の遊び方**：開く → 留守中に何ステージ進んだか・何を拾ったかを見る → ガチャを引く → 出撃キャラと装備を直す → 閉じる。
- 課金・広告なし。ガチャ通貨はゲーム内で入手のみ。

## 2. 基本ループ
```
フィールドの雑魚を自動で討伐（討伐数ゲージが溜まる）
  → 規定数でエリアボス出現 → 倒せば次のステージへ
                           → 負けたら同じステージを自動で周回（強くなったら自動で再挑戦）
  → コイン・宝石・素材・守護霊を得る
  → 宝石でガチャ（キャラ・装備・スキル）、コインで強化
  → 出撃キャラ・装備・守護霊を整えて、さらに奥へ
```

## 3. 仕様

### 3.1 基本
| 項目 | 内容 |
|---|---|
| プラットフォーム | Webブラウザ（PC・スマホ縦画面） |
| 技術 | TypeScript + Vite + PixiJS（フィールド描画）＋ DOM（メニュー） |
| 保存 | localStorage に自動保存。書き出し/読み込み用の文字列も用意 |
| 配置 | このリポジトリの `idle/` |

### 3.2 メイン画面：フィールド討伐
- 画面上半分がフィールド（見下ろしの1画面マップ）。雑魚モンスターが一定数うろついていて、倒すと補充される。
- フィールドに出る自分のキャラは**1体**。**完全自動**：近くの敵を探す → 近づく → 攻撃 → スキル自動発動 → 次の敵へ。
- **討伐ゲージ**：雑魚を規定数（例：30体）倒すと満タンになり、**エリアボス**が出現。
- **ボス戦**：制限時間内に倒せば次のステージへ。キャラが倒れるか時間切れなら失敗。
- **失敗時**：同じステージの雑魚狩りに戻って周回し、報酬を稼ぐ。強化・ガチャでステータスが上がったら自動でボスに再挑戦（「ボス自動挑戦」のON/OFFあり）。
- ステージ構成：1エリア＝10ステージ。エリアごとに背景と出てくる魔物の種類が変わる。
- 見せ方：Librariumの絵をフィールド用に縮小して使う。歩くときは上下に弾ませ、向きは左右反転で表現（規約で反転・縮小は可）。攻撃時の飛び出し、被弾時の白点滅とノックバック、撃破時に崩れて消える。ボスは大きく表示。

### 3.3 キャラクター（ガチャ）
- Librarium の魔物から採用。ガチャで入手。
- **出撃**：フィールドに出るのは常に1体。手持ちから選んで入れ替える。
- **所持ボーナス（提案）**：出撃していないキャラも、持っているだけで全体に小さなボーナス（例：キャラ1体ごとに攻撃+1%、★が高いほど大きい）。1体しか出さなくても集める意味が残る。
- レア度 ★1〜★5。★が高いほど基礎ステータスとスキル枠が多い。
- タイプ：近接 / 遠距離 / 魔法 / 回復 などで、フィールドでの動き方が変わる（近づいて殴る、距離を取って撃つ、味方の近くにいる）。
- 属性：火・水・風・土・光・闇。属性相性でダメージ増減。
- 重複：同じキャラを引いたら「限界突破」でレベル上限と能力が伸びる。
- 育成：コインでレベル上げ（自動強化：優先順位を決めておけば勝手にコインを使う）。

### 3.4 装備（ガチャ）
- 枠：武器・防具・アクセサリー（キャラごと）。
- レア度5段階。同じものを重ねて強化。
- 装備ガチャはキャラガチャと別枠。

### 3.5 スキル（ガチャ）
- キャラに装着する技。最大2〜3枠（★で増える）。
- 種類：単体攻撃 / 範囲攻撃 / 回復 / 強化 / 弱体。クールタイムで自動発動。
- スキルは出撃キャラに装着する（キャラごとに付け替え）。
- 重複で強化。スキルガチャも別枠。

### 3.6 守護霊
- 戦闘には出ず、出撃キャラに**常時ボーナス**を与える（フィールドでは出撃キャラの背後に半透明で浮かべる）。
- 入手：フィールドの雑魚・ボスを倒したとき、まれにその魔物が守護霊になる（ボスは確率高め）。ガチャとは別ルートにして、「討伐していると勝手に集まる」放置らしさを出す。
- 効果：属性やランクに応じて 攻撃+% / HP+% / コイン獲得+% / ドロップ率+% など。
- 配置枠に置いた分だけ効果が出る。枠はステージ進行で増える。
- 同じ魔物を重ねるとランクアップ。図鑑の達成率でも恒久ボーナス。
- 色違い個体をレアとして出す（規約で色調変更は可）。

### 3.7 ガチャ
| ガチャ | 中身 | 通貨 |
|---|---|---|
| 召喚 | キャラ | 宝石 |
| 武具 | 装備 | 宝石 |
| 秘術 | スキル | 宝石 |
- 宝石の入手：ボス初回撃破、ミッション、図鑑、放置報酬。
- 天井あり（一定回数で★5確定、回数は要調整）。
- ガチャを引き続けるとガチャ自体のレベルが上がり、高レア排出率が上がる（放置系でよくある仕組み）。

### 3.8 放置
- 閉じている間：最後にいたステージの周回を計算で再現し、コイン・素材・守護霊・宝石を加算。ボスに勝てる強さならステージも進める（上限時間 24時間で仮置き）。
- 復帰時の **留守中レポート**：「12時間で 3-4 → 4-2、雑魚 18,400体討伐、守護霊 3体（うち色違い1）」のように成果を一覧表示。
- 開いている間も操作不要。

### 3.9 ミッション
- ガイドミッション：序盤の流れを順に案内。
- 日替わり・週替わり：宝石の主な入手源。

### 3.10 画面
- 上半分：フィールド（討伐ゲージ・ステージ表示・ボス挑戦ボタン）。
- 下半分のタブ：**出撃** / **強化** / **装備** / **スキル** / **守護霊** / **ガチャ** / **図鑑** / **設定**。
- 常時表示：コイン、宝石、戦闘速度。

### 素材の扱い
- 元ファイルは `idle/assets-src/` に置き、`.gitignore` で除外（公開リポジトリのため）。
- ビルド時に、使う魔物だけを縮小・圧縮してアトラスにする。
- **魔物データ作り**：874体に 名前・属性・タイプ・体格・レア度 を付ける。画像から自動で仮決め（主な色→属性、画像の大きさ→体格）→ 一覧ビューアで手直し → `monsters.json`。
- 1体の魔物が「ガチャキャラ」「フィールドの敵」「守護霊」のどれに使われるかもデータで決める（同じ魔物を兼用してよいかは未決定）。
- `idle/CREDITS.md` とゲーム内クレジット画面に表記。

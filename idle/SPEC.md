# 百魔の王（仮） 仕様書（叩き台 v0.2）

> 構想段階。v0.1（32rogues前提のパーティ制オートバトル）を置き換える。
> 参考：「気づいたら魔王」（gameberry studio）の**仕組み**（主人公1体の育成・オートバトル・放置報酬・鍵ダンジョン・掃討・進化）。
> 名前・キャラクター・絵・UI・文章は参考にしない。見た目はすべて Ækashics Librarium とオリジナルUIで作る。

---

## 1. コンセプト
- **一言**：生まれたての魔物が、勝手に戦って勝手に強くなり、倒した魔物を眷属にしながら、いつの間にか魔王になっていく放置RPG。
- **参考元から変えるところ（放置を強める）**
  | 参考元 | このゲーム |
  |---|---|
  | ステータス強化は手動でタップ | **自動強化**（優先順位を決めておけばコインを勝手に使う） |
  | ダンジョンは鍵を使って手動で挑戦・掃討 | **自動周回**（鍵が貯まったら勝手に挑戦、勝てる所は勝手に掃討） |
  | 放置報酬は回収のみ | **放置中もステージが進む**（閉じている間の戦闘を計算で再現） |
  | 主人公1体だけ | 主人公＋**眷属**（倒した魔物が仲間になる。Librariumの874体を収集対象に） |
  | ガチャは課金通貨 | 課金なし。ガチャ通貨はゲーム内で入手のみ |
- **1回の遊び方**：開く → 留守中の成果を見る（何階進んだ、誰が眷属になった、何を拾った）→ 強化の優先順位や眷属の配置を少し直す → 閉じる。

## 2. 基本ループ
```
主人公が自動でステージを進む（敵＝Librariumの魔物）
  → コイン・宝石・鍵・素材を得る / 倒した魔物がまれに眷属になる
  → コインで自動強化、鍵で自動ダンジョン、宝石でガチャ（装備・スキル）
  → 眷属を配置して能力ボーナスと放置収入を得る
  → 行き詰まったら「進化」（周回）：ステージは最初から、恒久ボーナスと新しい姿を得る
```

## 3. 仕様

### 3.1 基本
| 項目 | 内容 |
|---|---|
| プラットフォーム | Webブラウザ（PC・スマホ縦画面） |
| 技術 | TypeScript + Vite + PixiJS（戦闘描画）＋ DOM（メニュー） |
| 保存 | localStorage に自動保存。書き出し/読み込み用の文字列も用意 |
| 配置 | このリポジトリの `idle/` |

### 3.2 主人公と進化
- 主人公は魔物1体。最初は小さな魔物で、**進化**するたびに別のLibrarium魔物の姿に変わる（例：5〜7段階で最後が魔王）。
- 進化＝周回（プレステージ）。ステージ・コイン・ステータスレベルはリセット。眷属・図鑑・装備・恒久ボーナスは残る。
- 進化ごとに新しい能力が1つ解放される（例：2段階目で眷属枠+1、3段階目でダンジョン自動周回、など）。進化そのものが「機能が増える」ご褒美になる。

### 3.3 ステータスと自動強化
- ステータス：攻撃・HP・攻撃速度・会心率・会心ダメージ・回復量・獲得コイン・獲得経験。
- コインで1段階ずつ上げる。上限はステータスごとに設定（伸びは指数的、要調整）。
- **自動強化**：プレイヤーは「攻撃とHPを交互に、会心率は上限まで優先」のように優先順位を決めるだけ。コインが貯まり次第、勝手に振る。

### 3.4 戦闘（完全自動）
- 横スクロールで主人公が前進し、敵の群れが次々に来る。1ステージ＝数ウェーブ＋ボス。
- 主人公は通常攻撃とスキル（最大4枠、クールタイムで自動発動）で戦う。眷属は戦闘に出ず、ボーナスで支える（下記）。
- ボスに負けたら1つ前のステージに戻って周回し、強くなったら自動で再挑戦する。
- 見せ方：Librariumは正面向きの一枚絵なので、敵は正面向きで右から登場。動きはコードで付ける（呼吸の揺れ、攻撃時の飛び出し、被弾時の揺れと白点滅、撃破時に崩れて消える）。

### 3.5 眷属（Librarium収集）
- ステージの敵を倒すと、低確率でその魔物が**眷属**になる。ボスは確率高め。
- 眷属は戦闘には出ず、次の2つの役割を持つ。
  1. **玉座の間**（配置枠）：置いた眷属の属性・ランクに応じて主人公に常時ボーナス（攻撃+%、コイン+%など）。
  2. **遠征**：眷属を派遣しておくと、時間経過で素材・鍵・宝石を持ち帰る（放置収入の柱）。
- 同じ魔物を重ねて眷属ランクを上げる。図鑑の達成率でも恒久ボーナス。
- **色違い**：Librariumは色調変更が許可されているので、色違い個体をレアとして出す。

### 3.6 装備・スキル・ガチャ
- 装備：武器・防具・首飾り・指輪。レア度5段階。同じもの重ねで強化。
- スキル：攻撃・範囲・回復・強化系。ガチャで入手、重ねて強化。
- ガチャ通貨（宝石）はミッション・ボス・遠征・図鑑報酬で入手。**課金・広告なし**。

### 3.7 ダンジョン（自動周回）
| ダンジョン | 報酬 | 鍵 |
|---|---|---|
| 鍛錬の洞 | 装備強化石 | 赤の鍵 |
| 秘術の書庫 | スキル強化石 | 紫の鍵 |
| 刻印の祭壇 | 刻印（ルーン：ステータス補正の装着品） | 青の鍵 |
| 魂の淵 | 魂（眷属ランク上げ用） | 黒の鍵 |
- 鍵は時間で回復＋ステージ報酬で入手。
- **自動周回**：鍵が貯まったら、自動で最高到達階に挑戦。勝てない場合は勝てる最高階を掃討して報酬を受け取る。

### 3.8 放置
- 閉じている間：経過時間からステージ進行・コイン・ドロップ・眷属化・遠征・鍵回復を計算で再現（上限24時間、要調整）。
- 復帰時の **留守中レポート**：「12時間で 340→412 ステージ、眷属 3体（うち色違い1）、ダンジョン自動周回 18回」のように成果を一覧表示。これがこのゲームの一番の「開く楽しみ」。
- 開いている間も操作不要。画面を見ているだけで進む。

### 3.9 ミッション
- ガイドミッション：序盤の操作を順に案内（解放順の説明を兼ねる）。
- 日替わり・週替わりミッション：宝石と鍵の主な入手源。

### 3.10 画面
- メイン：上半分が戦闘、下半分がタブ。
- タブ：**強化**（ステータス・自動強化の優先順位）/ **眷属**（玉座の間・遠征・図鑑）/ **装備** / **スキル** / **ダンジョン** / **召喚**（ガチャ）/ **進化** / **設定**
- 常時表示：ステージ、コイン、宝石、鍵、戦闘速度。

## 4. 素材
| 用途 | 素材 | ライセンス | クレジット |
|---|---|---|---|
| 主人公・敵・眷属 | [Ækashics Librarium](https://aekashics.itch.io/aekashics-librarium-librarium-static-batch-megapack)（静止画874体＋骨格アニメ72体） | 独自：商用可、どのエンジンでも可、加工可（色調・反転・拡大縮小）、名前変更可。再配布不可、テンプレート形式での配布不可 | **必須**：「Ækashics」の名前と作者サイトへのリンク |
| アイコン（装備・スキル・素材） | 未定（Librariumの手描き調に合わせ、ドット絵は避ける） | — | — |
| UI | オリジナル（CSSで作る）を基本に、必要なら素材を追加 | — | — |
| SE・BGM | 未定（カタログの RPG Essentials SFX / Music Loop Bundle / 魔王魂 など） | — | — |

### 素材の扱い
- 元ファイルは `idle/assets-src/` に置き、`.gitignore` で除外（公開リポジトリのため）。
- ビルド時に、使う魔物だけを縮小・圧縮してアトラスにする。
- **魔物データ作り**：874体それぞれに 名前・属性・体格・ランク を付ける。
  1. 画像から自動で仮決め（主な色→属性、画像の大きさ→体格）
  2. 一覧ビューアで見ながら手で直す
  3. `monsters.json` に保存
- `idle/CREDITS.md` にクレジットを記載し、ゲーム内のクレジット画面にも表示。

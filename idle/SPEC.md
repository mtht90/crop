# 放置系キャラ収集オートバトル 仕様書（叩き台 v0.1）

> 仮案。キャラ素材は「2D（仮）」。Raven Fantasy Icons を装備・スキル・状態異常の表示に使う前提で組んでいる。

---

## 1. コンセプト
- **一言**：ダンジョンに潜る小さな冒険者たちを集めて、5人のパーティを組み、放っておくと勝手に戦って強くなっていくゲーム。
- **遊ぶ時間の想定**：1回数分。開いて報酬を回収し、キャラを引いて、編成と装備を直して閉じる。閉じている間も進む。
- **課金なし**。ガチャ相当の仕組みはゲーム内通貨のみ。

## 2. 基本ループ
```
自動戦闘でステージを進む → ゴールド・素材・装備・召喚石を得る
  → 召喚でキャラを集める / 重複でキャラを強化
  → 装備を付け替える・合成する
  → 編成を組み替えて、詰まったステージを突破する
  → 行き詰まったら「転生」（周回）で恒久ボーナスを得て最初からもっと速く進む
```

## 3. 仕様

### 3.1 基本
| 項目 | 内容 |
|---|---|
| プラットフォーム | Webブラウザ（PC優先、スマホ縦画面でも遊べるレイアウト） |
| 技術 | TypeScript + Vite + PixiJS（2D描画）。UIはDOMオーバーレイ |
| 保存 | localStorage（自動保存＋書き出し/読み込み用の文字列） |
| 配置 | このリポジトリの `idle/`（既存のMinecraftプラグイン・`game/` とビルド分離） |

### 3.2 戦闘（自動）
- 横向きの対面戦闘。味方5人（前列2・後列3）vs 敵の群れ（ウェーブ制、1ステージ＝3〜5ウェーブ＋ボス）。
- 各キャラは「通常攻撃」と「スキル（クールタイム制）」を自動で使う。プレイヤーの操作は**倍速切替**と**スキルの自動/手動切替**のみ。
- 状態異常（毒・燃焼・凍結・スタン・出血・挑発・バリアなど）をRavenのアイコンで頭上に表示。
- ダメージ数字、ヒット時の小さなフラッシュ、倒した時のアイコンドロップ演出。

### 3.3 キャラ収集
- **レア度**：★1〜★5。★が高いほど基礎ステータスとスキル枠が多い。
- **職業（6）**：戦士 / 守り手 / 射手 / 魔法使い / 僧侶 / 盗賊。前列・後列の得意位置が決まっている。
- **種族（5）**：人間 / 獣人 / アンデッド / 魔物 / 動物。
- **シナジー**：同じ職業・種族を2人/3人/5人揃えるとボーナス（オートチェス系の特性ボーナス）。編成を考える楽しさの中心。
- **重複**：同じキャラを引いたら「覚醒」素材になり、レベル上限とスキルが伸びる。
- **入手**：召喚（召喚石を消費）、ボスの確定ドロップ、図鑑の達成報酬。

### 3.4 装備（Raven Fantasy Icons を使う部分）
- 枠：武器・防具・アクセサリーの3枠。
- レア度は**色違いアイコン**で表現（Ravenは同じ形の色違いが多い）。
- 合成：同じ装備3つで1段階上に。素材（鉱石・木材・魔石）で強化。
- 装備ごとのランダム追加効果（例：攻撃+5%、毒付与 10%）。

### 3.5 放置要素
- 閉じている間の進行：最後に突破したステージの周回報酬を時間で計算（上限12時間、要調整）。
- 復帰時に「留守中の報酬」画面。
- **転生**：一定ステージ以降で可能。ステージとゴールドはリセット、キャラ・図鑑は残り、恒久ボーナス用の通貨を得る。

### 3.6 画面
タイトル → メイン（戦闘画面＋下部タブ）
- タブ：**編成** / **キャラ一覧・図鑑** / **装備** / **召喚** / **転生** / **設定**
- HUD：ステージ・ウェーブ、ゴールド、召喚石、倍速ボタン、留守中報酬の通知

## 4. 素材
| 用途 | 素材 | ライセンス | クレジット |
|---|---|---|---|
| キャラ・敵（第一候補） | [32rogues](https://sethbb.itch.io/32rogues) — 人型・魔物50体以上＋動物80体以上、32x32 | 独自（商用可・再配布不可・AI/NFT不可） | 任意 |

| SE | [RPG Essentials SFX](https://leohpaz.itch.io/rpg-essentials-sfx-free) | 独自（商用可・再配布不可） | 任意 |

| フォント | DotGothic16 | OFL | — |

**32rogues を第一候補にする理由**：Ravenと同じ32x32のドット絵で、どちらも黒い縁取りなので並べても浮かない。キャラ数が多く「集める」遊びに足りる。アニメが無い静止画なので、動きはコードで付ける（上下に弾む待機、攻撃時の前進と伸縮、被弾時の点滅とノックバック）。

### 素材の扱い
- 素材はすべて**再配布不可**。このリポジトリは公開なので、元ファイルは `idle/assets-src/` に置き、`.gitignore` で除外する。
- ビルド時に必要なアイコンだけを切り出してアトラスにまとめる（未使用の素材をまとめて配信しない）。
- `idle/CREDITS.md` で全素材のライセンスを管理する。
- Ravenのファイル名は連番（`fb1.png`〜）で分類が無いため、**アイコンID対応表**（`icons.json`：ID → 用途・名前・レア度）を作る。

## 5. 実装計画
| フェーズ | 内容 | 完了条件 |
|---|---|---|
| P0 基盤 | `idle/` に Vite + TS + PixiJS、素材の切り出しスクリプト、CI（既存ワークフローとは別） | 空の画面が表示され、CIでビルドが通る |
| P1 戦闘コア | 5対Nの自動戦闘、通常攻撃・スキル・状態異常、ウェーブとボス、倍速 | 仮キャラ5人がステージを自動で進む |
| P2 収集 | キャラ定義データ（1キャラ＝1データ）、召喚、重複覚醒、図鑑、職業/種族シナジー | 召喚して編成を変えると勝敗が変わる |
| P3 装備 | 3枠装備、色違いレア度、合成・強化、ランダム追加効果、アイコン対応表 | 装備の付け替えで突破できるステージが変わる |
| P4 放置 | 自動保存、留守中報酬、転生 | 閉じて開くと報酬が貯まっている |
| P5 見た目と音 | 動きの演出、エフェクト、SE/BGM、UI素材の適用 | 素材込みで通しで遊べる（MVP） |
| P6 調整 | 数値バランス、スマホ表示、キャラ追加 | — |

# Spirit Master

放置系のオートバトルRPG「Spirit Master」を作ってください。
下に書いたこと以外（技術、画面構成、数値、世界観、演出など）は自由に決めてください。面白さを優先してください。

## プラットフォーム
- ブラウザゲーム。Render で公開する。

## 見た目
- UIはしっかり作り込む。
- 見た目はすべて外部素材の画像で作る。CSSやコードで絵を描かない（下の補足を参照）。
- アセットは絵柄の統一感を最優先に厳選する。Librarium の手描きの絵柄に合わないもの（ドット絵など）は使わない。
- UI素材は [Cozy UI Pack](https://dobo-ui.itch.io/cozy-ui)（dobo_ui）を使う。
  - ライセンス：商用可・改変可。素材の再配布・販売、NFT、生成AIの学習への利用は不可。
  - 元ファイルは Librarium と同じく `idle/assets-src/` に置き、コミットしない。

## ゲーム
- 参考：「気づいたら魔王」の仕組み。放置要素はそれより強くする。名前・キャラ・絵・UIは真似しない。
- ガチャで引いたキャラを1体選んで使う。
- そのキャラがメイン画面のフィールドにはびこるモンスターを自動で討伐していく。
- 一定数倒すとエリアボスが出る。倒せたら次のステージへ。倒せなかったら（死んだら）そのステージを自動で周回する。
- 装備とスキルもガチャで手に入る。
- 守護霊：戦闘には出ず、パッシブ効果を与える。

## キャラ素材
- キャラはすべて [Ækashics Librarium](https://aekashics.itch.io/aekashics-librarium-librarium-static-batch-megapack) から使う。
- 敵と味方は別のキャラにする。プレイヤーが使うキャラと守護霊は同じキャラでもよい。
- ライセンス：
  - 商用可・どのエンジンでも可・加工可（色調・反転・拡大縮小）・名前の変更可。
  - ゲーム内のクレジットに「Ækashics」と作者サイト（https://www.akashics.moe/）へのリンクを必ず載せる。
  - 素材ファイルの再配布は不可。このリポジトリは公開なので、素材の元ファイルは `idle/assets-src/`（`.gitignore` で除外済み）に置き、コミットしない。

## 補足：見た目は全部外部素材
- ボタン・パネル・枠・ゲージ・タブ・アイコン・背景・エフェクトなど、目に見えるものはすべて外部素材の画像を使う。
- CSSで見た目を描くのは禁止（グラデーション・角丸の箱・影・CSSで作ったボタンやゲージ・図形・絵文字を絵の代わりにすることなど）。
- CSSは配置・レイアウトと、素材画像の表示（`border-image` などで素材を伸縮させる、位置・拡大縮小・動き）にだけ使う。
- UIは Cozy UI Pack、キャラは Librarium を使う。それ以外に必要な素材（フィールドの背景、エフェクト、効果音、BGM、フォントなど）も、絵柄の合う外部素材を探して使う。ライセンスを確認し、`idle/CREDITS.md` に記録する。
- 今CSSで描いている部分は、すべて素材に置き換える。

# Credits

All art, sound and fonts are third-party assets. None of the source files are committed to this
repository: `scripts/fetch-assets.mjs` downloads them from each author's official page at build time,
and `scripts/build-assets.mjs` only resizes / trims / recolors / packs them. The mapping of which file
is used for what lives in `src/data/assets.ts`.

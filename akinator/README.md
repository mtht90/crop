# 千里眼のシキ — 心を読むアキネーター

人物・キャラ・動物・植物・食べ物・物・場所、なんでも当てる Web ゲーム。
外部 API には頼らず、**知識ベースを自前で持ち、遊ばれるほど賢くなる**。

## 動かす

```bash
cd akinator
node server.mjs          # → http://localhost:3000   (Node 18+、依存なし)
```

サーバーなし（GitHub Pages 等）で置く場合は `node tools/build-static.mjs` で `public/db.json` を作り、`public/` を配信する。
この場合、学習データは各プレイヤーのブラウザ（localStorage）にだけ貯まる。

## しくみ

| 部分 | ファイル | 内容 |
|---|---|---|
| 質問・タグ体系 | `data/questions.txt` | 約330問。排他グループ・含意ルール（`mlb ⇒ baseball ⇒ athlete` など） |
| 知識ベース | `data/entities/*.txt` | `名前/別名 \| タグ…` の1行1件。現在 約1,700件 |
| 推論エンジン | `public/engine.js` | ベイズ推定＋情報利得最大の質問選択＋学習（ブラウザ／Node 共通） |
| サーバー | `server.mjs` | DB配信と学習データの保存（`data/learned.json`） |
| 画面 | `public/` | 占い師キャラ・読心率メーター・匂わせ演出 |

### 「心を読まれた」体験の作り方
- **賢い質問選択**: 毎回、回答後の候補のエントロピー期待値が最小になる質問を選ぶ。序盤は上位数問からランダムに選ぶので毎回同じ流れにならない。
- **曖昧・嘘に強い**: 回答は確率モデル（「はい」でも数%は違うかもしれない）で扱うので、1問間違えても当てられる。「わからない」「たぶん」も情報として使う。
- **早当て**: 確信度93%以上なら4問目からでも当てに行き、「もう分かった。これ以上の質問は不要だ。」と宣言する。
- **匂わせ**: まだ聞いていない特徴（例: *ポケモン*、*ジャンプ作品*、*武将*）を候補の大半が共有していると、「……ポケモン、だな？ いや、答えなくてよい。」と先回りする。
- **読心率メーター・セリフ**: 確信度に応じて占い師の目・水晶玉・セリフが変わる。

自己対戦（`node test/simulate.mjs 200 0.1`、10%の回答をランダムに乱した条件）で
**正解率 約98%・1回目で的中 約86%・平均 約18問**。

### 学習
- 当たったとき: その対象への回答を記録し、質問ごとの答えの分布を補正する（ディリクレ事後）。
- 外れたとき: 正解を教えてもらう。既存の対象なら回答を記録、未知なら新しい対象として追加。
- 新規の対象は `NEW_ENTITY_MIN_VOTES`（既定2）人以上から教わるまで他の人の候補に出ない（いたずら対策）。
- 不適切な投稿は `data/learned.json` から該当キーを消せばよい。

## データを1万件以上に増やす

手書きの初期データに加え、Claude API で一括生成するツールがある。

```bash
cd akinator && npm install
export ANTHROPIC_API_KEY=...
node tools/generate.mjs --all --dry-run     # 生成予定のテーマ一覧（43テーマ・合計約1万件）
node tools/generate.mjs --all               # 生成（既存テーマはスキップ。途中で止めても再開できる）
node tools/generate.mjs --domain C --theme "鬼滅の刃のキャラクター" --count 50   # 個別に追加
node tools/check.mjs                        # 検証
```

- 生成は `data/entities/gen_*.txt` に出力。未知タグは除去、既存と重複する名前は捨てる。
- **生成データは事実誤りを含みうる**ので、`git diff` で目視確認してからコミットすること。
- モデルは `GEN_MODEL` 環境変数で変更可（既定 `claude-opus-5-5`、拒否時は自動フォールバック）。

## データの書き方

```
@P                                   ← ドメイン (P人物 C架空 A動物 L植物 F食べ物 O物 S場所)
大谷翔平 | m jp era21 active mlb tv *
```
- `tag` 当てはまる / `?tag` 場合による / `-tag` 明確に違う / `*` 超有名（事前確率3倍）
- タグを付けないものは「たぶん違う」扱い。当てはまるタグはなるべく漏れなく付ける。
- 新しい質問は `questions.txt` に1行足すだけ。既存データにそのタグが無くても、学習で答えの分布が埋まっていく。

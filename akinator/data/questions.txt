#
#  ディレクティブ:
#    !group 名前 tag tag ...   排他グループ（どれか1つを持てば他は「いいえ」）
#    !imply tag => tag tag ... 含意（左を持てば右も持つ）
#    !default D group tag      ドメインDでグループのタグが無ければtagを付与
#    !alias 短縮 => 正式タグ    エンティティ記述用の短縮名
# ============================================================

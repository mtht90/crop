# inachat

白ベース × 青系統一のリアルタイムチャット。ルームを作ってQRで招待し、閉じていてもプッシュ通知が届きます。
Node.js + WebSocket（`ws`）で、ビルド工程はありません。

## できること

- **ルーム**: 作成、参加中一覧（未読数つき）、切り替え、退出、作成者による削除
- **公開ルーム**: 「さがす」タブに人数つきで表示され、誰でも参加できる
- **招待制ルーム**: 推測されにくいURL（`/?r=xxxxxxxx`）を知っている人だけが入れる
- **合言葉**: ルームに設定すると参加時に入力が必要（サーバーには scrypt のハッシュのみ保存）
- **QR招待**: 招待シートのQRを読むと参加画面が開く。「合言葉もリンクに含める」をオンにすると、QRだけで参加できる（合言葉はURLの `#` 以降に入るためサーバーには送られません）
- **プッシュ通知**: ブラウザやアプリを閉じていても新着を通知。そのルームを開いて見ている間は送らない。ルームごとにオフにできる
- **PWA**: ホーム画面に追加してアプリとして使える。iPhone / iPad はホーム画面に追加したアプリでのみ通知を受け取れます（iOS 16.4 以降）

## ローカルで動かす

```bash
cd chat
npm install
npm start
```

`http://localhost:3000` を開きます。`REDIS_URL` がないときは `chat/data/state.json` に保存します。

## Render にデプロイ

リポジトリ直下の `render.yaml`（Blueprint）で次の2つが作られます。

| サービス | 内容 |
|---|---|
| `inachat`（Web Service, free） | アプリ本体。`SECRET` は自動生成され、通知用の鍵がここから作られます |
| `inachat-store`（Key Value, free） | ルーム・履歴・通知登録の保存先。Webサービスがスリープ・再起動しても残ります |

手順: Render ダッシュボードで **New → Blueprint** を選び、このリポジトリとブランチを指定して **Apply**。

## 無料プランの注意

- Webサービスは15分アクセスがないとスリープし、次のアクセスで起動に30秒〜1分かかります。スリープ中に届いたメッセージはないので通知も出ませんが、誰かが開いて送信すれば通知は届きます
- 無料の Key Value は Render 側の都合でまれに再起動され、その際は保存内容（ルーム・履歴）が消えます。確実に残したい場合は Key Value を有料プランにしてください
- Key Value の無料インスタンスはワークスペースに1つまでです

## 環境変数

| 変数 | 説明 |
|---|---|
| `REDIS_URL` | 保存先の Redis / Key Value。未設定ならファイル保存 |
| `SECRET` | 通知（VAPID）鍵の元になる値。変えると既存の通知登録が無効になり、各端末で開き直すと再登録されます |
| `VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY` | 鍵を直接指定したい場合（`SECRET` より優先） |
| `VAPID_SUBJECT` | 通知サービスに伝える連絡先（`mailto:` か URL）。未設定なら Render の公開URL |
